## 2. 交叉算子改进

### 2.1 打印阶段交叉（50% POX + 50% JBX）

#### 新增方法
```java
public void operSeqCrossoverPOX_Print(int[] o1, int[] m1, int[] o2, int[] m2)
public void operSeqCrossoverJBX_Print(int[] o1, int[] m1, int[] o2, int[] m2)
```

#### 实现特点
- **POX交叉（50%概率）**：
  - 随机选择工件集合
  - 保留选中工件的位置和机器分配
  - 其他工件从另一父代继承
  - 同时交换工序序列和对应的机器分配

- **JBX交叉（50%概率）**：
  - 随机选择工件集合
  - 保留选中工件在原位置
  - 其他工件位置打乱
  - 同时交换工序序列和对应的机器分配

### 2.2 机器层交叉（任意两点交换序列）

#### 新增方法
```java
public void machineSeqCrossover_TwoPointSwap(int[] m1, int[] m2)
```

#### 实现特点
- 随机选择两个交叉点
- 交换两点之间的机器序列
- 适用于打印阶段和离散处理阶段

### 2.3 主交叉方法更新

```java
public void Crossover(Chromosome c1, Chromosome c2) {
    // 清空printSolution缓存
    c1.printSolution = null;
    c2.printSolution = null;
    
    // 打印阶段：50% POX交叉，50% JBX交叉
    double printCrossoverType = r.nextDouble();
    if (printCrossoverType < 0.5) {
        operSeqCrossoverPOX_Print(c1.gene_OS, c1.gene_MS, c2.gene_OS, c2.gene_MS);
    } else {
        operSeqCrossoverJBX_Print(c1.gene_OS, c1.gene_MS, c2.gene_OS, c2.gene_MS);
    }
    
    // 机器层：选取任意两点交换序列
    machineSeqCrossover_TwoPointSwap(c1.gene_MS, c2.gene_MS);
    
    // 修复无效机器分配
    fixInvalidMachineAssignments(c1);
    fixInvalidMachineAssignments(c2);
    
    // 验证染色体有效性
    validateChromosome(c1, "交叉后-c1");
    validateChromosome(c2, "交叉后-c2");
}
```

## 3. 变异算子改进

### 3.1 新的变异策略

#### 主要特点
- 在工件层随机选择多个点位（1-5个）进行机器重分配
- 50%变异为可选机器中加工时间最短的机器（打印层高最高的打印机）
- 50%变异为可选机器中随机一个机器

### 3.2 实现方法

```java
public void Mutation(Chromosome chromosome) {
    chromosome.printSolution = null;
    
    // 随机选择变异点的数量（1到5个点位）
    int mutationPoints = 1 + r.nextInt(5);
    
    // 随机选择变异位置（避免重复）
    Set<Integer> selectedPositions = new HashSet<>();
    while (selectedPositions.size() < mutationPoints && 
           selectedPositions.size() < totalLength) {
        selectedPositions.add(r.nextInt(totalLength));
    }
    
    // 对每个选中的位置进行变异
    for (int pos : selectedPositions) {
        int jobNo = chromosome.gene_OS[pos];
        
        if (pos < jobCount) {
            // 打印工序变异
            mutatePrintOperation(chromosome, pos, jobNo);
        } else {
            // 离散工序变异
            mutateDiscreteOperation(chromosome, pos, jobNo, 
                                   proDesMatrix, operationToIndex);
        }
    }
    
    // 修复可能的无效机器分配
    fixInvalidMachineAssignments(chromosome);
}
```

```java
private void mutatePrintOperation(Chromosome chromosome, int pos, int jobNo) {
    // 找到所有可以容纳该零件的打印机
    List<Integer> availablePrinters = new ArrayList<>();
    List<Double> printerHeights = new ArrayList<>();
    
    // 收集可用打印机及其层高
    for (int i = 0; i < printMachineCount; i++) {
        PrintMachine pm = (PrintMachine) machines[i];
        if (零件可以放入打印机) {
            availablePrinters.add(i + 1);
            printerHeights.add(pm.H);  // 打印层高
        }
    }
    
    // 50%选择打印层高最高的，50%随机选择
    if (r.nextDouble() < 0.5) {
        // 选择打印层高最高的打印机
        chromosome.gene_MS[pos] = 层高最高的打印机;
    } else {
        // 随机选择一个打印机
        chromosome.gene_MS[pos] = 随机打印机;
    }
}
```

### 3.4 离散工序变异

```java
private void mutateDiscreteOperation(Chromosome chromosome, int pos, int jobNo, 
                                     double[][] proDesMatrix, int[][] operationToIndex) {
    // 计算工序编号
    int operNo = 计算该工件的第几个离散工序;
    int operIdx = operationToIndex[jobNo][operNo];
    
    // 找到所有可用机器及其加工时间
    List<Integer> availableMachines = new ArrayList<>();
    List<Double> processingTimes = new ArrayList<>();
    
    for (int k = 0; k < proDesMatrix[operIdx].length; k++) {
        if (proDesMatrix[operIdx][k] > 0 && 
            proDesMatrix[operIdx][k] != Double.MAX_VALUE) {
            availableMachines.add(k + 1);
            processingTimes.add(proDesMatrix[operIdx][k]);
        }
    }
    
    // 50%选择加工时间最短的，50%随机选择
    if (r.nextDouble() < 0.5) {
        // 选择加工时间最短的机器
        chromosome.gene_MS[pos] = 加工时间最短的机器;
    } else {
        // 随机选择一个机器
        chromosome.gene_MS[pos] = 随机机器;
    }
}
```

## 4. 局部搜索策略

### 4.1 现有实现

局部搜索策略已经在原算法中实现，包括以下五个邻域动作：

1. **N1: 基于打印时间的跨机移动**
   - 将打印时间长的零件移动到其他打印机
   - 减少关键打印机的负载

2. **N2: 基于面积占用率的跨机移动**
   - 将面积占用率高的零件移动到其他打印机
   - 优化打印机空间利用率

3. **N3: 相邻批次交换**
   - 交换同一打印机上的相邻批次
   - 优化打印顺序

4. **N4: 关键块内工序插入**
   - 在关键路径的关键块内插入工序
   - 减少makespan

5. **N5: 关键工序机器重分配**
   - 为关键路径上的工序重新分配机器
   - 选择加工时间更短的机器

### 4.2 局部搜索流程

```java
            case 3: // N4: 关键块内工序插入
                // 生成关键块移动候选，评估并接受改进
```

## 8. 注意事项

### 8.1 机器分配约束
- 打印工序：必须分配到能容纳零件尺寸的打印机
- 离散工序：必须分配到能加工该工序的机器（加工时间>0且!=MAX_VALUE）

### 8.2 工序顺序约束
- 同一工件的工序必须按顺序执行：打印 → 批处理 → 离散加工1 → 离散加工2 → ...
- 交叉和变异操作不会改变同一工件内部的工序顺序

### 8.3 修复机制
- `fixInvalidMachineAssignments()` 会在交叉和变异后自动调用
- 该方法会检查并修复所有无效的机器分配
- 修复时优先选择加工时间短的机器
