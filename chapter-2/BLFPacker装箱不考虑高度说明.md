# BLFPacker装箱逻辑说明 - 不考虑高度约束

## 重要修改

已移除装箱过程中的高度约束检查。

---

## 📋 装箱逻辑

### 2D装箱 vs 3D打印

**关键理解**：
- **装箱阶段**：只考虑L×W平面的2D装箱问题
- **打印阶段**：批次的高度由最高零件决定，影响打印时间

```
装箱过程：
┌─────────────────┐
│  2D平面装箱      │
│  只考虑 L × W    │  ← 不限制高度
│  零件尽量放入    │
└─────────────────┘
         ↓
批次高度 = max(所有零件高度)
         ↓
打印时间 = f(批次高度)
```

## 📊 装箱流程

```
对每个零件：
│
├─ 计算2D尺寸 (itemL, itemW)
│  └─ 根据朝向和旋转计算
│
├─ 尝试在L×W平面上放置
│  ├─ 搜索可行天际线
│  ├─ 检查 X + itemL ≤ L
│  └─ 检查 Y + itemW ≤ W
│
├─ 如果能放置：
│  ├─ 放入当前批次
│  ├─ 记录零件高度 itemH
│  └─ 更新批次最大高度
│
└─ 如果不能放置：
   └─ 进入下一批次
```

## 🎯 批次属性

### 计算方式

```java
// 1. 总面积
totalArea += itemL * itemW;  // 所有零件面积之和

// 2. 最大高度
maxHeight = Math.max(maxHeight, itemH);  // 取最高零件

// 3. 利用率
utilizationRate = totalArea / (L * W);  // 平面利用率

// 4. 返回Solution
return new Solution(placedItems, maxHeight, totalArea, utilizationRate);
```

### Solution参数说明

| 参数 | 含义 | 说明 |
|------|------|------|
| `placedItems` | 已放置零件列表 | 该批次包含的所有零件 |
| `maxHeight` | 批次最大高度 | max(所有零件高度) |
| `totalArea` | 总面积 | Σ(itemL × itemW) |
| `utilizationRate` | 平面利用率 | totalArea / (L × W) |

## 💡 为什么不考虑高度？

### 1. 打印特性

3D打印机的构建腔室：
- **L × W**：打印平台尺寸（有限）
- **H**：打印高度方向（理论上无限，只影响时间）

同一批次的零件：
- 并排放置在L×W平面上
- 打印高度 = 最高零件的高度
- 所有零件同时打印（同一高度）

### 2. 批次高度影响

```
批次高度 → 影响打印时间
打印时间 = 准备时间 + 重涂层时间 × (批次高度 / 打印层高)
```

**但不影响能否装入批次！**

### 3. 装箱目标

- **目标**：最大化平面利用率
- **约束**：L × W 平面空间
- **不约束**：高度（高度只影响打印时间，不影响装箱）

## 📈 示例

### 示例：3个零件装箱

**零件信息**：
```
零件1: 10×10×5  (L×W×H)
零件2: 10×10×20 (很高)
零件3: 10×10×3  (很矮)
```

**构建腔室**：100×100×50

### 旧逻辑（考虑高度）

```
批次1: [零件1]  maxHeight=5
批次2: [零件2]  maxHeight=20  ← 可能被拒绝（超过某个阈值）
批次3: [零件3]  maxHeight=3
```

**问题**：零件2可能因为太高而独占一个批次

### 新逻辑（不考虑高度）

```
批次1: [零件1, 零件2, 零件3]  maxHeight=20

打印时间 = 准备时间 + 重涂层时间 × (20 / 打印层高)
```

**优点**：
- ✅ 平面利用率更高
- ✅ 批次数量更少
- ⚠️ 某些批次打印时间可能较长（但总体更优）

## 📝 注意事项

### 1. 高度仍然记录

虽然不作为约束，但`maxHeight`仍然计算和记录：
```java
maxHeight = Math.max(maxHeight, itemH);
```

**用途**：
- 传递给Solution对象
- 用于后续打印时间计算
- 用于甘特图和报告

### 2. 打印时间计算

在`RandomKeyEvaluator`中计算打印时间时会使用`batch.maxG`（即maxHeight）：

```java
double printTime = pm.prepareTime + pm.reCoatingTime * batch.maxG / pm.printH;
```

### 3. 真实场景考虑

如果实际应用中确实需要限制批次高度：
- 可以在后处理阶段检查
- 可以添加软约束（惩罚过高批次）
- 可以设置一个很大的H值作为硬约束
