# PSO粒子群算法 - 对比算法实现说明

## 📋 算法简介

**PSO (Particle Swarm Optimization)** - 粒子群优化算法，是一种基于群体智能的启发式算法，灵感来源于鸟群觅食行为。

### 核心思想

```
每个粒子 = 一个解
粒子在解空间中飞行
受到两种力的影响：
  1. 个体经验（个体最优）
  2. 群体经验（全局最优）
通过速度和位置的更新，逐渐找到最优解
```

---

## 🎯 为什么选择PSO作为对比算法？

### 1. 同样是群体智能算法
- ✅ 与GA同属于元启发式算法
- ✅ 都基于种群/群体进行搜索
- ✅ 对比更有意义

### 2. 算法特性不同
| 特性 | 混合GA | PSO |
|------|--------|-----|
| **搜索机制** | 交叉+变异 | 速度+位置更新 |
| **信息共享** | 隐式（通过选择） | 显式（全局最优） |
| **探索vs开发** | 通过pm/pc平衡 | 通过w/c1/c2平衡 |
| **局部搜索** | 独立的5个邻域算子 | 无（PSO本身就是搜索） |

- ✅ 证明混合GA的优势
- ✅ 展示算法对比分析
- ✅ 提供统计显著性检验

## 🧬 PSO编码方式

### 与GA的编码一致

为了公平对比，PSO使用与GA相同的编码：

```
粒子 = {gene_OS, gene_MS}

gene_OS = [工序序列]
  示例: [J0, J1, J2, J0, J1, J2, ...]
  
gene_MS = [机器分配]
  示例: [P1, P2, P1, M1, M2, M3, ...]
```

### PSO特有属性

```
粒子额外包含：
1. velocity_OS: 工序序列的"速度"（交换操作列表）
2. velocity_MS: 机器分配的"速度"（机器变更列表）
3. pBest_OS, pBest_MS: 个体历史最优位置
4. pBestFitness: 个体历史最优适应度
```

---

## ⚙️ PSO核心机制

### 1. 速度更新

**标准PSO公式**：
```
v_new = w * v_old + c1 * r1 * (pBest - x) + c2 * r2 * (gBest - x)
```

**离散化适配**（针对调度问题）：

```java
// 工序序列速度 = 交换操作列表
velocity_OS = [
    SwapOperation(pos1=3, pos2=7),   // 交换位置3和7
    SwapOperation(pos1=5, pos2=9),   // 交换位置5和9
    ...
]

// 机器分配速度 = 机器变更列表
velocity_MS = [
    MachineChange(position=2, newMachine=5),  // 位置2改为机器5
    MachineChange(position=8, newMachine=3),  // 位置8改为机器3
    ...
]
```

**速度生成过程**：

```java
// 1. 个体认知部分：学习个体最优
if (random() < c1) {
    计算 current 与 pBest 的差异;
    生成交换操作序列使 current → pBest;
    添加到 velocity;
}

// 2. 社会认知部分：学习全局最优
if (random() < c2) {
    计算 current 与 gBest 的差异;
    生成交换操作序列使 current → gBest;
    添加到 velocity;
}
```

---

### 2. 位置更新

**应用速度到位置**：

```java
// 1. 应用工序序列的速度
for (SwapOperation swap : velocity_OS) {
    交换 gene_OS[swap.pos1] 和 gene_OS[swap.pos2];
    同步交换 gene_MS[swap.pos1] 和 gene_MS[swap.pos2];
}

// 2. 应用机器分配的速度
for (MachineChange change : velocity_MS) {
    if (机器可行) {
        gene_MS[change.position] = change.newMachine;
    }
}
```

---

### 3. 自适应惯性权重

**线性递减策略**：

```java
w = w_max - (w_max - w_min) * (iter / maxIter)

初始: w = 0.7  (偏向探索)
最终: w = 0.4  (偏向开发)

实现：
if (iteration % 50 == 0) {
    w = Math.max(0.4, w * 0.98);
}
```

**作用**：
- **前期**: w大 → 保持惯性 → 全局探索
- **后期**: w小 → 快速收敛 → 局部开发

## 🔬 算法流程

### 完整伪代码

```
1. 初始化粒子群
   for i = 1 to swarmSize:
       粒子[i] = 随机生成或启发式生成
       pBest[i] = 粒子[i]
   
2. 评估初始适应度
   for 每个粒子:
       fitness = evaluate(粒子)
   gBest = 最优粒子
   
3. 主循环
   while (未达到终止条件):
       for 每个粒子:
           更新速度(w, c1, c2, pBest, gBest)
           更新位置(应用速度)
           评估适应度
           if (fitness > pBest.fitness):
               pBest = 当前位置
       
       if (最优粒子 > gBest):
           gBest = 最优粒子
       
       自适应调整 w
   
4. 返回 gBest
```

## 🆚 PSO vs 混合GA 对比

### 算法特性对比

| 维度 | 混合GA | PSO |
|------|--------|-----|
| **种群/群体大小** | 100 | 100 |
| **主要操作** | 交叉(90%) + 变异(30%) | 速度更新 + 位置更新 |
| **信息共享** | 通过交叉隐式共享 | 通过gBest显式共享 |
| **局部搜索** | ✅ 5个邻域算子(N1-N5) | ❌ 无独立局部搜索 |
| **初始化** | 启发式多样化 | 启发式多样化 |
| **参数数量** | 多（pc, pm, 局部搜索参数） | 少（w, c1, c2） |
| **收敛速度** | 中等 | 快速（gBest引导） |
| **多样性维持** | 变异+局部搜索 | 惯性权重 |

### 预期性能对比

**混合GA 的优势**：
- ✅ 局部搜索强化（5个邻域算子）
- ✅ 更细致的解空间探索
- ✅ 更好的解质量

**PSO 的优势**：
- ✅ 参数少，易调试
- ✅ 收敛快
- ✅ 实现简单

## 💡 PSO参数说明

### 关键参数

| 参数 | 默认值 | 作用 | 调整建议 |
|------|--------|------|---------|
| **swarmSize** | 100 | 粒子群大小 | 与GA的popSize一致 |
| **w** | 0.7→0.4 | 惯性权重 | 自适应递减 |
| **c1** | 1.5 | 个体学习因子 | 控制向pBest靠拢 |
| **c2** | 1.5 | 社会学习因子 | 控制向gBest靠拢 |

### 参数平衡

```
c1 > c2: 偏向个体探索（多样性强）
c1 < c2: 偏向群体收敛（收敛快）
c1 = c2: 平衡探索和开发（推荐）

w大: 全局探索能力强
w小: 局部开发能力强
自适应: 前期探索，后期开发（最优）
```

## 🔬 实现细节

### 1. 离散化处理

**问题**：调度问题是离散的，而PSO原本用于连续优化

**解决方案**：

```java
// 速度 = 离散操作序列

velocity_OS = List<SwapOperation>
  SwapOperation {pos1, pos2}  // 交换两个位置

velocity_MS = List<MachineChange>
  MachineChange {position, newMachine}  // 改变机器分配
```

### 2. 速度计算

**从 current 到 target 的差异**：

```java
// 计算需要多少次交换才能从current变成target
int[] temp = current.clone();
for (int i = 0; i < temp.length; i++) {
    if (temp[i] != target[i]) {
        找到 target[i] 在 temp 中的位置 j;
        记录 SwapOperation(i, j);
        执行交换;
    }
}
```

### 3. 位置更新

```java
// 应用速度（执行交换操作）
for (SwapOperation swap : velocity) {
    swap(gene_OS[swap.pos1], gene_OS[swap.pos2]);
    swap(gene_MS[swap.pos1], gene_MS[swap.pos2]);
}

// 应用机器变更
for (MachineChange change : velocity) {
    if (机器可行) {
        gene_MS[change.position] = change.newMachine;
    }
}
```
