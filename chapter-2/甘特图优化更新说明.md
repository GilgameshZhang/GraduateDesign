### 2. **批处理机和离散机显示问题** ✅

**问题描述**：
- 甘特图上只显示打印机的工序
- 批处理机和离散机的工序未显示

**原因分析**：
- Y轴范围设置错误
- 机器编号坐标偏移不正确

**解决方案**：
- 修正Y轴范围：从 `-0.5 到 totalMachines-0.5`
- 修正矩形Y坐标：`machineNo + 0.1`（之前是 `+ 0.6`）
- 添加工序统计输出，便于调试

**修改代码**：
```java
// 设置Y轴范围（机器编号从0开始）
int totalMachines = problem.getMachineCount();
plot.getRangeAxis().setRange(-0.5, totalMachines - 0.5);

// 绘制工序矩形
double y = op.machineNo + 0.1;  // 修正坐标偏移
double height = 0.8;

// 统计工序数量（调试用）
System.out.println("  ✓ 甘特图已保存: " + outputPath);
System.out.println("    - 打印工序: " + printOpCount + " 个");
System.out.println("    - 批处理工序: " + batchOpCount + " 个");
System.out.println("    - 离散工序: " + discreteOpCount + " 个");
```

### 3. **详细报告增强 - 机器运行时间统计** ✅

**新增内容**：
- 每台机器的工作时间
- 每台机器的完成时间
- 每台机器的利用率
- 各类型机器的汇总统计
- 全局机器利用率

**报告格式示例**：

```
【机器运行时间统计】

打印机:
  打印机1: 工序数=5, 工作时间=120.50, 完成时间=120.50, 利用率=100.0%
  打印机2: 工序数=3, 工作时间=80.30, 完成时间=95.20, 利用率=84.4%
  打印机总工作时间: 200.80

批处理机器:
  批处理机1: 工序数=8, 工作时间=40.00, 完成时间=140.50, 利用率=28.5%
  批处理机总工作时间: 40.00

离散处理机器:
  离散机1: 工序数=6, 工作时间=30.20, 完成时间=165.30, 利用率=18.3%
  离散机2: 工序数=4, 工作时间=20.10, 完成时间=170.40, 利用率=11.8%
  离散机总工作时间: 50.30

全局统计:
  所有机器总工作时间: 291.10
  最终完成时间(Makespan): 170.40
  整体机器利用率: 34.1%
```

**统计指标说明**：

| 指标 | 说明 | 计算方法 |
|------|------|----------|
| 工序数 | 该机器处理的工序数量 | 统计操作次数 |
| 工作时间 | 机器实际工作时间 | Σ(工序结束时间 - 工序开始时间) |
| 完成时间 | 机器最后一个工序结束时间 | max(所有工序结束时间) |
| 利用率 | 机器工作效率 | 工作时间 / 完成时间 × 100% |
| 整体利用率 | 所有机器平均利用率 | 总工作时间 / (Makespan × 机器数) × 100% |

## 🔍 问题排查

### 如果批处理/离散工序仍未显示

**检查步骤**：

1. **查看控制台输出**：
```
  ✓ 甘特图已保存
    - 打印工序: X 个
    - 批处理工序: Y 个  ← 检查是否为0
    - 离散工序: Z 个    ← 检查是否为0
```

2. **如果批处理工序为0**：
   - 检查 `RandomKeyEvaluator` 中批处理工序的记录逻辑
   - 确认 `chromosome.operationMatrix[partIdx][1]` 是否正确赋值

3. **如果离散工序为0**：
   - 检查问题数据是否包含离散工序（operCount > 2）
   - 确认离散工序的 `machineNo` 是否正确计算

### 如果字体仍显示为方框

**解决方案**：

1. 确认系统已安装 `Microsoft YaHei` 字体
2. 如果没有，可以替换为其他字体：
```java
Font titleFont = new Font("SimHei", Font.BOLD, 16);  // 黑体
// 或
Font titleFont = new Font("SimSun", Font.BOLD, 16);  // 宋体
```

## 📈 性能分析建议

### 利用机器运行时间统计

**1. 识别瓶颈机器**：
- 利用率接近100%的机器可能是瓶颈
- 需要增加该类型机器数量

**2. 发现闲置资源**：
- 利用率很低的机器说明资源过剩
- 可以减少该类型机器数量

**3. 优化调度策略**：
- 批处理利用率低 → 考虑增大批次大小
- 离散机利用率低 → 考虑调整工序分配策略

**4. 对比不同算法**：
- 比较混合GA和随机密钥GA的机器利用率
- 分析哪种算法的资源利用更合理
