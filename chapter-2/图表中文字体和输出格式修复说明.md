# 图表中文字体和输出格式修复说明

## 🎯 修复内容

### 1. 图表中文乱码修复

**问题**：迭代曲线图和批次布局图中的中文显示为乱码（方框）

**原因**：没有设置正确的中文字体

**修复方案**：参考原版`ScheduleVisualizer`和`PrinterLayoutVisualizer`，添加`setChineseFont`方法

---

## 🔧 修复详情

### 1. 添加`setChineseFont`方法

参考原版实现，在`RandomKeyVisualizer.java`末尾添加：

```java
/**
 * 设置中文字体（参考原版ScheduleVisualizer）
 */
private void setChineseFont(JFreeChart chart) {
    // 设置标题字体
    Font titleFont = new Font("宋体", Font.BOLD, 18);
    chart.getTitle().setFont(titleFont);
    
    // 设置轴标签字体
    Font labelFont = new Font("宋体", Font.PLAIN, 14);
    Font tickFont = new Font("宋体", Font.PLAIN, 12);
    
    if (chart.getPlot() instanceof XYPlot) {
        XYPlot plot = (XYPlot) chart.getPlot();
        plot.getDomainAxis().setLabelFont(labelFont);
        plot.getRangeAxis().setLabelFont(labelFont);
        plot.getDomainAxis().setTickLabelFont(tickFont);
        plot.getRangeAxis().setTickLabelFont(tickFont);
    }
}
```

**字体选择**：使用"宋体"（与原版一致）
- ✅ Windows系统自带
- ✅ 支持中文显示
- ✅ 与原版算法一致
