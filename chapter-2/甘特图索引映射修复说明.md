# 甘特图索引映射修复说明

## 🎯 问题描述

用户修改了`BLFPacker`，将`PlaceItem.name`从局部索引改为原始`Item.name`，导致`RandomKeyEvaluator`中的索引解析失败，甘特图输出错误。

---

## 🔍 问题分析

### 用户的修改（BLFPacker.java）

```java
// 在packSingleBatch方法中
if (placedItem != null) {
    // 先用局部索引标记已放置
    int idx = Integer.parseInt(placedItem.name);  // placedItem.name = "0", "1", "2"...
    packed[idx] = true;
    packedCount++;

    // ✨ 用户修改：将PlaceItem.name改为原始Item.name
    placedItem.name = items[idx].name;  // items[idx].name = "J0", "J1", "J2"...
    placedItems.add(placedItem);
    
    // ...
}
```

**影响**：
- `PlaceItem.name`原本存储局部索引（"0", "1", "2"...）
- 现在存储原始Item名称（"J0", "J1", "J2"...）

---

### 原有代码的问题（RandomKeyEvaluator.java）

```java
// ❌ 旧代码：尝试将Item.name解析为整数
for (PlaceItem placeItem : batch.placeItemList) {
    int localIdx = Integer.parseInt(placeItem.name);  // ❌ 失败！"J0"无法解析为int
    if (localIdx < machinePartSequence.size()) {
        int partIdx = machinePartSequence.get(localIdx);
        
        // 记录打印工序...
    }
}
```

**错误**：
- `placeItem.name`现在是"J0"、"J1"等，无法用`Integer.parseInt`解析
- 导致运行时异常：`NumberFormatException`

---

## 🔧 修复方案

### 核心思路

使用**HashMap**建立`Item.name → 全局索引`的映射，替代直接解析整数。

---

### 修复1：创建Item name到全局索引的映射

```java
// 在每台机器的嵌套处理中
for (int i = 0; i < machinePartSequence.size(); i++) {
    int partIdx = machinePartSequence.get(i);
    machineParts[i] = items[partIdx];
    orientations[i] = chromosome.getOrientation(partIdx);
    rotations[i] = chromosome.partRotations[partIdx];
    
    // ✅ 建立Item name到全局索引的映射
    itemNameToGlobalIndex.put(items[partIdx].name, partIdx);
}
```

**说明**：
- `items[partIdx].name`：原始Item名称（如"J0"）
- `partIdx`：全局零件索引（0, 1, 2...）
- 映射关系：{"J0" → 0, "J1" → 1, "J2" → 2, ...}

---

### 修复2：使用映射获取全局索引

```java
// ✅ 新代码：通过Item name查找全局索引
for (PlaceItem placeItem : batch.placeItemList) {
    // 通过Item name获取全局索引
    Integer partIdx = itemNameToGlobalIndex.get(placeItem.name);
    
    if (partIdx != null) {
        // 记录打印工序
        Operation printOp = chromosome.operationMatrix[partIdx][0];
        printOp.jobNo = partIdx;
        printOp.task = 0;  // 打印工序
        printOp.machineNo = machineIndex;
        printOp.startTime = batch.startTime;
        printOp.endTime = batch.endTime;
        printOp.id = "J" + partIdx + "T0";
    }
}
```

**优点**：
- ✅ 支持任意Item name格式（不限于整数）
- ✅ 代码更健壮（通过`partIdx != null`检查）
- ✅ 与用户修改兼容

---

### 修复3：修复BatchInfo构造函数

**原有问题**：

```java
// ❌ 旧代码：仍然尝试解析整数
public BatchInfo(int machineNo, Solution batch, List<Integer> partIndices) {
    this.partIndices = new ArrayList<>();
    
    for (PlaceItem pi : batch.placeItemList) {
        int idx = Integer.parseInt(pi.name);  // ❌ 失败！
        if (idx < partIndices.size()) {
            this.partIndices.add(partIndices.get(idx));
        }
    }
}
```

**修复方案**：

```java
// ✅ 新代码：使用映射获取全局索引
public BatchInfo(int machineNo, Solution batch, Map<String, Integer> itemNameToGlobalIndex) {
    this.machineNo = machineNo;
    this.batch = batch;
    this.partIndices = new ArrayList<>();
    
    // 从batch中提取零件的全局索引（通过Item name映射）
    for (PlaceItem pi : batch.placeItemList) {
        Integer globalIdx = itemNameToGlobalIndex.get(pi.name);
        if (globalIdx != null) {
            this.partIndices.add(globalIdx);
        }
    }
    
    this.endTime = batch.endTime;
}
```

**调用方式更新**：

```java
// ❌ 旧调用
batchQueue.add(new BatchInfo(machineNo, batch, machinePartSequence));

// ✅ 新调用
batchQueue.add(new BatchInfo(machineNo, batch, itemNameToGlobalIndex));
```

## 📝 关键技术点

### 1. HashMap映射

```java
Map<String, Integer> itemNameToGlobalIndex = new HashMap<>();
```

**用途**：将Item name（字符串）映射到全局索引（整数）

**优势**：
- O(1)查找时间
- 支持任意字符串格式
- 代码更健壮

---

### 2. 去重检查

```java
if (!machineJobs.get(machineIdx).contains(jobInfo)) {
    machineJobs.get(machineIdx).add(jobInfo);
}
```

**原因**：同一个工件可能有多个工序在同一台机器上加工，避免重复记录。

---

### 3. 格式化输出

```java
String jobInfo = String.format("J%d[%.2f-%.2f]", op.jobNo, op.startTime, op.endTime);
```

**效果**：清晰显示工件编号和时间区间
