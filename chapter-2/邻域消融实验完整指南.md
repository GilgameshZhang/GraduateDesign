## 实验目的

本实验旨在**细粒度地验证混合局部搜索策略中5种邻域算子的各自贡献度**，包括：

- ✅ 确定每个邻域策略的独立贡献
- ✅ 识别最重要的邻域策略
- ✅ 分析邻域策略之间的协同效应
- ✅ 为算法改进提供数据支持

**与基础消融实验的区别**：

| 实验类型 | 测试内容 | 实验组数 | 用途 |
|---------|---------|---------|------|
| **基础消融实验** | 局部搜索整体 + 启发式初始化 | 4组 | 验证两个主要创新策略 |
| **邻域消融实验** | N1、N2、N3、N4、N5 | 7组 | 深入分析局部搜索的细节 |

## 邻域策略说明

混合局部搜索策略包含5种互补的邻域算子：

### N1: 基于打印时间的跨机移动

**作用阶段**：打印段  
**优化目标**：平衡打印机负载，减少打印瓶颈  
**策略**：
- 从打印完工时间最长的机器中选择零件
- 使用轮盘赌选择（高度越高权重越大）
- 移动到打印完工时间最短的机器

**适用场景**：打印时间差异大的算例

---

### N2: 基于面积占用率的跨机移动

**作用阶段**：打印段  
**优化目标**：优化打印平台空间利用率  
**策略**：
- 从面积占用率高的机器中选择零件
- 使用轮盘赌选择（面积越大权重越大）
- 移动到面积占用率低的机器

**适用场景**：打印平台空间紧张的算例

---

### N3: 相邻批次交换

**作用阶段**：打印段  
**优化目标**：优化批次顺序，减少等待时间  
**策略**：
- 在同一打印机上交换相邻批次
- 评估交换后的makespan改进
- 首次改进策略

**适用场景**：批次数量多的算例

---

### N4: 关键块首尾相邻工序交换

**作用阶段**：离散处理段  
**优化目标**：优化关键路径，减少makespan  
**策略**：
- 识别关键路径上的关键块
- 交换关键块首尾的相邻工序
- 评估对makespan的影响

**适用场景**：离散处理时间占比大的算例

**理论基础**：基于JSP的经典邻域结构（Van Laarhoven & Aarts, 1992）

---

### N5: 关键工序机器重分配

**作用阶段**：离散处理段  
**优化目标**：重新分配关键工序到更快的机器  
**策略**：
- 识别关键路径上的工序
- 使用轮盘赌选择关键工序（处理时间越长权重越大）
- 尝试分配到可用的备选机器

**适用场景**：机器性能差异大的算例

## 实验设计

### 实验组配置（7组）

| 组号 | 实验组名称 | N1 | N2 | N3 | N4 | N5 | 作用 |
|-----|-----------|----|----|----|----|----|----|
| 1 | **完整算法** | ✓ | ✓ | ✓ | ✓ | ✓ | **基线** |
| 2 | 无N1 | ✗ | ✓ | ✓ | ✓ | ✓ | 测试N1贡献 |
| 3 | 无N2 | ✓ | ✗ | ✓ | ✓ | ✓ | 测试N2贡献 |
| 4 | 无N3 | ✓ | ✓ | ✗ | ✓ | ✓ | 测试N3贡献 |
| 5 | 无N4 | ✓ | ✓ | ✓ | ✗ | ✓ | 测试N4贡献 |
| 6 | 无N5 | ✓ | ✓ | ✓ | ✓ | ✗ | 测试N5贡献 |
| 7 | **无局部搜索** | ✗ | ✗ | ✗ | ✗ | ✗ | **对照组** |

### 实验参数

- **算例**：建议选择中等规模（J50或J100系列）
- **运行次数**：每组10次（消除随机性）
- **终止条件**：统一的时间限制（如30-60秒）
- **其他参数**：种群规模、交叉率、变异率保持一致

### 评估指标

- **平均Makespan**：主要指标
- **标准差**：衡量稳定性
- **变异系数(CV)**：相对稳定性
- **最优/最差值**：算法鲁棒性
- **与基线差异**：贡献度百分比

- 📊 **N4最重要**（关键块交换），贡献2.35%
- 📊 **N5次之**（机器重分配），贡献2.07%
- 📊 **N1-N3**也有显著贡献


**解读**：
- ✅ 如果协同效应 > 0：各邻域策略有正协同效应，联合使用效果更佳
- ⚠️ 如果协同效应 ≈ 0：各邻域策略独立作用
- 📝 如果协同效应 < 0：各邻域策略有一定的重复作用（正常现象）

## 统计显著性检验

### 为什么需要？

- ✅ 证明差异不是偶然的
- ✅ 满足顶级期刊/会议的要求
- ✅ 增强结果的科学性

### 使用Python脚本

可以创建一个统计检验脚本：

```python
import scipy.stats as stats
import numpy as np

# 从实验报告中提取10次makespan数据
full = [832.10, 838.50, 842.30, 848.20, 850.10, 852.40, 855.60, 858.30, 862.10, 865.40]
no_n1 = [848.50, 852.30, 858.40, 862.50, 865.30, 868.20, 872.10, 875.50, 878.90, 882.10]
no_n2 = [840.20, 845.30, 850.40, 854.60, 858.40, 862.30, 866.20, 870.10, 873.50, 875.30]
no_n3 = [845.00, 850.20, 855.30, 859.40, 862.50, 866.30, 870.50, 874.20, 877.80, 880.20]
no_n4 = [852.30, 858.50, 863.20, 867.40, 870.20, 874.30, 878.60, 882.40, 885.70, 888.50]
no_n5 = [850.50, 856.30, 861.40, 865.20, 867.80, 871.50, 875.40, 879.30, 882.80, 885.60]

# 配对t检验

print(f"N4贡献显著性: t={t4:.3f}, p={p4:.6f}")

all_data = full + no_n1 + no_n2 + no_n3 + no_n4 + no_n5
groups = ['full']*10 + ['no_n1']*10 + ['no_n2']*10 + ['no_n3']*10 + ['no_n4']*10 + ['no_n5']*10
f_stat, p_anova = stats.f_oneway(full, no_n1, no_n2, no_n3, no_n4, no_n5)
print(f"\nANOVA: F={f_stat:.3f}, p={p_anova:.6f}")
```

## 常见问题

### Q1: 需要运行多少次？

**建议**：
- **快速验证**：5次（不推荐用于论文）
- **论文标准**：10-20次 ⭐
- **高要求**：30次以上

### Q2: 如果某个邻域策略贡献很小怎么办？

如果贡献度 < 1%：
- ✅ 检查代码实现是否正确
- ✅ 该策略可能在特定算例上贡献小（正常现象）
- ✅ 诚实报告结果，说明该策略适用场景有限
- ✅ 考虑在不同规模/特征的算例上测试

### Q3: 可以测试邻域策略的组合吗？

可以！例如：
- N1+N2（仅打印段优化）vs N4+N5（仅离散段优化）
- 打印段优化（N1+N2+N3）的总贡献
- 离散段优化（N4+N5）的总贡献

但这会增加实验量。

### Q4: 实验时间太长怎么办？

- ✅ 减少运行次数到5次（快速验证）
- ✅ 选择更小规模的算例（J20或J50）
- ✅ 增加多线程数（如果CPU和内存充足）
- ✅ 减少终止时间（如从60秒降到30秒）

### Q5: 如何确定哪个邻域策略最重要？

1. **看贡献度百分比**：去除后性能下降最多的最重要
2. **看统计显著性**：p值最小的最显著
3. **看实际应用场景**：根据问题特征选择

### 1. 不同规模算例的对比

在J20、J50、J100上分别测试，观察邻域策略的贡献是否随规模变化：

| 算例规模 | N1 | N2 | N3 | N4 | N5 | 趋势 |
