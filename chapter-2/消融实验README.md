# 消融实验 (Ablation Study) - README

> 验证局部搜索策略和启发式初始化策略有效性的完整实验框架

---

## 📖 什么是消融实验？

消融实验通过**逐步移除算法组件**，观察性能变化，从而**证明各组件的有效性和贡献度**。

简单来说：
- 🔧 **完整算法** = 所有创新策略 ✓
- ❌ **移除局部搜索** = 观察性能下降多少？
- ❌ **移除启发式初始化** = 观察性能下降多少？
- ❌❌ **基础GA** = 全部移除，性能下降多少？

---

## 🎯 本实验验证什么？

### 两个核心创新策略：

1. **🧠 启发式初始化策略**
   - 基于负载均衡的种群初始化
   - 目标：生成高质量初始解

2. **🔍 混合局部搜索策略**
   - 5种邻域算子 (N1-N5)
   - 打印段 + 离散段综合优化

### 实验组设计：

| 实验组 | 启发式初始化 | 局部搜索 | 作用 |
|--------|-------------|---------|------|
| **完整算法** | ✓ | ✓ | 基线 |
| 无局部搜索 | ✓ | ✗ | 证明局部搜索贡献 |
| 无启发式初始化 | ✗ | ✓ | 证明初始化贡献 |
| **基础GA** | ✗ | ✗ | 对照组 |

## 📊 期望结果示例

### 结果表格

```
实验组              平均Makespan   标准差    与基线差异
-----------------------------------------------------------
完整算法            850.23        12.45     +0.00%      ← 基线
无局部搜索          920.56        15.32     +8.27%      ← ⬆️
无启发式初始化      885.40        13.80     +4.14%      ← ⬆️
基础GA              975.80        18.90     +14.77%     ← ⬆️⬆️
```

### 解读

✅ **局部搜索贡献 ≈ 8%** - 去掉后性能下降8.27%  
✅ **初始化贡献 ≈ 4%** - 去掉后性能下降4.14%  
✅ **联合贡献 ≈ 15%** - 都去掉后性能下降14.77%  
✅ **协同效应** - 15% > 8% + 4%，说明两者配合有额外增益

## ⚠️ 注意事项

### ✅ 运行前检查

- [ ] 确认算例文件路径正确
- [ ] 确认终止时间设置合理（建议30-60秒）
- [ ] 确认有足够的磁盘空间（约200MB）
- [ ] 确认所有代码已编译无误

### ⚠️ 常见问题

**Q: 编译错误 - 找不到符号 `enableLocalSearch`**
```
A: 确保 GAParameters.java 已更新，包含消融实验开关字段
```

**Q: 运行时间太长怎么办？**
```
A: 减少运行次数到5次，或选择更小的算例（J20而非J50）
```

**Q: 贡献度很小（<2%）怎么办？**
```
A: 1) 检查代码实现是否正确
   2) 增加运行次数以降低随机性
   3) 如果确实贡献小，诚实报告
```

**Q: 标准差很大（CV>10%）**
```
A: 增加运行次数到20-30次
```
