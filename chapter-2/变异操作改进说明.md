# 变异操作改进说明

## 📋 改进概述

将原有的简单随机交换变异改进为**结构化的双层变异策略**，针对打印阶段和离散处理阶段采用不同的变异方式，更符合问题特性。

---

## 🎯 新变异策略设计

### 策略框架

```
变异操作
├── 工序变异 (50% 概率)
│   ├── 打印阶段工序逆序 (50%)
│   └── 离散阶段工序逆序 (50%) + 修复
└── 机器变异 (50% 概率)
    ├── 打印阶段机器重分配 (50%)
    └── 离散阶段机器重分配 (50%)
```

## 🔄 工序变异（Sequence Mutation）

### 1. 打印阶段工序逆序

**操作**：选择一段打印工序（2-6个元素），进行逆序排列

**特点**：
- **同步逆序**：`gene_OS` 和 `gene_MS` 同步逆序
- **无需修复**：打印工序之间没有顺序约束

**示例**：

```
变异前：
gene_OS: [J0, J1, J2, J3, J4, ...]  (打印段)
gene_MS: [P0, P1, P2, P0, P1, ...]

选择逆序段：位置 1-3 (J1, J2, J3)

变异后：
gene_OS: [J0, J3, J2, J1, J4, ...]  ← 逆序
gene_MS: [P0, P0, P2, P1, P1, ...]  ← 同步逆序
```

**代码实现**：

```java
private void mutatePrintSequenceReverse(Chromosome chromosome) {
    // 1. 找到打印段范围
    // 2. 随机选择逆序段 (长度2-6)
    // 3. 同步逆序 OS 和 MS
    reverseSegment(os, start, end);
    reverseSegment(ms, start, end);
}
```

---

### 2. 离散阶段工序逆序

**操作**：选择一段离散工序进行逆序，然后**修复**以保证工序约束

**特点**：
- **需要修复**：离散工序有前后依赖关系
- **约束保持**：修复后每个工件的工序顺序合法

**示例**：

```
变异前：
gene_OS: [... | J0(Op1), J1(Op1), J0(Op2), J1(Op2), J0(Op3) ]  (离散段)
gene_MS: [... | M0,      M1,      M0,      M1,      M0     ]

选择逆序段：位置 1-3 (J1(Op1), J0(Op2), J1(Op2))

逆序后（未修复）：
gene_OS: [... | J0(Op1), J1(Op2), J0(Op2), J1(Op1), J0(Op3) ]  ← J1的Op2在Op1前面！
gene_MS: [... | M0,      M1,      M0,      M1,      M0     ]

修复后：
gene_OS: [... | J0(Op1), J1(Op1), J0(Op2), J1(Op2), J0(Op3) ]  ← 修复顺序
gene_MS: [... | M0,      M1,      M0,      M1,      M0     ]
```

**修复算法**：

```java
private void repairDiscreteSequence(Chromosome chromosome) {
    // 多轮扫描，直到没有违反约束的工序
    while (有违反约束的工序) {
        for (每个工序位置 i) {
            for (后续位置 j > i) {
                if (同一工件 && j的工序号 < i的工序号) {
                    交换(i, j);  // 同时交换OS和MS
                }
            }
        }
    }
}
```

## 🔧 机器变异（Machine Mutation）

### 1. 打印阶段机器重分配

**操作**：选择一个工件，将其打印工序重新分配到**能放下它的**其他打印机

**约束**：
- 新机器的打印平台尺寸 ≥ 工件尺寸
- `itemLength ≤ printerLength`
- `itemWidth ≤ printerWidth`

**示例**：

```
工件 J0: 长度=100, 宽度=80

可行打印机：
- P0: 长度=150, 宽度=100  ✓ 可以放下
- P1: 长度=120, 宽度=90   ✓ 可以放下
- P2: 长度=80,  宽度=80   ✗ 长度不够

当前分配: J0 → P0

变异后:   J0 → P1 (随机选择)
```

**代码实现**：

```java
private void mutatePrintMachineReassignment(Chromosome chromosome) {
    // 1. 随机选择工件
    // 2. 获取工件尺寸
    // 3. 找到所有能放下该工件的打印机
    List<Integer> feasiblePrinters = new ArrayList<>();
    for (PrintMachine pm : printMachines) {
        if (item.length <= pm.length && item.width <= pm.width) {
            feasiblePrinters.add(pm.id);
        }
    }
    // 4. 随机选择一个可行打印机（不同于当前）
    ms[position] = newMachine;
}
```

### 2. 离散阶段机器重分配

**操作**：选择一个工件的某道离散工序，重新分配到其**可加工的**其他机器

**约束**：
- 新机器必须在该工序的可选机器集合中
- 从 `availableMachineMatrix[taskIndex]` 中选择

**示例**：

```
工件 J0 的第2道工序 (Op2):

可选机器（从算例文件读取）：
- M0, M1, M3

当前分配: J0(Op2) → M0

变异后:   J0(Op2) → M3 (随机选择)
```

**代码实现**：

```java
private void mutateDiscreteMachineReassignment(Chromosome chromosome) {
    // 1. 随机选择工件
    // 2. 随机选择该工件的一道离散工序
    // 3. 获取该工序的可选机器列表
    Machine[] availableMachines = job.availableMachineMatrix[taskIndex];
    // 4. 随机选择一个可行机器（不同于当前）
    ms[position] = newMachine;
}
```

## 🎨 变异效果对比

### 旧版本（简单随机交换）

```java
// 随机交换两个位置

int pos2 = random();

swap(ms[pos1], ms[pos2]);
```

**问题**：
- ❌ 容易破坏解的结构

- ❌ 不考虑问题特性

### 新版本（结构化变异）

```java
// 根据阶段特性选择变异方式
if (工序变异) {
    if (打印阶段) {
        逆序一段 + 同步MS;  // 充分利用打印段无约束特性

        逆序一段 + 修复;     // 尊重离散段的工序约束
    }
} else {
    if (打印阶段) {
        重分配到可行打印机;  // 考虑尺寸约束
    } else {
        重分配到可加工机器;  // 考虑工艺约束
    }
}
```

**优势**：
- ✅ 针对性强
- ✅ 保持解的合法性
- ✅ 更符合问题特性
- ✅ 探索效果更好

## 🔍 关键技术细节

### 1. 逆序段长度选择

```java
int segmentLength = r.nextInt(Math.min(totalLength, 5)) + 2;
```

- **最小长度**: 2（至少交换2个元素才有意义）
- **最大长度**: min(总长度, 6)
- **原因**: 避免过度破坏解的结构

### 2. 修复算法收敛性

```java
int maxIterations = 100;  // 防止无限循环
while (changed && iteration < maxIterations) {
    // 冒泡式修复
}
```

- **最大迭代**: 100次
- **提前退出**: 没有交换时停止
- **时间复杂度**: O(n²) × 迭代次数

### 3. 可行性检查

**打印机器分配**：
```java
if (itemLength <= pm.length && itemWidth <= pm.width) {
    feasible = true;
}
```

**离散机器分配**：
```java
Machine[] available = job.availableMachineMatrix[taskIndex];
if (contains(available, targetMachine)) {
    feasible = true;
}
```

## 🎓 理论支持

### 1. 逆序操作的优势

- **Block Move**: 逆序相当于一次移动多个相邻元素
- **邻域扩展**: 比单点交换探索更广的邻域
- **保持局部性**: 同一段内的元素仍然相邻

### 2. 约束修复 vs. 约束预防

**修复策略** (当前实现):
```
生成 → 检查 → 修复
```
- 优点：简单、通用
- 缺点：可能需要多次修复

**预防策略** (可选优化):
```
检查 → 生成 → 验证
```
- 优点：不产生非法解
- 缺点：实现复杂

### 3. 多样性维持

4种变异方式确保：
- **基因型多样性**: OS 和 MS 都会变化
- **表现型多样性**: 打印批次和加工顺序都会改变
- **搜索空间覆盖**: 不同区域都能探索到
