### 2. 修改 `ChromosomeOperation.java` - 支持邻域独立控制

**位置**: `src/main/java/AlgorthmFrame/ga/ChromosomeOperation.java`

**修改内容**: 在 `LocalSearch()` 方法中添加邻域策略的开关检查

**实现逻辑**:
```java
for (int iter = 0; iter < maxIterations; iter++) {
    int neighborhoodType = iter % 5;
    
    if (neighborhoodType == 0 || neighborhoodType == 1) {
        // 检查N1或N2是否启用
        boolean enableN1 = (params != null) ? params.enableN1 : true;
        boolean enableN2 = (params != null) ? params.enableN2 : true;
        
        // 如果当前邻域被禁用，则跳过
        if ((neighborhoodType == 0 && !enableN1) || (neighborhoodType == 1 && !enableN2)) {
            continue;
        }
        // ... N1/N2的执行逻辑
    } else if (neighborhoodType == 2) {
        // 检查N3是否启用
        boolean enableN3 = (params != null) ? params.enableN3 : true;
        if (!enableN3) {
            continue;
        }
        // ... N3的执行逻辑
    } 
    // ... N4和N5类似
}
```

**优点**:
- ✅ 向后兼容：如果`params`为null，默认启用所有策略
- ✅ 灵活控制：可以任意组合N1-N5
- ✅ 性能优化：禁用的策略会被跳过，不会执行

## 📊 实验流程

```
┌─────────────────────────────────────────────────────────────┐
│                    邻域消融实验流程                          │
└─────────────────────────────────────────────────────────────┘

1. 配置参数
   ├── 算例路径
   ├── 运行次数
   └── 线程数

2. 运行7组实验
   ├── 完整算法 (N1+N2+N3+N4+N5) ← 基线
   ├── 无N1 (N2+N3+N4+N5)
   ├── 无N2 (N1+N3+N4+N5)
   ├── 无N3 (N1+N2+N4+N5)
   ├── 无N4 (N1+N2+N3+N5)
   ├── 无N5 (N1+N2+N3+N4)
   └── 无局部搜索 ← 对照组

3. 统计分析
   ├── 平均makespan
   ├── 标准差
   ├── 变异系数
   ├── 最优/最差值
   └── 与基线差异

4. 计算贡献度
   ├── N1贡献 = (无N1平均 - 完整平均) / 完整平均
   ├── N2贡献 = (无N2平均 - 完整平均) / 完整平均
   ├── N3贡献 = (无N3平均 - 完整平均) / 完整平均
   ├── N4贡献 = (无N4平均 - 完整平均) / 完整平均
   └── N5贡献 = (无N5平均 - 完整平均) / 完整平均

5. 重要性排序
   └── 按贡献度从高到低排序

6. 协同效应分析
   ├── 单独贡献度之和
   ├── 实际联合贡献
   └── 协同效应 = 实际 - 理论

7. 生成报告和图表
   ├── 文本报告 (.txt)
   ├── 对比柱状图 (.png)
   └── 箱线图 (.png)
```

## ⚠️ 注意事项

### 1. 实验时间
- 7组×10次=70次运行
- 每次如果30秒，总时间约35-40分钟（多线程加速）
- 建议在性能较好的机器上运行

### 2. 结果解释
- 贡献度是相对值（百分比）
- 不同算例的贡献度可能不同
- 小贡献度（<1%）也可能是显著的

### 3. 统计检验
- 建议进行配对t检验
- 证明差异不是随机波动
- 满足顶级期刊的要求
