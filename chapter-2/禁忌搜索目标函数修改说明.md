### 修改前的目标函数

```java
/**
 * 计算适应度值
 * 目标：最小化分批数和打印时间
 */
private double calculateFitness(List<Solution> solutions) {
    if (solutions == null || solutions.isEmpty()) {
        return Double.MAX_VALUE;
    }
    
    // 计算总的打印时间和浪费率
    double totalTime = 0.0;
    double totalWasteRate = 0.0;
    
    for (Solution solution : solutions) {
        // 打印时间 = 准备时间 + 层高相关的打印时间
        double printTime = printMachine.prepareTime + 
                         printMachine.reCoatingTime * solution.maxG / printMachine.printH;
        totalTime += printTime;
        
        // 浪费率 = 1 - 利用率
        totalWasteRate += (1.0 - solution.rate);
    }
    
    // ❌ 适应度 = 总时间 + 惩罚项（平均浪费率）
    double avgWasteRate = totalWasteRate / solutions.size();
    return totalTime + avgWasteRate * 100.0;
}
```

**问题**：
- 目标函数包含两项：总时间 + 浪费率惩罚
- 浪费率惩罚项的权重是人为设定的（100.0）
- 可能导致优化方向不明确

### 修改后的目标函数

```java
/**
 * 计算适应度值
 * 目标：最小化该打印机器的完工时间（makespan）
 * 完工时间 = 所有批次的打印时间总和
 */
private double calculateFitness(List<Solution> solutions) {
    if (solutions == null || solutions.isEmpty()) {
        return Double.MAX_VALUE;
    }
    
    // 计算该打印机器的完工时间（所有批次顺序执行）
    double makespan = 0.0;
    
    for (Solution solution : solutions) {
        // 打印时间 = 准备时间 + 层高相关的打印时间
        double printTime = printMachine.prepareTime + 
                         printMachine.reCoatingTime * solution.maxG / printMachine.printH;
        makespan += printTime;
    }
    
    // ✓ 适应度 = 完工时间（越小越好）
    return makespan;
}
```

**改进**：
- ✅ 目标明确：最小化完工时间
- ✅ 没有人为权重，更加客观
- ✅ 与整体调度目标一致（最小化makespan）

## 🔍 原理说明

### 完工时间（Makespan）的定义

对于单台打印机：
```
Makespan = Σ (每个批次的打印时间)

其中，每个批次的打印时间 = prepareTime + reCoatingTime × maxG / printH
```

**解释**：
- 批次是**顺序执行**的（一个批次完成后才能开始下一个）
- 完工时间 = 第一个批次时间 + 第二个批次时间 + ... + 最后一个批次时间
- 这就是该打印机完成所有零件的总时间

### 为什么不考虑浪费率？

**修改前**：
- 目标 = 完工时间 + 浪费率惩罚
- 试图同时优化两个目标

**问题**：
1. **权重难以确定**
   - 浪费率的权重设为100，为什么是100？
   - 如果改为50或200，结果会不同
   - 没有理论依据

2. **可能偏离主要目标**
   - 主要目标应该是完工时间
   - 浪费率是次要考虑
   - 加入惩罚项可能找到次优解

3. **浪费率已经间接影响了完工时间**
   - 浪费率高 → 需要更多批次
   - 更多批次 → 完工时间更长
   - 所以优化完工时间会自然地降低浪费率

**修改后**：
- 目标 = 完工时间
- 单一明确的优化目标
- 浪费率作为装箱算法的自然结果

## 💡 理论依据

### 单目标vs多目标优化

**单目标优化**（修改后）：
```
min f(x) = makespan(x)

优点：
- 目标明确，易于理解
- 优化方向清晰
- 结果可预测
```

**多目标优化**（修改前）：
```
min f(x) = α·makespan(x) + β·wasteRate(x)

问题：
- α和β如何确定？
- 两个目标可能冲突
- 需要权衡取舍
```

### Pareto最优

如果真的需要同时考虑完工时间和浪费率，应该使用多目标优化方法（如Pareto前沿），而不是简单地加权求和。

但对于当前问题：
- **主要目标**：最小化makespan
- **次要考虑**：浪费率（通过装箱算法自然处理）
- **结论**：单目标优化足够
