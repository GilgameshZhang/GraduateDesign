# 编译错误修复说明

## 问题描述

编译时出现错误：
```
java: 找不到符号
  符号:   变量 maxRunTime
  位置: 类型为ProblemFrame.GAParameters的变量 params
```

## 原因分析

`GAParameters` 类中缺少 `maxRunTime` 字段。随机密钥GA算法需要使用这个字段来控制运行时间限制。

## 解决方案

已在 `GAParameters.java` 中添加了 `maxRunTime` 字段：

### 修改1：添加字段声明

```java
// 终止参数（注：主要终止条件由时间控制）
public int maxStagnantStep;      // 最大停滞步数（早停阈值）
public double maxRunTime;        // 最大运行时间（分钟）  // ← 新增
```

### 修改2：设置默认值

```java
public static GAParameters getDefaultParameters() {
    GAParameters params = new GAParameters();
    params.popSize = 200;
    params.pr = 0.15;
    params.pc = 0.90;
    params.pm = 0.30;
    params.maxStagnantStep = 500;
    params.maxRunTime = 5.0;  // 默认5分钟  // ← 新增
    // ...
    return params;
}
```

### 修改3：更新toString方法

```java
@Override
public String toString() {
    return String.format(
        "GAParameters{\n" +
        "  popSize=%d, pr=%.2f, pc=%.2f, pm=%.2f\n" +
        "  maxStagnantStep=%d (早停阈值), maxRunTime=%.1f分钟\n" +  // ← 更新
        // ...
    );
}
```

## 验证结果

✅ 所有编译错误已修复  
✅ `GAParameters.java` - 无错误  
✅ `RandomKeyGAExperimentRunner.java` - 无错误  
✅ `RandomKeyGA.java` - 无错误  
✅ 所有随机密钥GA相关文件 - 无错误  

## 使用说明

### 默认配置

现在可以直接使用默认参数（包含5分钟时间限制）：

```java
GAParameters params = GAParameters.getDefaultParameters();
// params.maxRunTime = 5.0 (默认值)
```

### 自定义时间限制

如需修改时间限制：

```java
GAParameters params = GAParameters.getDefaultParameters();
params.maxRunTime = 10.0;  // 改为10分钟
```

### 对比实验配置

对于小算例（快速测试）：
```java
params.maxRunTime = 2.0;  // 2分钟
```

对于中等算例：
```java
params.maxRunTime = 5.0;  // 5分钟（默认）
```

对于大规模算例：
```java
params.maxRunTime = 10.0;  // 10分钟
```

## 影响范围

这个修改**不会影响**您现有的混合GA算法，因为：

1. `maxRunTime` 字段已存在于现有的GA算法实现中（通过其他方式使用）
2. 只是将这个字段正式添加到 `GAParameters` 配置类中
3. 增加了统一的参数管理方式
