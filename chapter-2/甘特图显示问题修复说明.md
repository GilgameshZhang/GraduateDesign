# 甘特图显示问题修复说明

## 问题描述

在甘特图坐标反转后，出现了两个显示问题：

### 问题1：机器名字被坐标挡住
- 机器标签（如"打印机1"、"批处理机1"等）显示在Y轴左侧
- 但标签位置太靠近Y轴，被坐标线或刻度挡住了一部分
- 导致标签文字不完整，无法清楚识别机器名称

### 问题2：批次号标签格式错误
- 打印机和批处理机上的标签显示为`B120`
- 这个格式不清晰，无法区分是"1号机器第20批次"还是"12号机器第0批次"
- 需要在机器号和批次号之间添加明确的分隔符

## 解决方案

### 修复1：增加机器标签的左侧空间

**修改前：**
```java
// 添加机器标签在Y轴上
for (int machineIdx = 0; machineIdx < machineCount; machineIdx++) {
    XYTextAnnotation machineLabel = new XYTextAnnotation(
        machineNames[machineIdx],
        minTime - (maxTime - minTime) * 0.08,  // X位置偏移8%
        machineIdx
    );
    plot.addAnnotation(machineLabel);
}

// 设置X轴范围
double timePadding = (maxTime - minTime) * 0.1;  // 左右各留10%
plot.getDomainAxis().setRange(minTime - timePadding, maxTime + timePadding);
```

**修改后：**
```java
// 设置X轴范围（先设置范围，再添加标签）
double timePadding = (maxTime - minTime) * 0.15;  // 增加到15%
plot.getDomainAxis().setRange(minTime - timePadding, maxTime + timePadding);

// 添加机器标签在Y轴上
double labelXPosition = minTime - (maxTime - minTime) * 0.12;  // 增加到12%
for (int machineIdx = 0; machineIdx < machineCount; machineIdx++) {
    XYTextAnnotation machineLabel = new XYTextAnnotation(
        machineNames[machineIdx],
        labelXPosition,  // 使用更大的偏移量
        machineIdx
    );
    plot.addAnnotation(machineLabel);
}
```

**改进点：**
- 增加X轴左侧padding从10%到15%，留出更多空间
- 增加机器标签的X偏移量从8%到12%
- 调整代码顺序，先设置X轴范围，再添加标签（更符合逻辑）

### 修复2：批次号标签添加分隔符

**修改前：**
```java
// 打印机和批处理机：B机器号批次号
int machineNumber = getMachineNumber(op.machineNo);
label = "B" + machineNumber + batchNumber;
// 结果：B120（无法区分是B1-20还是B12-0）
```

**修改后：**
```java
// 打印机和批处理机：B机器号-批次号（用'-'分隔）
int machineNumber = getMachineNumber(op.machineNo);
label = "B" + machineNumber + "-" + batchNumber;
// 结果：B1-20 或 B12-0（清晰明确）
```

**改进点：**
- 在机器号和批次号之间添加`-`分隔符
- 标签格式更清晰，易于识别

## 其他说明

### 为什么选择"-"作为分隔符？

- **清晰性**：减号在视觉上很容易识别
- **简洁性**：只占用一个字符，不会让标签过长
- **可读性**：符合常见的编号格式习惯
- **兼容性**：不会与其他符号冲突

### 如果标签仍然重叠怎么办？

如果在工序很多的情况下，标签可能重叠，可以：

1. 调整字体大小：
   ```java
   textLabel.setFont(new Font("宋体", Font.BOLD, 8));  // 从10改为8
   ```

2. 增加图表宽度：
   ```java
   ChartUtils.saveChartAsPNG(new File(outputPath), chart, 1600, 800);  // 从1200改为1600
   ```

3. 只在矩形较宽时显示标签：
   ```java
   if (width > 100) {  // 只有足够宽的矩形才显示标签
       plot.addAnnotation(textLabel);
   }
   ```
