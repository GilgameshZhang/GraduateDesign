# 迭代曲线图功能说明

## 功能概述

添加了迭代曲线图功能，用于可视化遗传算法每一代的最优makespan变化趋势，帮助分析算法的收敛性能。

## 功能特点

### 1. 数据收集
- 自动记录每一代（包括第0代初始种群）的最优makespan
- 存储在`bestMakespanHistory`列表中
- 无需手动干预，完全自动化

### 2. 图表展示
- **横轴（X轴）**：迭代次数（代数），从0开始
- **纵轴（Y轴）**：最优Makespan值
- **曲线**：蓝色实线，带数据点标记
- **分辨率**：1920x1080高清
- **中文支持**：标题、轴标签使用中文显示

### 3. 自动生成
- 在算法结束后自动生成
- 与甘特图、打印机布局图一起保存
- 保存路径：`visualization_results/iteration_curve.png`

**新增方法`generateIterationCurve()`：**
```java
private void generateIterationCurve(String outputPath) throws IOException {
    System.out.println("生成迭代曲线图...");
    
    // 创建数据集
    org.jfree.data.xy.XYSeries series = new org.jfree.data.xy.XYSeries("最优Makespan");
    for (int i = 0; i < bestMakespanHistory.size(); i++) {
        series.add(i, bestMakespanHistory.get(i));
    }
    
    org.jfree.data.xy.XYSeriesCollection dataset = new org.jfree.data.xy.XYSeriesCollection();
    dataset.addSeries(series);
    
    // 创建图表
    JFreeChart chart = ChartFactory.createXYLineChart(
        "遗传算法迭代曲线图",
        "迭代次数（代数）",
        "最优Makespan",
        dataset,
        PlotOrientation.VERTICAL,
        true, true, false
    );
    
    // 获取绘图区域并设置样式
    XYPlot plot = (XYPlot) chart.getPlot();
    plot.setBackgroundPaint(Color.WHITE);
    plot.setDomainGridlinePaint(Color.LIGHT_GRAY);
    plot.setRangeGridlinePaint(Color.LIGHT_GRAY);
    
    // 设置线条样式
    org.jfree.chart.renderer.xy.XYLineAndShapeRenderer renderer = 
        new org.jfree.chart.renderer.xy.XYLineAndShapeRenderer();
    renderer.setSeriesPaint(0, Color.BLUE);
    renderer.setSeriesStroke(0, new BasicStroke(2.0f));
    renderer.setSeriesShapesVisible(0, true);  // 显示数据点
    plot.setRenderer(renderer);
    
    // 设置轴范围
    plot.getDomainAxis().setRange(-1, bestMakespanHistory.size());
    double minMakespan = bestMakespanHistory.stream().min(Double::compare).orElse(0.0);
    double maxMakespan = bestMakespanHistory.stream().max(Double::compare).orElse(1.0);
    double padding = (maxMakespan - minMakespan) * 0.1;
    plot.getRangeAxis().setRange(minMakespan - padding, maxMakespan + padding);
    
    // 设置中文字体
    setChineseFont(chart);
    
    // 保存图表
    ChartUtils.saveChartAsPNG(new File(outputPath), chart, 1920, 1080);
    System.out.println("迭代曲线图已保存: " + outputPath);
}
```

```
最优Makespan

      |          *
```

**曲线特点：**
- 初始阶段：makespan快速下降（算法快速收敛）
- 中期阶段：makespan缓慢下降（算法持续优化）
- 后期阶段：makespan趋于平稳（算法收敛到最优解附近）

## 图表分析

### 1. 收敛速度分析

**快速收敛：**
```
Makespan
    ↑
    |*
    |  *
    |    **____________________
    └─────────────────────> Generation
```
- 前几代快速下降
- 说明初始种群质量好或问题相对简单

**缓慢收敛：**
```
Makespan
    ↑
    |*
    | *
    |  *
    |   *
    |    *
    |     *__________________
    └─────────────────────> Generation
```
- 持续缓慢下降
- 说明问题复杂或需要更多迭代

### 2. 停滞现象

**早期停滞：**
```
Makespan
    ↑
    |*___________________________
    |
    └─────────────────────> Generation
```
- 可能陷入局部最优
- 建议：增加种群多样性、调整变异概率

**正常收敛：**
```
Makespan
    ↑
    |*
    | *
    |  *
    |   *____________________
    └─────────────────────> Generation
```
- 逐步优化后趋于稳定
- 说明算法正常工作

### 3. 振荡现象

**轻微振荡：**
```
Makespan
    ↑
    |*  *
    | *  *
    |  *  *________________
    └─────────────────────> Generation
```
- 正常现象，由遗传算法的随机性引起
- 整体趋势向下即可

**剧烈振荡：**
```
Makespan
    ↑
    |* * *
    | * * *
    |  * * *
    └─────────────────────> Generation
```
- 可能参数设置不当
- 建议：降低变异概率、增加精英保留

迭代曲线图的数据点对应控制台输出：

```
[初始种群统计]
  最优makespan: 330122.10 (fitness: 302.92)   ← 代数0的数据点
  ...

After 0 generation, the best fitness is:302.92 (makespan: 330122.10), ...  ← 代数0
After 1 generation, the best fitness is:309.85 (makespan: 322735.53), ...  ← 代数1
After 2 generation, the best fitness is:312.91 (makespan: 319582.25), ...  ← 代数2
...
After 200 generation, the best schedule cost is:251147.14                   ← 代数200
```

每一行的`makespan`值对应曲线图上的一个数据点。

## 数据完整性

### 包含的数据点

- **第0代**：初始种群的最优makespan
- **第1-199代**：每一代迭代后的最优makespan
- **总计**：200+1 = 201个数据点（如果maxGen=200）

### 数据一致性

- 迭代曲线图的每个数据点都是**全局最优解**
- 曲线**单调不增**（或保持不变）
- 最后一个数据点等于最终输出的`best schedule cost`

## 性能影响

### 内存占用
- 存储201个double值：约1.6 KB
- 几乎可忽略不计

### 计算开销
- 每代添加一个数据点：O(1)操作
- 绘图时间：约0.5-1秒
- 总体影响极小

## 故障排查

### 问题1：图表未生成

**检查：**
1. 确认`bestMakespanHistory`不为空
2. 查看控制台是否有异常信息
3. 检查`visualization_results/`目录权限

**解决：**
```bash
# 检查目录是否存在
ls visualization_results/

# 如果不存在，手动创建
mkdir visualization_results
```

### 问题2：曲线不正常

**检查：**
1. 确认makespan数据是否正确
2. 检查是否有负数或异常值

**解决：**
- 在控制台输出中查看每一代的makespan
- 确认算法逻辑正确

### 问题3：中文显示乱码

**检查：**
- 系统字体是否支持中文
- `setChineseFont()`方法是否正确调用

**解决：**
```java
// 确保设置了中文字体
Font titleFont = new Font("宋体", Font.BOLD, 18);
chart.getTitle().setFont(titleFont);
```
