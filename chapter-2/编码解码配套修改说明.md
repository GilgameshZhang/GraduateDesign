# 编码解码配套修改说明

## 修改日期
2025-12-22

## 修改概述

将GA算法的编码和解码方式进行了配套修改，实现了**基于工件工序号的相对索引编码**方式。

---

## 核心改进：相对索引编码

### 原有编码方式（绝对机器编号）
```
离散工序的gene_MS[i]直接存储实际机器编号（1-based）
例如：gene_MS[10] = 5 表示该工序分配给机器M5
```

### 新编码方式（相对索引）
```
离散工序的gene_MS[i]存储可选机器集合中的相对索引（1-based）
例如：
  工件1工序2的可选机器：[M3, M5, M7]
  gene_MS[10] = 1 → 选择第1个可选机器 → M3
  gene_MS[10] = 2 → 选择第2个可选机器 → M5
  gene_MS[10] = 3 → 选择第3个可选机器 → M7
```

### 优势
1. **自动满足约束**：相对索引永远在有效范围内
2. **简化交叉变异**：不需要复杂的约束检查
3. **提高搜索效率**：避免生成无效解
4. **更好的编码表达**：直接反映工序的机器选择偏好

```java
private void mutateDiscreteOperation(Chromosome chromosome, int pos, int jobNo, 
                                     double[][] proDesMatrix, int[][] operationToIndex) {
    int jobCount = input.getJobCount();
    
    // 计算工序编号
    int operNo = 2;
    for (int j = jobCount; j < pos; j++) {
        if (chromosome.gene_OS[j] == jobNo) {
            operNo++;
        }
    }
    
    if (operNo >= operationToIndex[jobNo].length) {
        return;
    }
    int operIdx = operationToIndex[jobNo][operNo];
    
    // 找到所有可用机器及其加工时间
    List<Integer> availableMachines = new ArrayList<>();
    List<Double> processingTimes = new ArrayList<>();
    
    for (int k = 0; k < proDesMatrix[operIdx].length; k++) {
        if (proDesMatrix[operIdx][k] > 0 && proDesMatrix[operIdx][k] != Double.MAX_VALUE) {
            availableMachines.add(k + 1);
            processingTimes.add(proDesMatrix[operIdx][k]);
        }
    }
    
    if (availableMachines.isEmpty()) {
        return;
    }
    
    // 50%选择加工时间最短的，50%随机选择
    int selectedRelativeIndex;
    if (r.nextDouble() < 0.5) {
        // 选择加工时间最短的机器
        int minTimeIndex = 0;
        double minTime = processingTimes.get(0);
        for (int i = 1; i < processingTimes.size(); i++) {
            if (processingTimes.get(i) < minTime) {
                minTime = processingTimes.get(i);
                minTimeIndex = i;
            }
        }
        selectedRelativeIndex = minTimeIndex + 1;  // ✅ 转换为1-based相对索引
    } else {
        // 随机选择一个机器
        int randomIndex = r.nextInt(availableMachines.size());
        selectedRelativeIndex = randomIndex + 1;  // ✅ 转换为1-based相对索引
    }
    
    // ✅ 存储相对索引而不是绝对机器编号
    chromosome.gene_MS[pos] = selectedRelativeIndex;
}
```

## 编码方式对比

### 打印工序段（gene_OS[0] 到 gene_OS[jobCount-1]）
- **gene_OS[i]**：工件编号（0-based）
- **gene_MS[i]**：**绝对机器编号**（1-based，1到printMachineCount）
- **原因**：打印机数量固定，直接使用绝对编号更简单

### 离散工序段（gene_OS[jobCount] 到 gene_OS[length-1]）
- **gene_OS[i]**：工件编号（0-based）
- **gene_MS[i]**：**相对索引**（1-based，1到该工序可选机器数量）
- **原因**：每个工序的可选机器不同，使用相对索引更灵活

## 注意事项

### 1. 打印工序 vs 离散工序
- **打印工序**：使用绝对机器编号（1到printMachineCount）
- **离散工序**：使用相对索引（1到该工序可选机器数量）
- **不要混淆**：在处理gene_MS时要区分是打印段还是离散段

### 2. 索引转换
- **相对索引**：1-based（1, 2, 3, ...）
- **数组索引**：0-based（0, 1, 2, ...）
- **转换公式**：`arrayIndex = relativeIndex - 1`

### 3. 可选机器列表
- 每次需要解码时都要重新构建可选机器列表
- 不能缓存，因为不同工序的可选机器不同

### 4. 错误处理
- 如果相对索引超出范围，自动修复为1
- 输出详细的调试信息便于排查问题
