```bash

mvn compile
mvn exec:java -Dexec.mainClass="AblationExperimentRunner"
```

## ⚠️ 常见问题速查

### ❓ 编译错误

**问题**：找不到符号 `enableLocalSearch`

**解决**：确保GAParameters.java已更新，包含这两行：
```java
public boolean enableLocalSearch;
public boolean enableHeuristicInit;
```

---

### ❓ 运行时间太长

**解决方案**：
```java
int numberOfRuns = 5;  // 改为5次（快速测试）
```
或选择更小的算例（如J20而非J50）

---

### ❓ 结果不稳定（标准差很大）

**解决方案**：
```java
int numberOfRuns = 20;  // 增加到20次
```

---

### ❓ 贡献度太小（<2%）

**可能原因**：
1. 代码实现有问题（检查GA.java中的if判断）
2. 该策略确实贡献较小（诚实报告）
3. 随机性影响（增加运行次数）
