# 甘特图坐标反转修改说明

## 修改内容

对甘特图的显示方式进行了调整，主要包括：

### 1. 横纵坐标反转

**修改前：**
- 横轴（X轴）：机器编号
- 纵轴（Y轴）：时间

**修改后：**
- 横轴（X轴）：时间
- 纵轴（Y轴）：机器编号

这样更符合传统甘特图的显示习惯，时间从左到右流动。

### 2. 机器标签显示

**修改前：**
- 机器标签显示在X轴下方

**修改后：**
- 机器标签显示在Y轴左侧
- 格式：`打印机1`、`批处理机1`、`离散处理机1`等

### 3. 批次号标注改进

**修改前：**
- 打印机和批处理机的批次号固定为"1"

**修改后：**
- 批次号从1开始递增
- 按照时间顺序，每个工序都有独立的批次号
- 标签格式：`B<机器号><批次号>`
- 示例：`B11`（1号机器第1批次）、`B12`（1号机器第2批次）

### 4. 标签位置优化

**修改前：**
- 标签在矩形正中央

**修改后：**
- 标签靠近坐标轴侧（即矩形左侧）
- 位置：`x + width * 0.1`（距离左边缘10%宽度）
- 这样更容易识别每个批次的起始位置

### 主要修改点

#### 1. `generateGanttChart()` 方法

```java
// X轴和Y轴标签交换
JFreeChart chart = ChartFactory.createScatterPlot(
    "调度甘特图",
    "时间",    // 原来是 "机器"
    "机器",    // 原来是 "时间"
    ...
);

// Y轴范围设置（机器轴）
plot.getRangeAxis().setRange(-0.5, machineCount - 0.5);

// X轴范围设置（时间轴）
plot.getDomainAxis().setRange(minTime - timePadding, maxTime + timePadding);

// 机器标签添加到Y轴左侧
XYTextAnnotation machineLabel = new XYTextAnnotation(
    machineNames[machineIdx],
    minTime - (maxTime - minTime) * 0.08,  // X位置（靠近Y轴左侧）
    machineIdx  // Y位置（机器位置）
);
```

#### 2. `drawOperationRectangle()` 方法

```java
// 添加批次号参数
private void drawOperationRectangle(XYPlot plot, Operation op, int machineIdx, int batchNumber)

// X和Y坐标交换
double x = op.startTime;      // 原来是 machineIdx - 0.3
double y = machineIdx - 0.3;  // 原来是 op.startTime
double width = op.endTime - op.startTime;  // 原来是 0.6
double height = 0.6;          // 原来是 op.endTime - op.startTime

// 批次号使用传入的参数
label = "B" + machineNumber + batchNumber;

// 标签位置靠近坐标轴侧
XYTextAnnotation textLabel = new XYTextAnnotation(
    label,
    x + width * 0.1,  // 靠近左侧（坐标轴侧）
    y + height / 2    // 垂直居中
);
```

#### 3. 批次号计数逻辑

```java
// 在遍历每台机器的工序时，维护批次计数器
int batchCounter = 1;
for (Operation op : machineOperations) {
    drawOperationRectangle(plot, op, machineIdx, batchCounter);
    // 只有打印机和批处理机才增加批次计数
    if (isPrintMachine(op.machineNo) || isBatchMachine(op.machineNo)) {
        batchCounter++;
    }
}
```

## 注意事项

1. **批次号含义**：
   - 批次号从1开始，按照时间顺序分配
   - 每台打印机/批处理机有独立的批次计数器
   - 离散处理机不使用批次号，显示工件号

2. **标签位置**：
   - 标签靠近矩形左侧（坐标轴侧）
   - 如果矩形太小，标签可能重叠，可以调整字体大小

3. **图表尺寸**：
   - 图表尺寸为 1920x1080（1080p Full HD）
   - 提供高清晰度的显示效果
