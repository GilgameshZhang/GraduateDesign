# 消融实验使用说明

## 📖 什么是消融实验 (Ablation Study)

消融实验是一种科学验证方法，通过**逐步移除算法的组件**，观察性能变化，从而证明各组件的**有效性和贡献度**。

在机器学习和优化算法论文中，消融实验是**证明创新点有效性的重要手段**。

---

## 🎯 本研究的消融实验设计

### 验证目标

本研究提出了两个创新策略：
1. **启发式初始化策略** - 基于负载均衡的种群初始化
2. **混合局部搜索策略** - 5种邻域算子的组合搜索

消融实验通过对比**有/无这些策略**的性能差异，证明它们的贡献。

### 实验组设计

| 实验组 | 启发式初始化 | 局部搜索 | 说明 |
|--------|-------------|---------|------|
| **完整算法** | ✓ | ✓ | 完整版本（基线Baseline） |
| **无局部搜索** | ✓ | ✗ | 验证局部搜索的贡献 |
| **无启发式初始化** | ✗ | ✓ | 验证初始化策略的贡献 |
| **基础GA** | ✗ | ✗ | 最简版本（对照组） |

### 实验设置

- **每组运行次数**: 10次（消除随机性影响）
- **算例选择**: 建议选择中等规模算例（如J20、J50系列）
- **终止条件**: 统一的时间限制
- **记录指标**: 
  - 平均Makespan
  - 标准差
  - 变异系数
  - 最优值/最差值

## 🚀 如何运行消融实验

### 1. 配置实验参数

打开 `src/test/java/AblationExperimentRunner.java`，修改：

```java
// 测试算例路径
String instancePath = "你的算例路径";
String instanceName = "J20P3B2D5_01";

// 每组运行次数
int numberOfRuns = 10;  // 建议10-30次
```

### 2. 运行实验

直接运行 `AblationExperimentRunner.main()` 方法。

程序会自动：
- 依次运行4组实验
- 每组运行10次（可配置）
- 自动保存所有结果
- 生成对比图表
- 生成统计报告

### 3. 查看结果

所有结果保存在：
```
src/main/resources/result/消融实验/
├── 完整算法_run1_HHMMSS/
│   ├── 实验报告.txt
│   ├── 收敛曲线图.png
│   ├── 甘特图.png
│   └── 打印布局图*.png
├── 完整算法_run2_HHMMSS/
├── ...（每次运行一个文件夹）
├── 无局部搜索_run1_HHMMSS/
├── ...
└── 消融实验总结_算例名/
    ├── 消融实验报告.txt         ← 核心报告
    ├── 消融实验对比柱状图.png    ← 平均值对比
    └── 消融实验箱线图.png        ← 分布对比
```

```
为验证所提出的启发式初始化策略和混合局部搜索策略的有效性，

(1) 完整算法 - 包含所有提出的策略；
(2) 无局部搜索 - 移除混合局部搜索模块；
(3) 无启发式初始化 - 采用随机初始化替代启发式初始化；
(4) 基础GA - 移除所有提出的策略，仅保留基本遗传算法框架。

每组实验在算例J20P3B2D5上运行10次，记录平均Makespan。
```

### 2. 结果分析部分

```
表X展示了消融实验结果。可以看出：

(1) 局部搜索策略的贡献：与"完整算法"相比，"无局部搜索"组的
    平均Makespan增加了8.27%，说明混合局部搜索策略能有效改善
    解的质量。

(2) 启发式初始化策略的贡献："无启发式初始化"组比"完整算法"
    的Makespan增加了4.14%，证明基于负载均衡的启发式初始化能
    生成更高质量的初始种群。

(3) 联合贡献："基础GA"组的性能最差，比"完整算法"差14.77%，
    说明两种策略的联合使用具有显著的协同效应。

上述结果充分证明了本文所提策略的有效性。
```

### 3. 统计显著性检验（可选）

报告中建议进行的统计检验：

#### 配对t检验 (Paired t-test)
```python
# Python示例
from scipy import stats

full = [850.2, 852.1, ...]  # 完整算法的10次结果
no_ls = [920.5, 918.3, ...] # 无局部搜索的10次结果

t_stat, p_value = stats.ttest_rel(full, no_ls)
print(f"t统计量={t_stat:.4f}, p值={p_value:.4f}")

# 如果p < 0.05，说明差异显著
```

在论文中写：
```
配对t检验表明，"完整算法"与"无局部搜索"组之间存在
显著差异(t=-8.234, p<0.001)，证实了局部搜索策略的
统计显著性。
```

## 🔧 高级用法

### 1. 修改实验组配置

如果你想测试其他组合（例如只测试单个邻域算子的贡献），可以修改 `AblationExperimentRunner.java`：

```java
// 添加新的实验组
AblationConfig[] configs = {
    new AblationConfig("完整算法", "全部策略", true, true),
    new AblationConfig("仅N1N2", "只用打印段邻域", true, true),
    // 需要在ChromosomeOperation中添加更细粒度的开关
};
```

### 2. 多算例对比

可以在main方法中循环多个算例：

```java
String[] instances = {
    "J20P3B2D5_01",
    "J50P5B4D10_01",
    "..."
};

for (String inst : instances) {
    // 运行消融实验
    ...
}
```

### 3. 调整运行次数

根据时间和精度需求：
- **快速验证**: 5次
- **论文标准**: 10-20次
- **高精度**: 30次以上

## ⚠️ 注意事项

1. **随机种子控制**：
   - 如需完全可重复，在GA构造函数中取消注释 `r.setSeed(1)`
   - 但注意：固定种子会降低统计说服力

2. **时间成本**：
   - 4组 × 10次 = 40次实验
   - 每次如果跑30秒，总时间约20分钟
   - 建议先用小算例快速验证

3. **对比公平性**：
   - 确保所有组使用**相同的终止条件**
   - 相同的种群规模、交叉/变异概率等基础参数

4. **结果解读**：
   - 如果某组件贡献度<2%，可能不够显著
   - 如果标准差很大（CV>10%），建议增加运行次数
