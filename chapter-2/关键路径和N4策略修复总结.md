# 关键路径和N4策略修复总结

## 修复内容

### 1. 修复`findOperationPosition`方法（适配新编码方式）

#### 问题分析

旧代码直接比较`ms[i] == machineNo + 1`，但这在新编码方式下完全错误：

```java
// ❌ 旧代码（错误）
if (count == discreteOperCount && ms[i] == machineNo + 1) {
    return i;
}
```

**为什么错误？**
- 新编码方式下，离散工序的MS存储的是**相对索引**（1-based）
- `ms[i]`表示该工序在其可选机器列表中的位置（相对索引）
- `machineNo`是实际的机器编号（1-based）
- 两者完全不可比！

#### 新的解决方案

```java
/**
 * 在gene_OS中找到指定工序的位置（适配新编码方式）
 * 
 * 查找策略：
 * 1. 在OS中找到该工件的第N个离散工序
 * 2. 通过MS固定位置解码实际机器编号
 * 3. 验证机器编号是否匹配
 */
private int findOperationPosition(Operation op, int[] os, int[] ms, int jobCount) {
    // 步骤1：在OS中定位
    int discreteOperIndex = operNo - 2;
    int count = 0;
    int positionInOS = -1;
    for (int i = jobCount; i < os.length; i++) {
        if (os[i] == jobNo) {
            if (count == discreteOperIndex) {
                positionInOS = i;
                break;
            }
            count++;
        }
    }
    
    // 步骤2：计算MS固定位置并解码
    int msIndex = jobCount;
    for (int j = 0; j < jobNo; j++) {
        msIndex += (input.getOperationCountArr()[j] - 2);
    }
    msIndex += discreteOperIndex;
    
    // 步骤3：获取可选机器列表
    int relativeIndex = ms[msIndex];
    List<Integer> availableMachines = getAvailableMachines(operIdx);
    
    // 步骤4：解码实际机器编号
    int actualMachineNo = availableMachines.get(relativeIndex - 1);
    
    // 步骤5：验证匹配
    if (actualMachineNo == targetMachineNo) {
        return positionInOS;
    }
    
    return -1;
}
```

### 2. 将N4改为交换块首和块尾两相邻工序

#### 新的N4策略

```java
/**
 * N4邻域：生成关键块首尾相邻工序交换的候选
 * 
 * 策略：识别关键路径和关键块，交换块首和块尾两相邻工序
 * - 块首交换：交换块的第一个工序和第二个工序
 * - 块尾交换：交换块的倒数第二个工序和最后一个工序
 */
```

#### 生成候选逻辑

```java
for (CriticalBlock block : criticalBlocks) {
    if (block.operationPositions.size() < 2) continue;
    
    // 候选1：交换块首两相邻工序
    int headPos1 = block.operationPositions.get(0);
    int headPos2 = block.operationPositions.get(1);
    int jobNo1 = os[headPos1];
    int jobNo2 = os[headPos2];
    
    if (isSwapFeasible(headPos1, headPos2, jobNo1, jobNo2, os, ms, jobCount)) {
        moves.add(new CriticalBlockMove(headPos1, headPos2));
    }
    
    // 候选2：交换块尾两相邻工序
    int tailPos1 = block.operationPositions.get(size - 2);
    int tailPos2 = block.operationPositions.get(size - 1);
    int jobNo3 = os[tailPos1];
    int jobNo4 = os[tailPos2];
    
    if (isSwapFeasible(tailPos1, tailPos2, jobNo3, jobNo4, os, ms, jobCount)) {
        moves.add(new CriticalBlockMove(tailPos1, tailPos2));
    }
}
```

#### isSwapFeasible方法（新增）

```java
/**
 * 操作前约束筛选：检查工序交换的可行性
 * 
 * 检查维度：
 * 1. 直接优先级约束：同一工件只能交换相邻工序
 * 2. 间接优先级约束：不同工件可以自由交换
 */
private boolean isSwapFeasible(int pos1, int pos2, int jobNo1, int jobNo2, 
                                int[] os, int[] ms, int jobCount) {
    if (jobNo1 == jobNo2) {
        // 同一工件：找到所有工序位置
        List<Integer> jobOperationPositions = new ArrayList<>();
        for (int i = jobCount; i < os.length; i++) {
            if (os[i] == jobNo1) {
                jobOperationPositions.add(i);
            }
        }
        
        int index1 = jobOperationPositions.indexOf(pos1);
        int index2 = jobOperationPositions.indexOf(pos2);
        
        // 只能交换相邻工序
        if (Math.abs(index1 - index2) != 1) {
            return false;
        }
    }
    
    // 不同工件可以自由交换
    return true;
}
```

#### applyCriticalBlockMove方法（修改为交换）

```java
/**
 * 应用关键块移动：交换两个相邻工序
 */
private void applyCriticalBlockMove(Chromosome chromosome, CriticalBlockMove move) {
    move.saveOriginal(chromosome.gene_OS, chromosome.gene_MS);
    int[] ms = chromosome.gene_MS;
    int[] os = chromosome.gene_OS;
    int pos1 = move.fromPosition;
    int pos2 = move.toPosition;
    
    if (pos1 == pos2) return;
    
    // 交换gene_OS中的两个工序
    int tempJob = os[pos1];
    os[pos1] = os[pos2];
    os[pos2] = tempJob;
    
    // 交换gene_MS中的两个机器分配
    int tempMachine = ms[pos1];
    ms[pos1] = ms[pos2];
    ms[pos2] = tempMachine;
    
    chromosome.printSolution = null;
}
```

## 工作原理示例

### 示例1：findOperationPosition查找

```
要查找：工件2的工序3，机器M5

步骤1：在OS中找工件2的第2个离散工序（operNo-2=1）
OS: [1, 0, 2, | 0, 1, 2, 0, 1, 2, ...]
         打印段 |    离散段
工件2在离散段出现：位置5（第0次），位置8（第1次）
→ 返回位置8

步骤2：计算MS固定位置
msIndex = 3 + (工件0离散数) + (工件1离散数) + 1
        = 3 + 2 + 3 + 1 = 9

步骤3：获取相对索引
MS[9] = 3

步骤4：获取可选机器列表
工件2工序3的可选机器 = [M3, M4, M5, M7]

步骤5：解码
relativeIndex = 3 → availableMachines[2] = M5 ✓

步骤6：验证
actualMachineNo = 5 == targetMachineNo = 5 → 返回位置8
```
