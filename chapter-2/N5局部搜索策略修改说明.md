# N5局部搜索策略修改说明

## 修改概述

将N5邻域从**"复合邻域（修改机器分配和工序顺序）"**改为**"基于轮盘赌的机器重分配（只修改MS相对索引）"**策略。

## 核心策略

1. **识别关键路径**：找到所有关键路径上的离散处理加工任务
2. **轮盘赌选择**：对可选机器根据加工时间进行轮盘赌选择
   - 加工时间短的机器被选中概率高
   - 权重计算：`weight = (maxTime - time + 1)`
3. **修改MS相对索引**：由于离散工序的MS使用固定顺序编码，直接修改MS中的相对索引即可

### 2. selectMachineByRoulette方法（新增）

实现轮盘赌选择逻辑：

```java
/**
 * 轮盘赌选择机器（基于加工时间，时间短权重大）
 * 
 * @param availableMachines 可选机器列表（实际机器ID）
 * @param processingTimes 对应的加工时间列表
 * @return 选中的相对索引（1-based，在availableMachines中的位置+1）
 */
private int selectMachineByRoulette(List<Integer> availableMachines, List<Double> processingTimes) {
    // 找到最大加工时间
    double maxTime = Double.NEGATIVE_INFINITY;
    for (double time : processingTimes) {
        if (time > maxTime) maxTime = time;
    }
    
    // 计算权重：weight = (maxTime - time + 1)
    // 使得时间短的机器权重大
    List<Double> weights = new ArrayList<>();
    double totalWeight = 0;
    for (double time : processingTimes) {
        double weight = (maxTime - time + 1);
        weights.add(weight);
        totalWeight += weight;
    }
    
    // 轮盘赌选择
    double randomValue = r.nextDouble() * totalWeight;
    double cumulativeWeight = 0;
    
    for (int i = 0; i < weights.size(); i++) {
        cumulativeWeight += weights.get(i);
        if (randomValue <= cumulativeWeight) {
            return i + 1;  // 返回相对索引（1-based）
        }
    }
    
    return weights.size();  // 默认返回最后一个
}
```

### 3. applyMachineReassignment方法

简化为只修改MS中的相对索引：

```java
/**
 * 应用机器重分配：只修改gene_MS中的相对索引，不移动工序位置
 * 
 * @param chromosome 染色体
 * @param move 机器重分配移动（包含MS位置和新的相对索引）
 */
private void applyMachineReassignment(Chromosome chromosome, MachineReassignmentMove move) {
    move.saveOriginal(chromosome.gene_OS, chromosome.gene_MS);
    
    int[] ms = chromosome.gene_MS;
    int msIndex = move.operationPosition;  // MS中的固定位置
    int newRelativeIndex = move.newMachine;  // 新的相对索引
    
    // 直接修改MS中的相对索引
    ms[msIndex] = newRelativeIndex;
    
    chromosome.printSolution = null;  // 清空装箱结果
}
```

## 工作原理示例

假设关键路径上有一个工序：

```
工件2的工序3（离散工序）
当前机器：M5
可选机器：M3, M4, M5, M6
加工时间：[10, 15, 12, 8]

步骤1：排除当前机器M5
可选机器：M3, M4, M6
加工时间：[10, 15, 8]

步骤2：计算权重（maxTime=15）
M3权重 = 15-10+1 = 6
M4权重 = 15-15+1 = 1
M6权重 = 15-8+1 = 8
总权重 = 15

步骤3：轮盘赌选择
- M3被选中概率 = 6/15 = 40%
- M4被选中概率 = 1/15 = 6.7%
- M6被选中概率 = 8/15 = 53.3%  （加工时间最短，概率最高）

步骤4：假设选中M6（相对索引=3）
计算MS中的固定位置：
msIndex = jobCount + (工件0的离散工序数) + (工件1的离散工序数) + (工件2工序3的偏移)
        = jobCount + Σ(前面工件的离散工序数) + (3-2)

步骤5：修改MS[msIndex] = 3（M6在可选机器[M3,M4,M6]中的相对位置）
```

## 优势

1. **简单高效**：不涉及工序位置移动，只修改MS中的相对索引
2. **符合编码方式**：与离散工序的固定顺序相对索引编码完全匹配
3. **智能选择**：轮盘赌保证了加工时间短的机器有更高概率被选中
4. **局部优化**：聚焦关键路径，针对性强
5. **操作原子性**：每次只修改一个MS值，撤销简单

## 注意事项

1. 只针对关键路径上的离散工序（task >= 2）
2. MS的固定索引计算必须准确（与编码方式一致）
3. 轮盘赌选择时排除当前机器，确保产生有效变化
4. 权重计算使用`(maxTime - time + 1)`避免零权重
5. 修改后需要清空printSolution缓存
