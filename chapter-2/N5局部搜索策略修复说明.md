# N5局部搜索策略修复说明

## 🔍 问题分析

旧版N5实现是一个**复合邻域**：
- 同时修改机器分配（MS）
- 同时移动工序位置（OS）

但用户要求的是：
- **只修改机器分配**
- **使用轮盘赌选择**（加工时间短的机器权重大）

## 📊 修复前后对比

### 修复前（复合邻域）

```java
// 1. 遍历所有可选机器
for (int newMachine : availableMachines) {
    // 2. 为每个机器找插入位置
    for (int insertPos : candidatePositions) {
        // 3. 生成移动（修改MS + 移动OS）
        moves.add(new Move(opPosition, currentMachine, newMachine, insertPos));
    }
}

// 应用移动：
applyMachineReassignment() {
    ms[opPos] = newMachine;  // 修改机器
    移动OS从opPos到insertPos;   // 移动工序位置
}
```

**问题**：
1. 不符合新编码方式（MS是固定顺序的）
2. 没有使用轮盘赌选择
3. 操作过于复杂（同时改变两个维度）

### 修复后（轮盘赌选择）

```java
// 1. 计算MS固定位置
int msIndex = jobCount;
for (int j = 0; j < jobNo; j++) {
    msIndex += (operationCountArr[j] - 2);
}
msIndex += (taskNo - 2);

// 2. 获取所有可选机器及加工时间

List<Double> candidateProcessingTimes;

// 4. 轮盘赌选择（时间短权重大）
int selectedIdx = selectMachineIndexByRoulette(candidateProcessingTimes);
int selectedRelativeIndex = candidateMachinesIdx.get(selectedIdx) + 1;

// 5. 生成移动（只修改MS）
moves.add(new Move(msIndex, ms[msIndex], selectedRelativeIndex, msIndex));

// 应用移动：
applyMachineReassignment() {
    ms[msIndex] = newRelativeIndex;  // 只修改MS
    // OS保持不变！
}
```

## 🎯 核心修复点

### 1. 正确计算MS固定位置

```java
// MS的固定顺序映射：
// MS[jobCount + 0] = 工件0工序2的相对索引
// MS[jobCount + 1] = 工件0工序3的相对索引
// MS[jobCount + 2] = 工件0工序4的相对索引
// MS[jobCount + 3] = 工件1工序2的相对索引
// ...

int msIndex = jobCount;
for (int j = 0; j < jobNo; j++) {
    msIndex += (input.getOperationCountArr()[j] - 2);
}
msIndex += (taskNo - 2);
```

### 2. 正确构建相对索引

```java
// 步骤1：获取所有可选机器（0-based）
List<Integer> allAvailableMachines = [M3, M4, M5, M7]  // 对应索引[3, 4, 5, 7]

// 步骤2：为每个机器分配相对索引（1-based）
相对索引1 → M3（索引3）
相对索引2 → M4（索引4）
相对索引3 → M5（索引5）
相对索引4 → M7（索引7）

// 步骤3：排除当前机器（假设当前是M4，索引4）
candidateMachinesIdx = [0, 2, 3]  // 在allAvailableMachines中的索引
candidateProcessingTimes = [t3, t5, t7]

// 步骤4：轮盘赌选择（假设选中第2个，即M5）
selectedIdx = 1
selectedMachineInAllList = candidateMachinesIdx[1] = 2
selectedRelativeIndex = 2 + 1 = 3  // M5的相对索引

// 步骤5：更新MS
ms[msIndex] = 3  // 存储相对索引
```

### 3. 轮盘赌选择算法

```java
private int selectMachineIndexByRoulette(List<Double> processingTimes) {
    // 1. 找到最大加工时间
    double maxTime = max(processingTimes);
    
    // 2. 计算权重（时间短权重大）
    for (double time : processingTimes) {
        weight = maxTime - time + 1;
        totalWeight += weight;
    }
    
    // 3. 轮盘赌选择
    double random = r.nextDouble() * totalWeight;
    double cumulative = 0;
    for (int i = 0; i < weights.size(); i++) {
        cumulative += weights[i];
        if (random <= cumulative) {
            return i;  // 返回选中的索引
        }
    }
}
```

**权重计算示例**：
```
加工时间：[10, 5, 8]
maxTime = 10

权重计算：
weight[0] = 10 - 10 + 1 = 1
weight[1] = 10 - 5 + 1 = 6  ← 时间短，权重大
weight[2] = 10 - 8 + 1 = 3
totalWeight = 10

选中概率：
P(M1) = 1/10 = 10%
P(M2) = 6/10 = 60%  ← 最短时间，最高概率
P(M3) = 3/10 = 30%
```

### 4. 只修改MS，不改变OS

```java
private void applyMachineReassignment(Chromosome chromosome, MachineReassignmentMove move) {
    int[] ms = chromosome.gene_MS;
    int msIndex = move.operationPosition;  // MS中的固定位置
    int newRelativeIndex = move.newMachine;  // 新的相对索引
    
    // ✅ 直接修改MS中的相对索引
    ms[msIndex] = newRelativeIndex;
    
    // ⚠️ OS不变！
    // N5只修改机器分配，不改变工序执行顺序
}
```

- 工件1：2道离散工序

                         M0 M1 M2 M3 M4 M5 M6 M7

相对索引：1,          2,          3,          4

### N5执行步骤

```
步骤1：计算MS固定位置
msIndex = 3 + (3个工件0离散) + (2个工件1离散) + 1
        = 3 + 3 + 2 + 1 = 9

步骤2：构建可选机器列表
allAvailableMachines = [3, 4, 5, 7]  (0-based索引)
allProcessingTimes = [8, 5, 9, 7]

步骤3：排除当前机器M4（索引4）
candidateMachinesIdx = [0, 2, 3]  // M3, M5, M7在列表中的位置
candidateProcessingTimes = [8, 9, 7]

步骤4：轮盘赌选择
maxTime = 9
weights = [9-8+1=2, 9-9+1=1, 9-7+1=3]
totalWeight = 6

概率分布：
P(M3) = 2/6 = 33.3%
P(M5) = 1/6 = 16.7%
P(M7) = 3/6 = 50%  ← M7时间最短，概率最高

假设选中M7（selectedIdx = 2）

步骤5：计算相对索引
selectedMachineInAllList = candidateMachinesIdx[2] = 3
selectedRelativeIndex = 3 + 1 = 4

步骤6：更新MS
ms[9] = 4  // 将工件2工序3的相对索引从2改为4（从M4换到M7）

// 工序执行顺序不改变，只是机器分配改变了
```

## ⚠️ 注意事项

### 与N4的区别

| 特性 | N4（关键块交换） | N5（机器重分配） |
|-----|----------------|----------------|
| 作用对象 | 关键块（同一机器的连续工序） | 关键路径上的单个工序 |
| 操作内容 | 交换OS中的两个工序位置 | 修改MS中的机器相对索引 |
| OS变化 | ✓ 改变工序执行顺序 | ✗ 保持不变 |
| MS变化 | ✗ 保持不变（固定顺序） | ✓ 改变机器分配 |
| 选择策略 | 相邻工序交换 | 轮盘赌选择新机器 |

### 与旧版N5的区别

| 特性 | 旧版N5（复合邻域） | 新版N5（轮盘赌） |
|-----|------------------|----------------|
| 操作维度 | 同时修改MS和OS | 只修改MS |
| 机器选择 | 遍历所有可选机器 | 轮盘赌选择一个 |
| 位置选择 | 查找插入位置 | 不移动位置 |
| 候选数量 | 多个（机器×位置） | 单个（每个工序一个） |
| 编码适配 | 不适配新编码 | 完全适配新编码 |

## 🎯 关键优势

1. **完全适配新编码**：直接操作MS的固定位置
2. **操作简单**：只修改一个值（MS中的相对索引）
3. **智能选择**：加工时间短的机器权重大
4. **约束友好**：不需要检查复杂的优先级约束
5. **高效执行**：O(1)的修改操作
