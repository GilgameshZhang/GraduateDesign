# 随机密钥遗传算法 (Random Key GA) - 对比算法

## 概述

这是一个独立的对比算法实现，用于与主算法（混合GA）进行性能对比。该算法采用随机密钥编码策略，融合改进的左下优先（BLF）嵌套启发式，专门针对增材制造中的零件嵌套与调度优化问题。

## 算法特点

### 1. 多子串随机密钥编码

染色体包含4个功能独立的子串：

- **零件序列子串**：[0,1]区间的随机密钥，解码后生成零件嵌套顺序
- **零件朝向子串**：整数1-3，代表3种可选朝向
- **旋转角度子串**：整数1-8，代表8种旋转角度（45°增量）
- **设备分配子串**：整数1-m，将零件分配到m台打印机

### 2. 遗传算子

- **交叉操作**：参数化均匀交叉（PUX）
  - 对每个基因位通过"掷硬币"决定继承父代1或父代2
  - 确保朝向、旋转、设备分配与零件序列同步
  
- **变异操作**：
  - 零件序列：随机替换随机密钥（仍在[0,1]区间）
  - 朝向/旋转/设备：随机替换为有效范围内的值
  
- **选择策略**：锦标赛选择（tournament size = 3）

- **精英保留**：每代最优10%直接进入下一代

### 3. 改进的BLF嵌套启发式

- 按染色体指定的零件序列依次嵌套
- 使用染色体指定的朝向和旋转角度
- 基于天际线（Skyline）算法实现左下优先放置
- 无法嵌套的零件自动转入下一批次
- 实现批次的动态生成

### 4. 队列调度

- **打印阶段**：多台打印机并行工作，按机器分配嵌套
- **批处理阶段**：共享批处理机器（支撑去除），FCFS策略
- **离散工序**：后续加工工序按顺序完成

## 使用方法

### 方式1：运行单个算例

```java
// 读取算例
Input input = new Input(new File("path/to/instance.txt"));
Problem problem = input.getProblemDesFromFile();

// 配置参数
GAParameters params = GAParameters.getDefaultParameters();

// 创建并运行算法
RandomKeyGA ga = new RandomKeyGA(problem, params);
RandomKeyGA.RandomKeySolution solution = ga.solve();

// 输出结果
System.out.println("最优Makespan: " + solution.cost);
```

### 方式2：运行对比实验

直接运行 `RandomKeyGAExperimentRunner.java`：

```bash
# 编译
javac RandomKeyGAExperimentRunner.java

# 运行
java RandomKeyGAExperimentRunner
```

实验将自动：
1. 扫描所有算例（J10, J20, J50, J100）
2. 每个算例运行10次
3. 多线程并行加速
4. 生成详细结果和汇总统计表

## 算法参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 种群大小 | 100 | 每代个体数量 |
| 交叉率 | 0.8 | 交叉操作概率 |
| 变异率 | 0.1 | 变异操作概率 |
| 精英比例 | 10% | 直接进入下一代的最优个体比例 |
| 最大停滞代数 | 50 | 连续无改进则终止 |
| 最大运行时间 | 5分钟 | 时间限制 |

## 与主算法的区别

| 特性 | 随机密钥GA（对比算法） | 混合GA（主算法） |
|------|----------------------|-----------------|
| 编码方式 | 随机密钥（4子串） | 整数编码（2子串） |
| 零件序列 | 随机密钥[0,1] | 工件编号直接排列 |
| 朝向/旋转 | 独立子串编码 | 装箱算法自动选择 |
| 嵌套算法 | BLF（按序嵌套） | 天际线+禁忌搜索 |
| 局部搜索 | 无 | 禁忌搜索 |
| 初始化策略 | 随机 | 多样化策略（面积/高度排序） |

1. **算例格式**：与主算法使用相同的算例格式
2. **结果目录**：自动创建在 `src/main/resources/result/对比试验/随机密钥GA/`
3. **内存使用**：大规模算例可能需要增加JVM堆内存
4. **并行计算**：自动检测CPU核心数，合理分配线程

## 理论依据

该算法设计基于以下文献思想：
- 随机密钥编码避免交叉/变异导致的零件重复/遗漏问题
- BLF启发式是二维装箱问题的经典方法
- 精英保留策略加速收敛
- 参数化均匀交叉保持种群多样性

## 扩展性

算法设计具有良好的扩展性：

1. **编码扩展**：可轻松添加新的子串（如零件优先级）
2. **启发式替换**：BLFPacker可替换为其他嵌套算法
3. **参数调优**：所有参数可通过GAParameters配置
4. **并行优化**：支持种群级并行评估
