一、算例集概览
==========================================

本目录包含多个不同规模和特性的测试算例，用于测试3D打印车间调度问题的求解算法。

算例命名规则：
test_instance_<特征>_<打印机数>m_<工件数>j_<工序数>ops.txt

二、算例列表
==========================================

1. test_instance_small_2m_5j.txt
   - 规模：小型
   - 打印机：2台 (200x200x150mm, 250x250x180mm)
   - 批处理机：2台 (60min, 50min)
   - 工件数：5个
   - 工序数：3道 (打印 → 批处理 → 其他)

四、算例设计原则
==========================================

1. 零件尺寸设计
   - 小零件：25-45mm，适合批量打印
   - 中等零件：50-70mm，平衡装箱和批量
   - 大零件：75-95mm，装箱约束明显

2. 打印机配置
   - 平台尺寸：150mm - 400mm
   - 层高：0.15mm - 0.3mm
   - 准备时间：6-20分钟
   - 换层时间：0.3-1.2分钟/层

3. 批处理机配置
   - 处理时间：35-70分钟
   - 数量：2-5台
   - 时间差异化设计，体现机器选择重要性

4. 工序设计
   - 第1道：打印工序（时间为0，由装箱决定）
   - 第2道：批处理工序（固定时间）
   - 后续：离散加工工序（可选多台机器）

5. 机器选择
   - 每道工序1-3台备选机器
   - 加工时间有差异（5-20分钟）
   - 体现柔性制造特征

五、使用建议
==========================================

1. 算法调试阶段
   推荐：test_instance_small_2m_5j.txt
   原因：规模小，便于手工验证和调试

2. 性能测试阶段
   推荐：test_instance_medium_3m_10j.txt
         test_instance_large_4m_20j.txt
   原因：中等规模，能反映算法真实性能

3. 算法对比阶段
   推荐：全部算例
   原因：覆盖不同特征，全面对比算法优劣

4. 装箱算法测试
   推荐：test_instance_large_parts_2m_8j.txt
         test_instance_small_parts_3m_12j.txt
   原因：强调装箱优化的重要性

5. 调度算法测试
   推荐：test_instance_multi_ops_4m_25j_6ops.txt
   原因：工序链长，调度复杂

七、算例验证要点
==========================================

1. 数据合法性检查
   ✓ 零件尺寸不超过最大打印机平台
   ✓ 机器编号连续且正确
   ✓ 工序数与实际描述一致
   ✓ 所有工件都有完整的工序信息

2. 调度结果验证
   ✓ 所有工件都被调度
   ✓ 工序顺序约束满足
   ✓ 机器容量约束满足
   ✓ 时间计算正确

3. 装箱结果验证
   ✓ 零件不重叠
   ✓ 零件不超出平台边界
   ✓ 批次划分合理
   ✓ 利用率在合理范围
