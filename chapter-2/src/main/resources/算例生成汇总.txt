🚀 快速开始
═══════════════════════════════════════════════════════════════════════════

1️⃣ 验证算例
   运行: TestInstanceValidator.java
   功能: 检查所有算例的格式和数据合法性

2️⃣ 查看统计
   运行: InstanceStatistics.java
   功能: 生成详细统计信息和CSV数据文件

3️⃣ 读取算例
   参考: SimpleInstanceReader.java
   功能: 演示如何在代码中读取和使用算例

4️⃣ 运行算法
   ```java
   // 读取算例
   File file = new File("src/main/resources/test_instance_small_2m_5j.txt");
   Input input = new Input(file);
   Problem problem = input.getProblemDesFromFile();
   
   // 运行遗传算法
   GA ga = new GA(problem, ...);
   Chromosome best = ga.run();
   
   // 输出结果
   System.out.println("最优解Makespan: " + best.fitness);
   ```


📖 使用场景推荐
═══════════════════════════════════════════════════════════════════════════

【算法开发阶段】
  推荐: test_instance_small_2m_5j.txt
  理由: 规模小，便于调试和验证

【性能测试阶段】
  推荐: test_instance_medium_3m_10j.txt
        test_instance_large_4m_20j.txt
  理由: 规模适中，能反映真实性能

【算法对比实验】
  推荐: 全部8个算例
  理由: 覆盖不同特征，全面评估算法性能

【论文实验】
  小规模组: small_2m_5j + small_parts_3m_12j
  中规模组: medium_3m_10j + complex_3m_15j_5ops + large_parts_2m_8j
  大规模组: large_4m_20j + multi_ops_4m_25j_6ops
  极限测试: xlarge_5m_30j

【装箱算法测试】
  推荐: test_instance_large_parts_2m_8j.txt (大零件)
        test_instance_small_parts_3m_12j.txt (小零件)
  理由: 突出装箱优化的重要性

【调度算法测试】
  推荐: test_instance_multi_ops_4m_25j_6ops.txt
        test_instance_complex_3m_15j_5ops.txt
  理由: 工序链长，调度复杂度高
