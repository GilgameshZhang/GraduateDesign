方法三：在你自己的代码中使用
═══════════════════════════════════════════════════════════════════════════

【完整代码示例】
─────────────────────────────────────────────────────────────────────────
import AlgorthmFrame.ga.GA;
import ProblemFrame.Solution;
import ProgramEntity.Input;
import ProgramEntity.Problem;
import java.io.File;

public class YourOwnCode {
    public static void main(String[] args) {
        try {
            // 1. 读取算例
            File instanceFile = new File("path/to/your/instance.txt");
            Input input = new Input(instanceFile);
            Problem problem = input.getProblemDesFromFile();
            
            // 2. 创建GA对象
            GA ga = new GA(problem);
            
            // 3. 运行求解
            long startTime = System.currentTimeMillis();
            Solution solution = ga.solve();
            long endTime = System.currentTimeMillis();
            
            // 4. 处理结果
            System.out.println("求解完成！");
            System.out.println("用时：" + (endTime - startTime) + "毫秒");
            
            // 根据Solution的实际结构获取更多信息
            // ...
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

调整算法参数
═══════════════════════════════════════════════════════════════════════════

GA类的参数在 GA.java 中定义（第20-33行）：

private final int popSize = 50;           // 种群规模
private final double pc = 0.80;           // 交叉概率
private final double pm = 0.10;           // 变异概率
private final int maxGen = 200;           // 最大迭代次数
private final int maxStagnantStep = 30;   // 最大停滞步数

【如何修改】
─────────────────────────────────────────────────────────────────────────
1. 打开 AlgorthmFrame/ga/GA.java
2. 修改第20-33行的参数值
3. 重新编译：mvn clean compile
4. 重新运行

【参数建议】
─────────────────────────────────────────────────────────────────────────
快速测试：popSize=30, maxGen=100
标准测试：popSize=50, maxGen=200  (默认)
深度搜索：popSize=100, maxGen=500

═══════════════════════════════════════════════════════════════════════════
常见问题与解决方案
═══════════════════════════════════════════════════════════════════════════

【问题1】文件路径错误
─────────────────────────────────────────────────────────────────────────
错误：文件不存在
解决：
1. 检查路径是否正确
2. 使用绝对路径
3. 注意Windows路径使用双反斜杠 \\

【问题2】内存不足
─────────────────────────────────────────────────────────────────────────
错误：OutOfMemoryError
解决：增加JVM内存
java -Xmx2g -cp ... test.RunAllInstances

【问题3】编译错误
─────────────────────────────────────────────────────────────────────────
解决：
1. 确保Maven正确安装
2. 运行 mvn clean compile
3. 检查Java版本（需要Java 8）

【问题4】算法运行时间过长
─────────────────────────────────────────────────────────────────────────
解决：
1. 先用小算例测试
2. 减少迭代次数（修改maxGen）
3. 减少种群规模（修改popSize）

【问题5】ArrayIndexOutOfBoundsException
─────────────────────────────────────────────────────────────────────────
解决：
1. 先运行 TestInstanceValidator 验证算例
2. 确保使用的是修正后的算例文件
3. 检查算例格式是否正确

3. 记录平均值、最优值、最差值、标准差

【参数调优】
1. 固定算例
2. 改变GA参数
3. 对比不同参数的效果
4. 找到最优参数组合
