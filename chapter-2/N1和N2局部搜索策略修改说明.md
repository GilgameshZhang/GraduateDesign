# N1和N2局部搜索策略修改说明

## 📝 修改概述

根据用户要求，对N1和N2局部搜索策略进行重写，采用更简单直接的策略。

## 🎯 修改内容

### N1策略修改

#### 旧策略
```
1. 找到打印完工时间最长的机器
2. 用轮盘赌选择该机器上的一个零件（高度越高权重越大）
3. 移动到完工时间最短的机器
```

#### 新策略 ⭐
```
1. 找到加工时间（完工时间）最长的机器
2. 选择该机器上最高的零件（直接选最高的，不用轮盘赌）
3. 分配给加工时间最短的打印机
```

**关键变化**：
- ❌ 去除轮盘赌选择
- ✅ 直接选择最高的零件（更确定性）
- ✅ 简化逻辑

### N2策略修改

#### 旧策略
```
1. 找到面积占用率最高的批次
2. 用轮盘赌选择该批次中的一个零件（面积越大权重越大）
3. 移动到其他合适的机器
```

#### 新策略 ⭐
```
1. 在所有打印机的最后一批中，找到高度最高的零件
2. 转移到最后一批中面积利用率最小的机器
3. 接在最后（追加到该机器的最后一批）
```

**关键变化**：
- ❌ 不再只关注占用率最高的批次
- ✅ 关注所有机器的最后一批
- ✅ 选择高度最高的零件（不用轮盘赌）
- ✅ 目标是面积利用率最小的机器

## 📊 详细实现

### N1：加工时间平衡策略

#### 步骤1：找到加工时间最长的机器

```java
int maxTimeMachineIdx = -1;
double maxTime = Double.NEGATIVE_INFINITY;

for (int i = 0; i < batchSolution.length; i++) {
    List<Solution> machineSolution = batchSolution[i];
    if (machineSolution == null || machineSolution.isEmpty()) {
        continue;
    }
    
    // 获取该机器的最后一个批次的完工时间
    double endTime = machineSolution.get(machineSolution.size() - 1).endTime;
    if (endTime > maxTime) {
        maxTime = endTime;
        maxTimeMachineIdx = i;
    }
}
```

**说明**：
- 遍历所有打印机
- 每台机器的加工时间 = 最后一批的完工时间
- 找到加工时间最长的那台

#### 步骤2：选择该机器上最高的零件

```java
int highestJobIdx = -1;
double maxHeight = Double.NEGATIVE_INFINITY;

for (int i = 0; i < printCount; i++) {
    if (ms[i] == maxTimeMachineNo) {
        int jobNo = os[i];
        Item item = items[jobNo];
        
        if (item.h > maxHeight) {
            maxHeight = item.h;
            highestJobIdx = i;
        }
    }
}
```

**说明**：
- 遍历该机器上的所有零件
- 直接找到高度最高的那个
- 不使用轮盘赌（确定性选择）

#### 步骤3：分配给加工时间最短的打印机

```java
int minTimeMachineIdx = -1;
double minTime = Double.POSITIVE_INFINITY;

for (int i = 0; i < printMachineCount; i++) {
    if (i == maxTimeMachineIdx) continue;  // 跳过源机器
    
    PrintMachine targetMachine = (PrintMachine) machines[i];
    boolean fitsNormal = (item.l <= targetMachine.L && 
                         item.w <= targetMachine.W && 
                         item.h <= targetMachine.H);
    boolean fitsRotated = (item.w <= targetMachine.L && 
                          item.l <= targetMachine.W && 
                          item.h <= targetMachine.H);
    
    if (fitsNormal || fitsRotated) {
        // 检查该机器的打印完工时间
        List<Solution> machineSolution = batchSolution[i];
        double endTime = 0.0;
        if (machineSolution != null && !machineSolution.isEmpty()) {
            endTime = machineSolution.get(machineSolution.size() - 1).endTime;
        }
        
        if (endTime < minTime) {
            minTime = endTime;
            minTimeMachineIdx = i;
        }
    }
}
```

**说明**：
- 遍历所有其他打印机
- 检查尺寸约束（正常放置或旋转90°）
- 找到能容纳该零件且加工时间最短的机器

#### 示例

```
初始状态：
  打印机1: 完工时间=100, 零件=[A(h=5), B(h=8), C(h=3)]
  打印机2: 完工时间=80,  零件=[D(h=6), E(h=4)]
  打印机3: 完工时间=60,  零件=[F(h=7)]

N1操作：
  步骤1: 最长加工时间机器 = 打印机1 (100)
  步骤2: 该机器最高零件 = B (h=8)
  步骤3: 最短加工时间机器 = 打印机3 (60)
  
  移动: B从打印机1 → 打印机3

结果：
  打印机1: 完工时间≈90, 零件=[A(h=5), C(h=3)]
  打印机2: 完工时间=80, 零件=[D(h=6), E(h=4)]
  打印机3: 完工时间≈70, 零件=[F(h=7), B(h=8)]
  
  改进: makespan从100降低到约90
```

### N2：最后一批优化策略

#### 步骤1：在所有机器的最后一批中找到高度最高的零件

```java
int highestJobIdx = -1;
int highestJobMachineIdx = -1;
double maxHeight = Double.NEGATIVE_INFINITY;

for (int i = 0; i < batchSolution.length; i++) {
    List<Solution> machineSolution = batchSolution[i];
    if (machineSolution == null || machineSolution.isEmpty()) continue;
    
    Solution lastBatch = machineSolution.get(machineSolution.size() - 1);
    
    // 遍历该批次中的所有零件
    for (ProgramEntity.PlaceItem placeItem : lastBatch.placeItemList) {
        int jobNo = Integer.parseInt(placeItem.name);
        Item item = items[jobNo];
        
        if (item.h > maxHeight) {
            maxHeight = item.h;
            highestJobMachineIdx = i;
            
            // 在gene_OS中找到该零件的位置
            for (int j = 0; j < printCount; j++) {
                if (os[j] == jobNo && ms[j] == (i + 1)) {
                    highestJobIdx = j;
                    break;
                }
            }
        }
    }
}
```

**说明**：
- 遍历所有打印机的最后一批
- 在所有最后一批的零件中找到高度最高的
- 记录该零件所在的机器

#### 步骤2：找到最后一批中面积利用率最小的机器

```java
int minRateMachineIdx = -1;
double minRate = Double.POSITIVE_INFINITY;

for (int i = 0; i < batchSolution.length; i++) {
    if (i == highestJobMachineIdx) continue;  // 跳过源机器
    
    List<Solution> machineSolution = batchSolution[i];
    if (machineSolution == null || machineSolution.isEmpty()) {
        // 空机器，利用率为0（最小）
        PrintMachine targetMachine = (PrintMachine) machines[i];
        boolean fitsNormal = (item.l <= targetMachine.L && 
                             item.w <= targetMachine.W && 
                             item.h <= targetMachine.H);
        boolean fitsRotated = (item.w <= targetMachine.L && 
                              item.l <= targetMachine.W && 
                              item.h <= targetMachine.H);
        
        if (fitsNormal || fitsRotated) {
            minRate = 0.0;
            minRateMachineIdx = i;
        }
        continue;
    }
    
    Solution lastBatch = machineSolution.get(machineSolution.size() - 1);
    double rate = lastBatch.rate;
    
    // 检查该机器能否容纳要移动的零件
    PrintMachine targetMachine = (PrintMachine) machines[i];
    boolean fitsNormal = (item.l <= targetMachine.L && 
                         item.w <= targetMachine.W && 
                         item.h <= targetMachine.H);
    boolean fitsRotated = (item.w <= targetMachine.L && 
                          item.l <= targetMachine.W && 
                          item.h <= targetMachine.H);
    
    if ((fitsNormal || fitsRotated) && rate < minRate) {
        minRate = rate;
        minRateMachineIdx = i;
    }
}
```

**说明**：
- 遍历所有其他打印机
- 获取每台机器最后一批的面积利用率
- 检查尺寸约束
- 找到利用率最小的机器

#### 示例

```
初始状态（最后一批）：
  打印机1: 批次3: [A(h=8, area=20), B(h=5, area=15)], rate=0.8
  打印机2: 批次2: [C(h=6, area=18), D(h=9, area=22)], rate=0.7
  打印机3: 批次1: [E(h=4, area=12)], rate=0.3

N2操作：
  步骤1: 所有最后一批中高度最高零件 = D (h=9)
         来自打印机2的批次2
  步骤2: 最后一批中利用率最小机器 = 打印机3 (rate=0.3)
  
  移动: D从打印机2 → 打印机3（接在最后）

结果：
  打印机1: 批次3: [A(h=8), B(h=5)], rate=0.8
  打印机2: 批次2: [C(h=6)], rate=0.4 ← 利用率下降
  打印机3: 批次1: [E(h=4), D(h=9)], rate≈0.6 ← 利用率上升
  
  改进: 打印机2的利用率下降，但批次更平衡
```

## 🎯 策略意图分析

### N1策略意图

**目标**：平衡打印机的加工时间，减少makespan

**逻辑**：
1. 加工时间最长的机器是瓶颈
2. 移除该机器上的高零件可以减少打印时间
3. 移动到加工时间最短的机器不会增加太多makespan

**为什么选最高的零件？**
- 高零件通常打印时间长
- 移除高零件对源机器影响大
- 有助于显著减少瓶颈机器的时间

### N2策略意图

**目标**：优化最后一批的面积利用率，提高资源利用效率

**逻辑**：
1. 最后一批直接影响makespan
2. 高零件在最后一批可能影响批次效率
3. 移动到利用率低的机器可以提高空间利用

**为什么关注最后一批？**
- 最后一批完成时间 = makespan
- 优化最后一批可以直接减少makespan
- 最后一批的利用率影响整体效率

## 📊 效果对比

| 维度 | 旧策略 | 新策略 |
|------|--------|--------|
| **选择方式** | 轮盘赌（概率性） | 直接选最优（确定性） |
| **计算复杂度** | O(n log n) | O(n) |
| **效果稳定性** | 低（随机性） | 高（确定性） |
| **探索能力** | 强（多样性） | 弱（固定选择） |
| **利用能力** | 中 | 强（直接选最优） |

### 优势 ✅

| 优势 | 说明 |
|------|------|
| **简单直接** | 逻辑清晰，易于理解和维护 |
| **计算效率** | 去除轮盘赌，计算更快 |
| **确定性强** | 每次运行结果一致（给定相同输入） |
| **针对性强** | N1针对时间平衡，N2针对空间利用 |

### 劣势 ⚠️

| 劣势 | 说明 |
|------|------|
| **多样性低** | 总是选择相同的零件移动 |
| **局部最优** | 可能陷入局部最优（缺乏探索） |
| **依赖初始解** | 如果初始解不好，可能难以改进 |

### 缓解措施

1. **与其他策略配合**
```
N1-N5轮流执行，增加多样性
N1/N2负责利用，N3/N4/N5负责探索
```

2. **与变异操作配合**
```
局部搜索提供局部优化（确定性）
变异操作提供全局探索（随机性）
```

3. **多次迭代**
```
即使单次移动确定，多次迭代后仍会产生不同结果
因为每次移动改变了状态，下次选择会不同
```
