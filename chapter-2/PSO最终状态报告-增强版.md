## 🎯 当前算法设计

### 核心流程

```
PSO算法流程:
1. 初始化粒子群（启发式策略）
   ↓
2. 评估所有粒子的适应度
   ↓
3. 更新个体最优(pBest)和全局最优(gBest)
   ↓
4. 对每个粒子:
   a. updateVelocity()  (简化)
   b. updatePosition()  (使用GA变异算子)
   c. 评估新适应度
   d. 更新pBest
   ↓
5. 更新gBest
   ↓
6. 检查终止条件（停滞或时间）
   ↓
7. 返回最优解
```

### 4种变异策略

```
updatePosition(): 随机选择一种变异

[25%] 策略1: mutatePrintSequence()
      └─ 打印段序列逆序变异
      └─ 同步逆序机器分配

[25%] 策略2: mutateDiscreteSequence()
      └─ 离散段序列逆序变异
      └─ 修复机器分配

[25%] 策略3: mutatePrintMachine()
      └─ 打印段机器重分配
      └─ 确保尺寸约束

[25%] 策略4: mutateDiscreteMachine()
      └─ 离散段机器重分配
      └─ 确保可用机器约束
```

## 🔧 技术细节

### 粒子编码

```java
public class Particle {
    public int[] gene_OS;      // 工序序列（双段：打印+离散）
    public int[] gene_MS;      // 机器分配（双段：打印+离散）
    public double fitness;     // 适应度
    public List<Solution>[] printSolution;  // 打印批次方案
    
    public int[] pBest_OS;     // 个体最优序列
    public int[] pBest_MS;     // 个体最优机器
    public double pBestFitness;// 个体最优适应度
}
```

### 变异算子详解

#### 1. mutatePrintSequence() - 打印段序列逆序

```java
// 原始
gene_OS: [J0, J1, J2, J3, J4]
gene_MS: [P1, P2, P1, P2, P1]

// 选择区间[1,3]逆序
gene_OS: [J0, J3, J2, J1, J4]
gene_MS: [P1, P2, P1, P2, P1]  // 同步逆序
```

#### 2. mutateDiscreteSequence() - 离散段序列逆序+修复

```java
// 原始
gene_OS: [..., J0_op2, J1_op2, J0_op3]
gene_MS: [..., M1, M2, M1]

// 选择区间逆序
gene_OS: [..., J0_op3, J1_op2, J0_op2]

// 修复机器分配
gene_MS: [..., M1, M2, M1]  // 检查并修复无效机器
```

#### 3. mutatePrintMachine() - 打印段机器重分配

```java
// 选择J1，当前在P2
可用打印机: [P1, P2, P3] (能容纳J1尺寸的)

// 重分配到P3
gene_MS[1]: P2 → P3
```

#### 4. mutateDiscreteMachine() - 离散段机器重分配

```java
// 选择J1_op2，当前在M2
可用机器: [M1, M2, M3] (该工序的候选机器)

// 重分配到M3
gene_MS[pos]: M2 → M3
```
