# 综合实验运行器使用说明

## 📋 功能概述

`ComprehensiveExperimentRunner` 是一个全自动的批量实验运行器，用于系统性地测试混合GA算法在不同规模算例上的性能。

### 核心功能

✅ **批量运行**: 自动运行 J10、J20、J50、J100 四个规模的所有算例  
✅ **多次重复**: 每个算例运行10次，确保结果可靠性  
✅ **多线程加速**: 利用多核CPU并行执行，大幅缩短实验时间  
✅ **完整输出**: 生成迭代曲线图、甘特图、打印布局图、实验报告  
✅ **自动汇总**: 生成详细的统计汇总表

在 `ComprehensiveExperimentRunner.java` 中：


### 线程数配置

自动配置（推荐）：
```java
int threadCount = Math.min(RUNS_PER_INSTANCE, Runtime.getRuntime().availableProcessors());
```

手动配置：
```java
int threadCount = 4;  // 固定使用4个线程
```

## ⚠️ 注意事项

### 1. 系统资源

**内存要求**：
- 8线程并行：至少 8GB RAM
- 16线程并行：至少 16GB RAM
- 如果内存不足，减少线程数

**磁盘空间**：
- 每次运行约占用 5-10MB（图表+报告）
- 200次运行约需 1-2GB 磁盘空间

### 2. 运行建议

✅ **推荐做法**：
- 在空闲时间运行（如晚上、周末）
- 确保电脑不会休眠或关机
- 定期检查控制台输出

❌ **不推荐**：
- 运行时使用电脑做其他高负载任务
- 中途手动停止（会导致数据不完整）

### 3. 错误处理

**如果某个算例失败**：
- 程序会继续运行其他算例
- 失败信息会输出到控制台
- 汇总表中会排除失败的算例

**常见错误**：
1. `FileNotFoundException`: 算例文件不存在 → 检查文件路径
2. `OutOfMemoryError`: 内存不足 → 减少线程数
3. `IOException`: 磁盘空间不足 → 清理磁盘

## 🔍 结果验证

### 快速检查

运行完成后，检查以下内容：

1. **文件夹数量**：
   ```
   应该有 20个算例文件夹 + 1个汇总表 = 21项
   ```

2. **每个算例文件夹**：
   ```
   应该有 10个 run 子文件夹
   ```

3. **每个 run 文件夹**：
   ```
   应该有：
   - 1个 实验报告.txt
   - 1个 收敛曲线图.png
   - 1个 甘特图.png
   - N个 打印布局图*.png（N = 打印机数量 × 批次数）
   ```

4. **汇总统计表**：
   ```
   应该包含 20行数据（每个算例一行）
   ```

### 数据合理性检查

- ✅ **Makespan**: 应该随问题规模增大而增大
- ✅ **标准差**: 应该相对较小（变异系数 < 5%）
- ✅ **最优值**: 应该 ≤ 平均值
- ✅ **运行时间**: 应该随问题规模增大而增大
