File file = new File("path/to/instance.txt");
Input input = new Input(file);
Problem problem = input.getProblemDesFromFile();

GA ga = new GA(problem);
Solution solution = ga.solve();

┌────────────────────────────────────────────────────────────────────────┐
│ 🔧 常见问题快速解决                                                      │
└────────────────────────────────────────────────────────────────────────┘

  文件找不到？
    → 检查路径，使用绝对路径，Windows用 \\

  编译失败？
    → 确保pom.xml设置Java 8
    → 运行 mvn clean compile

  运行慢？
    → 先用小算例测试
    → 减少maxGen和popSize

  出错？
    → 先运行 TestInstanceValidator 验证算例
