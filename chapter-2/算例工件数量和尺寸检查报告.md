## 技术实现

### 工件数量验证

```python
def validate_job_count(filepath):
    with open(filepath, 'r', encoding='utf-8') as f:
        lines = f.readlines()

    # 解析期望工件数
    header = lines[0].strip().split()
    expected_jobs = int(header[1])

    # 计算实际工件数
    actual_jobs = len(lines) - 3

    return actual_jobs == expected_jobs
```

### 尺寸修复

```python
def fix_dimensions(length, width, height):
    max_dim = max(length, width)
    if max_dim > 100:
        scale = 100.0 / max_dim
        new_length = max(10, int(length * scale))
        new_width = max(10, int(width * scale))
        new_height = max(10, int(height * scale))
        return new_length, new_width, new_height
    return length, width, height
```
