# 随机密钥GA与混合GA对比算法说明

## 算法对比概述

本项目实现了两种遗传算法用于增材制造零件嵌套与调度优化问题：

1. **混合GA（主算法）**：位于 `AlgorthmFrame/ga/GA.java`
2. **随机密钥GA（对比算法）**：位于 `AlgorthmFrame/randomKeyGA/RandomKeyGA.java`

## 核心设计差异

### 1. 染色体编码方式

#### 混合GA（主算法）
```
染色体 = [gene_OS | gene_MS]
- gene_OS: 工件序列（整数编码，工件编号直接排列）
- gene_MS: 机器选择（整数编码，每个工序对应的机器编号）

示例：
gene_OS = [2, 0, 1, 3, ...]  // 工件编号序列
gene_MS = [1, 2, 1, 2, ...]  // 对应的机器选择
```

**特点**：
- 简洁高效
- 依赖特殊的交叉算子（POX, LOX）保持可行性
- 朝向和旋转由嵌套算法自动决定

#### 随机密钥GA（对比算法）
```
染色体 = [随机密钥 | 朝向 | 旋转 | 机器分配]
- 随机密钥: [0,1]区间随机数，解码后生成零件序列
- 朝向: 1-3（3种朝向选择）
- 旋转: 1-8（8种旋转角度，45°增量）
- 机器分配: 1-m（m台打印机）

示例：
partSequenceKeys = [0.73, 0.21, 0.89, 0.45, ...]  // 随机密钥
partOrientations = [1, 2, 1, 3, ...]               // 朝向
partRotations    = [3, 1, 5, 2, ...]               // 旋转（3=90°, 1=0°, ...）
machineAssign    = [1, 2, 1, 1, ...]               // 机器分配

解码后序列: [1, 3, 0, 2, ...]  // 按随机密钥升序排序得到
```

**特点**：
- 多子串编码，信息更丰富
- 随机密钥编码天然避免交叉/变异导致的不可行解
- 朝向和旋转显式编码，增加搜索空间

---

### 2. 遗传算子

#### 混合GA（主算法）

**交叉算子**：
- POX（Position-based Crossover）：保持工序位置关系
- LOX（Linear Order Crossover）：保持工序相对顺序
- 两阶段交叉：分别处理打印工序和离散工序

**变异算子**：
- 交换变异：随机交换两个基因位
- 插入变异：随机移动一个基因到新位置
- 机器重分配变异：随机更改机器选择

**选择策略**：
- 锦标赛选择
- 精英保留（10%）

#### 随机密钥GA（对比算法）

**交叉算子**：
- 参数化均匀交叉（PUX）：对每个基因"掷硬币"决定继承父代1或父代2
- 4个子串同步交叉，保持一致性

**变异算子**：
- 随机密钥变异：替换为[0,1]区间新随机数
- 朝向/旋转/机器变异：替换为有效范围内的随机值
- 独立变异：每个子串独立进行

**选择策略**：
- 锦标赛选择（tournament size = 3）
- 精英保留（10%）

---

### 3. 嵌套启发式

#### 混合GA（主算法）

**天际线装箱（Skyline Packing）**：
```java
// 评分机制：综合考虑多个因素
score = f(矩形长度, 天际线长度, 左墙高度, 右墙高度)

// 12级评分系统（0-12分）
// 分数越高，放置位置越优
```

**特点**：
- 贪心选择：每次选择评分最高的零件和位置
- 支持旋转：自动尝试不旋转和旋转两种情况
- 精细化评分：根据左右墙高度动态调整策略

#### 随机密钥GA（对比算法）

**改进的BLF（Bottom-Left-First）**：
```java
// 按染色体指定的顺序依次尝试嵌套
for (零件 in 染色体序列) {
    应用染色体指定的朝向和旋转
    在天际线上寻找左下位置
    if (能放置) {
        放置零件，更新天际线
    } else {
        转入下一批次
    }
}
```

**特点**：
- 按序嵌套：严格按照染色体指定的零件顺序
- 朝向固定：使用染色体编码的朝向和旋转
- 左下优先：总是选择最左下的可行位置
- 动态分批：无法嵌套的零件自动形成新批次

---

### 4. 局部搜索

#### 混合GA（主算法）

**集成禁忌搜索**：
- 对装箱结果进行局部优化
- 邻域操作：交换零件位置、调整朝向
- 禁忌表：避免重复搜索已访问解

#### 随机密钥GA（对比算法）

**无局部搜索**：
- 纯GA框架，无额外局部搜索
- 依赖种群多样性和遗传算子进行全局搜索

---

### 5. 初始化策略

#### 混合GA（主算法）

**多样化初始化**：
```java
策略1: 随机初始化
策略2: 按零件面积降序排列（大零件优先）
策略3: 按零件高度降序排列（高零件优先）
策略4: 机器选择策略（轮盘赌/负载均衡）
```

#### 随机密钥GA（对比算法）

**纯随机初始化**：
```java
所有子串完全随机生成
- 随机密钥：[0,1]区间均匀分布
- 朝向/旋转/机器：均匀随机选择
```

## 理论优势对比

### 混合GA（主算法）优势

1. **高效编码**：整数编码直接，解码快速
2. **精细嵌套**：天际线评分机制考虑多种因素
3. **局部增强**：禁忌搜索提升局部最优解质量
4. **启发式初始化**：利用问题特性（面积/高度）生成高质量初始解
5. **成熟稳定**：编码方式和算子经过充分测试

### 随机密钥GA（对比算法）优势

1. **编码鲁棒性**：随机密钥天然避免不可行解，交叉变异简单
2. **搜索空间扩展**：显式编码朝向和旋转，增加决策变量
3. **易于扩展**：新增子串（如优先级）非常方便
4. **通用性强**：随机密钥编码是排列问题的通用方法
5. **理论保证**：遗传算子不破坏可行性

## 预期性能对比

### 求解质量

- **混合GA**：局部搜索和启发式初始化可能带来更好的解
- **随机密钥GA**：搜索空间更大，纯GA框架，质量依赖参数调优

### 求解速度

- **混合GA**：禁忌搜索增加计算时间，但收敛可能更快
- **随机密钥GA**：无局部搜索，单代更快，但可能需要更多迭代

### 稳定性

- **混合GA**：启发式初始化减少随机性，结果相对稳定
- **随机密钥GA**：完全随机初始化，不同运行间可能有较大差异

### 规模适应性

- **混合GA**：禁忌搜索在大规模问题上可能成为瓶颈
- **随机密钥GA**：纯GA框架，规模扩展性更好

## 实验对比方法

### 运行对比实验

```bash
# 1. 运行混合GA
java ComprehensiveExperimentRunner

# 2. 运行随机密钥GA
java RandomKeyGAExperimentRunner
```

### 对比指标

1. **平均Makespan**：10次运行的平均值
2. **最优Makespan**：10次运行的最小值
3. **标准差**：衡量稳定性
4. **变异系数**：标准化的稳定性指标
5. **平均运行时间**：效率指标
6. **收敛曲线**：观察收敛速度

### 统计检验

建议使用配对t检验或Wilcoxon秩和检验验证性能差异的显著性。

## 适用场景分析

### 混合GA更适合

- 需要高质量解的场景
- 中小规模问题（零件数<100）
- 对运行时间要求不严格
- 问题特性明显（如大小差异大）

### 随机密钥GA更适合

- 需要稳定性和通用性
- 大规模问题（零件数>100）
- 对运行时间敏感
- 问题结构不明显

---

## 总结

两种算法各有优劣：

- **混合GA**：通过局部搜索和启发式策略，牺牲一定通用性换取更好的求解质量
- **随机密钥GA**：采用通用编码和纯GA框架，保持算法简洁性和扩展性

实际应用中应根据问题规模、时间要求和质量需求选择合适的算法。本项目提供完整实现和对比实验，为算法选择提供数据支持。
