# 随机密钥GA可视化输出说明

## 概述

已为随机密钥GA算法添加了完整的可视化输出功能，包括：
- ✅ 迭代曲线图
- ✅ 打印批次布局图
- ✅ 详细实验报告

## 输出文件清单

每次运行后会在结果目录生成以下文件：

```
算例名称_runX/
├── experiment_info.txt          # 实验配置信息
├── algorithm_output.txt         # 算法运行日志
├── iteration_curve.png         # 迭代曲线图
├── printer1_batch1.png         # 打印机1批次1布局图
├── printer1_batch2.png         # 打印机1批次2布局图
├── printer2_batch1.png         # 打印机2批次1布局图
├── ...
└── detailed_report.txt         # 详细实验报告
```

---

## 1. 迭代曲线图 (iteration_curve.png)

### 内容
- X轴：迭代次数（Generation）
- Y轴：最优Makespan值
- 曲线：展示算法收敛过程

### 用途
- 观察算法收敛速度
- 分析是否过早收敛
- 对比不同运行的收敛轨迹

### 示例解读
```
如果曲线：
- 快速下降后趋于平缓 → 收敛良好
- 持续震荡 → 种群多样性好，持续探索
- 过早平坦 → 可能陷入局部最优
```

---

## 2. 打印批次布局图 (printerX_batchY.png)

### 内容
- 黑色边框：打印平台边界
- 彩色矩形：嵌套的零件
- 标签PX：零件编号
- 底部信息：零件数、利用率、最大高度

### 布局特点
- 左下优先（BLF）策略
- 按染色体指定的朝向和旋转
- 不同颜色区分不同零件

### 用途
- 验证嵌套算法正确性
- 观察空间利用率
- 分析零件摆放合理性

### 示例布局
```
┌─────────────────┐
│  P3   P1        │  ← 上部分空白较多，利用率待提升
│      ┌───┐      │
│  ┌───┤P2 │  P4  │
│  │P0 │   │      │  ← 左下优先，零件紧密排列
└──┴───┴───┴──────┘
```

## 3. 详细实验报告 (detailed_report.txt)

### 内容结构

#### （1）问题信息
```
【问题信息】
零件数量: 10
打印机数量: 2
批处理机器数量: 1
```

#### （2）求解结果
```
【求解结果】
最优Makespan: 5123.45
总迭代次数: 142
```

#### （3）最优染色体编码
```
【最优染色体编码】

零件加工顺序:
  P6 P5 P3 P4 P2 P1 P0 P9 P8 P7

零件朝向配置:
  P0:O1 P1:O2 P2:O1 P3:O3 P4:O1 ...

零件旋转配置:
  P0:0° P1:45° P2:90° P3:135° P4:180° ...

零件机器分配:
  P0:M1 P1:M2 P2:M1 P3:M2 P4:M1 ...
```

**解读**：
- 加工顺序：按随机密钥解码后的嵌套优先级
- 朝向O1/O2/O3：代表3种不同的摆放朝向
- 旋转角度：0°, 45°, 90°, ... 315°（8种）
- 机器分配：M1, M2, ... 表示分配到的打印机

#### （4）打印批次详情
```
【打印批次详情】

打印机1 - 共2个批次:
  批次1: 零件数=4, 利用率=68.5%, 高度=45.20, 时间=0.00~1234.56
  批次2: 零件数=2, 利用率=42.3%, 高度=38.10, 时间=1234.56~2345.67

打印机2 - 共1个批次:
  批次1: 零件数=4, 利用率=71.2%, 高度=50.30, 时间=0.00~1456.78

汇总统计:
  总批次数: 3
  总零件数: 10
  平均利用率: 60.7%
```

**解读**：
- 零件数：该批次嵌套的零件数量
- 利用率：嵌套空间利用率（越高越好）
- 高度：批次最大零件高度（影响打印时间）
- 时间：打印开始和结束时间

#### （5）迭代历史
```
【迭代历史（前10代和后10代）】

  Gen   0: 5678.90
  Gen   1: 5456.78
  Gen   2: 5234.56
  ...
  Gen 138: 5123.45
  Gen 139: 5123.45
  Gen 140: 5123.45
  Gen 141: 5123.45
  Gen 142: 5123.45
```

**解读**：
- 前几代：快速改进
- 后几代：值稳定，已收敛

### Q2: 布局图显示不完整？

**可能原因**：
- 零件数量过多，图表尺寸不够
- 零件坐标超出打印平台

**解决**：
- 调整图表尺寸（在RandomKeyVisualizer中修改）
- 检查BLF算法是否正确工作

### Q3: 详细报告中的数值如何理解？

**参考**：
- Makespan：越小越好（最小化目标）
- 利用率：60-80%为良好水平
- 迭代次数：通常100-300代收敛
