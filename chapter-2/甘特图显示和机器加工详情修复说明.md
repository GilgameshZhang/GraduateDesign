# 甘特图显示和机器加工详情输出修复说明

## 🎯 问题描述

用户反馈两个问题：
1. **甘特图问题**：没有显示批处理机和离散处理机器的块
2. **报告输出**：需要输出每台机器上的加工工件号、加工开始时间、加工结束时间

---

## 🔍 问题分析

### 问题1：甘特图机器标签缺失

**原因**：
```java
// ❌ 旧代码：机器标签没有添加到plot上
for (int i = 0; i < totalMachines; i++) {
    String machineLabel = getMachineLabel(i);
    XYTextAnnotation machineAnnotation = new XYTextAnnotation(
        machineLabel, 0, i + 0.5
    );
    machineAnnotation.setFont(labelFont);
    machineAnnotation.setTextAnchor(TextAnchor.CENTER_LEFT);
    // 不添加到plot，改为在图例中显示  ← ❌ 注释掉了！
}
```

**影响**：
- ❌ Y轴左侧没有机器标签
- ❌ 用户看不到哪个是打印机、批处理机、离散机
- ❌ 即使有矩形，也不知道对应哪台机器

---

### 问题2：机器加工详情输出不完整

**原有输出格式**：
```
打印机1: 工序数=3, 工作时间=150.00, 完成时间=180.00, 利用率=83.3%
  加工工件: J0[0.00-60.00], J3[60.00-110.00], J5[110.00-150.00]
```

**问题**：
- ⚠️ 去重逻辑会漏掉同一工件的多个工序
- ⚠️ 单行显示，不够清晰
- ⚠️ 没有独立列出每个工序的详情

**用户需求**：
- ✅ 显示每个工序（不去重）
- ✅ 显示工件号
- ✅ 显示开始时间
- ✅ 显示结束时间

## 🔧 修复方案

### 修复1：甘特图机器标签

参考原版`ScheduleVisualizer`的实现：

```java
// ✅ 新代码：正确添加机器标签
// 1. 计算时间范围
double minTime = Double.MAX_VALUE;
double maxTime = Double.MIN_VALUE;
for (int jobNo = 0; jobNo < chromosome.operationMatrix.length; jobNo++) {
    Operation[] operations = chromosome.operationMatrix[jobNo];
    for (Operation op : operations) {
        if (op != null && op.startTime >= 0 && op.endTime > op.startTime) {
            minTime = Math.min(minTime, op.startTime);
            maxTime = Math.max(maxTime, op.endTime);
        }
    }
}

// 2. 设置X轴范围，留出空间显示机器标签
if (maxTime > minTime) {
    double timePadding = (maxTime - minTime) * 0.15;
    plot.getDomainAxis().setRange(minTime - timePadding, maxTime + timePadding);
}

// 3. 在Y轴左侧添加机器标签
double labelXPosition = minTime - (maxTime - minTime) * 0.12;
for (int i = 0; i < totalMachines; i++) {
    String machineLabel = getMachineLabel(i);
    XYTextAnnotation machineAnnotation = new XYTextAnnotation(
        machineLabel,
        labelXPosition,  // ✅ 放在左侧（时间轴之外）
        i + 0.5          // ✅ Y坐标对应机器位置
    );
    machineAnnotation.setFont(labelFont);
    machineAnnotation.setPaint(Color.BLACK);
    plot.addAnnotation(machineAnnotation);  // ✅ 添加到plot上！
}
```

**关键改进**：
1. ✅ 计算时间范围（minTime, maxTime）
2. ✅ 扩展X轴范围（增加15%的padding）
3. ✅ 将标签放在`minTime - 12%`的位置（Y轴左侧）
4. ✅ **调用`plot.addAnnotation()`添加标签**

### 修复2：机器加工详情输出

#### 2.1 数据收集改进

```java
// ✅ 移除去重逻辑，记录所有工序
List<List<String>> machineJobDetails = new ArrayList<>();

for (Operation[] operations : chromosome.operationMatrix) {
    for (Operation op : operations) {
        if (op != null && op.startTime >= 0 && op.endTime > op.startTime) {
            int machineIdx = op.machineNo;
            if (machineIdx >= 0 && machineIdx < totalMachines) {
                // 记录工件详细信息：工件号[开始时间-结束时间]
                String jobDetail = String.format("J%d[%.2f-%.2f]", 
                                                 op.jobNo, op.startTime, op.endTime);
                machineJobDetails.get(machineIdx).add(jobDetail);  // ✅ 直接添加，不检查重复
            }
        }
    }
}
```

**关键改进**：
- ❌ 移除：`if (!machineJobs.get(machineIdx).contains(jobInfo))`
- ✅ 新增：直接添加所有工序，不去重

---

#### 2.2 输出格式改进

**旧格式**（单行显示）：
```
打印机1: 工序数=3, 工作时间=150.00, 完成时间=180.00, 利用率=83.3%
  加工工件: J0[0.00-60.00], J3[60.00-110.00], J5[110.00-150.00]
```

**新格式**（分行显示每个工序）：
```java
writer.println(String.format("  打印机%d: 工序数=%d, 工作时间=%.2f, 完成时间=%.2f, 利用率=%.1f%%",
    i + 1, machineOpCount[i], machineWorkTime[i], machineEndTime[i], utilization));

// ✅ 分行显示每个工序
if (!machineJobDetails.get(i).isEmpty()) {
    writer.println("    加工工件详情:");
    for (String jobDetail : machineJobDetails.get(i)) {
        writer.println("      " + jobDetail);  // ✅ 每行一个工序
    }
}
```

**新输出示例**：
```
打印机1: 工序数=3, 工作时间=150.00, 完成时间=180.00, 利用率=83.3%
  加工工件详情:
    J0[0.00-60.00]
    J3[60.00-110.00]
    J5[110.00-150.00]
```

**优势**：
- ✅ 每行一个工序，清晰易读
- ✅ 显示所有工序（包括同一工件的多个工序）
- ✅ 明确显示工件号、开始时间、结束时间
- ✅ 便于统计和分析
