# 田口实验使用说明

## 📋 概述

本文档说明如何使用参数化的遗传算法框架进行田口实验设计。

## 🎯 已完成的修改

### 1. 创建了参数配置类 `GAParameters`
**位置**: `src/main/java/ProblemFrame/GAParameters.java`

支持配置的参数：
- 种群参数：`popSize`, `pr`, `pc`, `pm`
- 终止参数：`maxStagnantStep`（早停阈值，主要终止条件由时间控制）
- 局部搜索参数：`localSearchMaxIter`, `localSearchNoImprove`
- 邻域算子候选数：`n1n2Candidates`, `n3Candidates`, `n4Candidates`, `n5Candidates`
- 初始化策略比例：`heuristicRatio`

**重要**：算法的主要终止条件由**运行时间**控制，`maxGen`（最大迭代次数）参数已移除。

### 2. 修改了 GA 类支持参数化
**位置**: `src/main/java/AlgorthmFrame/ga/GA.java`

- 新增参数化构造函数：`GA(Problem input, GAParameters params)`
- 保留默认构造函数：`GA(Problem input)` - 使用默认参数
- 新增结果输出器设置：`setResultWriter(ExperimentResultWriter writer)`

### 3. 创建了结果输出工具类
**位置**: `src/main/java/util/java/ExperimentResultWriter.java`

功能：
- 自动创建实验结果文件
- 格式化输出实验信息、迭代过程、最终结果
- 输出详细调度方案和机器负载统计

### 4. 创建了田口实验运行器
**位置**: `src/test/java/TaguchiExperimentRunner.java`

功能：
- 运行单次实验
- 批量运行多次实验并计算平均值
- 内置L9正交表实验设计示例

## 🚀 快速开始

### 方式1：使用默认参数运行（原有方式）

```java
Input input = new Input("src/main/resources/instance/J20P3B2D5_01.txt");
Problem problem = input.getProblem();

GA ga = new GA(problem);  // 使用默认参数
Solution solution = ga.solve();
```

### 方式2：使用自定义参数运行

```java
// 创建自定义参数
GAParameters params = GAParameters.createCustomParameters(
    150,      // popSize
    0.85,     // pc
    0.25,     // pm
    8         // localSearchMaxIter
);

// 创建GA并运行
GA ga = new GA(problem, params);
Solution solution = ga.solve();
```

### 方式3：运行田口实验（自动保存结果到文件）

```java
// 使用 TaguchiExperimentRunner
double makespan = TaguchiExperimentRunner.runSingleExperiment(
    "src/main/resources/instance/J20P3B2D5_01.txt",
    "J20P3B2D5_01",
    1,      // 实验次数
    params
);
```

## 📈 数据分析步骤

### 1. 收集实验数据

每个参数组合运行5次，记录平均Makespan到Excel表格：

| 实验号 | A | B | C | D | Makespan1 | Makespan2 | ... | 平均 |
|--------|---|---|---|---|-----------|-----------|-----|------|
| 1 | 1 | 1 | 1 | 1 | 1050.2 | 1055.3 | ... | 1052.5 |
| ... | ... | ... | ... | ... | ... | ... | ... | ... |

### 2. 计算信噪比 (S/N Ratio)

田口方法使用"越小越好"的信噪比：

```
S/N = -10 * log10(平均(yi^2))
```

### 3. 方差分析 (ANOVA)

使用Excel或Python计算：
- 各因子的平方和 (SS)
- 自由度 (DOF)
- 均方 (MS)
- F值
- 贡献率 (%)

### 4. 确定最优参数组合

根据S/N比主效应图，选择每个因子的最佳水平。

## ⚠️ 注意事项

1. **随机性处理**：每个参数组合建议运行5-10次，取平均值
2. **时间成本**：完整L9实验（9组×5次）需要较长时间
3. **结果保存**：所有结果自动保存到文件，避免数据丢失
4. **内存管理**：大规模实验注意JVM内存设置
5. **固定随机种子**：如需可重复实验，取消GA构造函数中的`r.setSeed(1)`注释
6. **终止条件**：算法由时间控制终止，不再使用迭代次数（maxGen已移除）
