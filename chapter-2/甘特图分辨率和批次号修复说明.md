# 甘特图分辨率和批次号修复说明

## 问题描述

用户反馈了两个问题：

### 问题1：分辨率不够高
- 原分辨率：1200x800像素
- 图表显示不够清晰，特别是在大屏幕或打印时

### 问题2：批次号不是从1开始
- 批次号计算逻辑有问题
- 期望每台打印机/批处理机的第一个批次是1，第二个是2，依次类推
- 但实际显示的批次号不正确

## 根本原因分析

### 批次号问题的根本原因

**原来的代码逻辑：**
```java
int batchCounter = 1;
for (Operation op : machineOperations) {
    drawOperationRectangle(plot, op, machineIdx, batchCounter);
    // 只有打印机和批处理机才增加批次计数
    if (isPrintMachine(op.machineNo) || isBatchMachine(op.machineNo)) {
        batchCounter++;
    }
}
```

**问题分析：**
1. ❌ 所有类型的工序（包括离散处理机）都使用同一个`batchCounter`
2. ❌ 离散处理机的工序也传入了`batchCounter`，但离散处理机不应该有批次号
3. ❌ 批次计数器的递增时机可能导致批次号不准确

**正确的逻辑应该是：**
1. ✅ 每台打印机/批处理机维护独立的批次计数器
2. ✅ 批次计数器从1开始
3. ✅ 每绘制一个工序后，批次计数器递增
4. ✅ 离散处理机的工序不使用批次号，传入0或不使用

## 解决方案

### 修复1：提高分辨率

**修改前：**
```java
ChartUtils.saveChartAsPNG(new File(outputPath), chart, 1200, 800);
```

**修改后：**
```java
ChartUtils.saveChartAsPNG(new File(outputPath), chart, 1920, 1080);
```

**改进点：**
- 分辨率从 1200x800 提高到 1920x1080（1080p Full HD）
- 宽度增加 60%（1200 → 1920）
- 高度增加 35%（800 → 1080）
- 适合大屏幕显示和打印输出

### 修复2：正确计算批次号

**修改后的代码：**
```java
// 为该机器初始化批次计数器（从1开始）
int batchCounter = 1;

// 为每个工序绘制矩形
for (Operation op : machineOperations) {
    // 只有打印机和批处理机才使用批次号，离散处理机传0
    if (isPrintMachine(op.machineNo) || isBatchMachine(op.machineNo)) {
        drawOperationRectangle(plot, op, machineIdx, batchCounter);
        batchCounter++; // 绘制后递增，下一个工序用下一个批次号
    } else {
        // 离散处理机不使用批次号
        drawOperationRectangle(plot, op, machineIdx, 0);
    }
}
```

**改进点：**
1. ✅ 每台机器的批次计数器从1开始
2. ✅ 只有打印机和批处理机才使用批次号
3. ✅ 离散处理机传入0（但在`drawOperationRectangle`中会显示工件号`J`，不会用到批次号）
4. ✅ 绘制后立即递增，确保下一个工序用下一个批次号

## 批次号显示逻辑

在`drawOperationRectangle`方法中：

```java
// 设置标签
String label;
if (isPrintMachine(op.machineNo) || isBatchMachine(op.machineNo)) {
    // 打印机和批处理机：B机器号-批次号（用'-'分隔）
    int machineNumber = getMachineNumber(op.machineNo);
    label = "B" + machineNumber + "-" + batchNumber;
} else {
    // 离散机：工件号（不使用batchNumber）
    label = "J" + op.jobNo;
}
```

**关键点：**
- 打印机和批处理机：使用传入的`batchNumber`，显示为`B<机器号>-<批次号>`
- 离散处理机：不使用`batchNumber`，显示为`J<工件号>`

## 注意事项

1. **批次号的含义**：
   - 批次号是按照工序在该机器上的时间段分配的
   - 同一时间段（开始时间和结束时间相同）的工序属于同一批次
   - 只有时间变化时，批次号才递增
   - 这个批次号对应实际的装箱批次

2. **如果图表仍然模糊**：
   - 可以进一步提高分辨率到2560x1440（2K）
   - 修改代码：`ChartUtils.saveChartAsPNG(..., 2560, 1440)`

3. **如果批次号仍然不对**：
   - 检查`operationMatrix`是否正确填充
   - 检查工序的`startTime`是否正确
   - 检查机器类型判断逻辑（`isPrintMachine`, `isBatchMachine`）
