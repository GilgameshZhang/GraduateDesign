# 邻域消融实验 - README

> 验证N1-N5五种邻域搜索策略的各自贡献度

---

## 📖 什么是邻域消融实验？

这是对**混合局部搜索策略的细粒度分析**，通过逐个移除5种邻域算子(N1-N5)，观察性能变化，从而**确定每个邻域策略的独立贡献度和重要性排序**。

---

## 🔬 5种邻域策略

| 邻域 | 名称 | 作用阶段 | 核心功能 |
|-----|------|---------|---------|
| **N1** | 基于打印时间的跨机移动 | 打印段 | 平衡打印机负载，减少打印瓶颈 |
| **N2** | 基于面积的跨机移动 | 打印段 | 优化打印平台空间利用率 |
| **N3** | 相邻批次交换 | 打印段 | 优化批次顺序，减少等待时间 |
| **N4** | 关键块首尾交换 | 离散段 | 优化关键路径，降低makespan |
| **N5** | 关键工序机器重分配 | 离散段 | 重新分配关键工序到更快的机器 |

---

## 🎯 实验目的

- ✅ **独立贡献度** - 确定每个邻域策略使makespan降低的百分比
- ✅ **重要性排序** - 识别最关键的邻域策略
- ✅ **协同效应** - 分析策略之间的相互作用
- ✅ **论文支撑** - 提供充分的实验数据和图表

## 📊 实验设计

测试**7组配置**（每组10次）：

| 实验组 | 配置 | 作用 |
|--------|------|------|
| **完整算法** | N1+N2+N3+N4+N5 | 基线 |
| 无N1 | N2+N3+N4+N5 | 测试N1贡献 |
| 无N2 | N1+N3+N4+N5 | 测试N2贡献 |
| 无N3 | N1+N2+N4+N5 | 测试N3贡献 |
| 无N4 | N1+N2+N3+N5 | 测试N4贡献 |
| 无N5 | N1+N2+N3+N4 | 测试N5贡献 |
| **无局部搜索** | 无邻域策略 | 对照组 |

**总运行次数**: 7 × 10 = **70次**

## 📈 期望结果示例

### 贡献度统计

```
实验组          平均Makespan   与基线差异   贡献度
--------------------------------------------------
完整算法        850.23        +0.00%      基线
无N1            865.30        +1.77%      N1贡献1.77%
无N2            858.40        +0.96%      N2贡献0.96%
无N3            862.50        +1.44%      N3贡献1.44%
无N4            870.20        +2.35%      N4贡献2.35% ⭐
无N5            867.80        +2.07%      N5贡献2.07%
无局部搜索      920.56        +8.27%      总贡献8.27%
```

### 重要性排序

```
按贡献度从高到低：
1. N4（关键块交换）         : 2.35% ★★★★★
2. N5（机器重分配）         : 2.07% ★★★★
3. N1（基于时间的跨机移动）  : 1.77% ★★★★
4. N3（批次交换）           : 1.44% ★★★
5. N2（基于面积的跨机移动）  : 0.96% ★★
```

### 关键发现

- ✅ **N4最重要** - 关键块交换对离散段优化效果最佳
- ✅ **N5次之** - 机器重分配在离散段也很关键
- ✅ **打印段策略** (N1+N2+N3) 合计贡献约4.2%
- ✅ **离散段策略** (N4+N5) 合计贡献约4.4%
- ✅ **联合效果** - 所有策略联合使makespan降低8.3%

**Q: 实验时间太长怎么办？**
```
A: 1) 减少运行次数到5次
   2) 选择小规模算例（J20或J50）
   3) 缩短终止时间
```

**Q: 某个策略贡献很小正常吗？**
```
A: 正常！不同策略在不同算例上贡献度不同：
   - N1/N2在打印时间占主导的算例上贡献大
   - N4/N5在离散处理时间长的算例上贡献大
   诚实报告结果即可。
```

A: 建议做（尤其是投顶级期刊）
