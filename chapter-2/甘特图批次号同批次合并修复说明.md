# 甘特图批次号同批次合并修复说明

## 问题描述

### 核心问题
打印机和批处理机可以同时处理多个零件（同一批次），这些零件具有相同的开始时间和结束时间。但原来的批次号计算逻辑把每个零件都当作一个独立的批次，导致批次号异常增长。

### 具体表现

**场景：打印机1有一个批次，包含3个零件**

| 零件 | 开始时间 | 结束时间 | 工序类型 |
|------|---------|---------|---------|
| 工件1 | 0.0 | 100.0 | 打印工序 |
| 工件2 | 0.0 | 100.0 | 打印工序 |
| 工件3 | 0.0 | 100.0 | 打印工序 |

**错误显示（修复前）：**
```
打印机1: [B1-1] [B1-2] [B1-3]
```
- 显示为3个批次，但实际是1个批次
- 批次号从1递增到3

**正确显示（修复后）：**
```
打印机1: [B1-1] [B1-1] [B1-1]
```
- 显示为1个批次（批次号都是1）
- 3个零件属于同一批次

## 根本原因分析

### 原来的错误逻辑

```java
int batchCounter = 1;

for (Operation op : machineOperations) {
    if (isPrintMachine(op.machineNo) || isBatchMachine(op.machineNo)) {
        drawOperationRectangle(plot, op, machineIdx, batchCounter);
        batchCounter++; // ❌ 每个工序都递增批次号
    }
}
```

**问题：**
- ❌ 无论工序是否属于同一批次，都递增批次号
- ❌ 没有判断工序的时间是否相同
- ❌ 同一批次的多个零件被错误地当作多个批次

### 正确的逻辑

**关键判断：**
- 同一批次的工序具有**相同的开始时间和结束时间**
- 只有当开始时间或结束时间发生变化时，才是新批次
- 需要跟踪上一个工序的时间，与当前工序比较

## 解决方案

### 修复后的代码

```java
// 按开始时间排序，如果开始时间相同则按结束时间排序
machineOperations.sort((a, b) -> {
    int cmp = Double.compare(a.startTime, b.startTime);
    if (cmp == 0) {
        return Double.compare(a.endTime, b.endTime);
    }
    return cmp;
});

// 为该机器初始化批次计数器（从1开始）
int batchCounter = 1;
double lastStartTime = -1;  // 上一个工序的开始时间
double lastEndTime = -1;    // 上一个工序的结束时间

// 为每个工序绘制矩形
for (Operation op : machineOperations) {
    if (isPrintMachine(op.machineNo) || isBatchMachine(op.machineNo)) {
        // 判断是否是新批次：如果开始时间或结束时间与上一个工序不同，说明是新批次
        // 允许微小的浮点误差（0.01）
        if (lastStartTime >= 0 && 
            (Math.abs(op.startTime - lastStartTime) > 0.01 || 
             Math.abs(op.endTime - lastEndTime) > 0.01)) {
            batchCounter++; // ✓ 只有新批次才递增
        }
        
        drawOperationRectangle(plot, op, machineIdx, batchCounter);
        
        // 更新上一个工序的时间
        lastStartTime = op.startTime;
        lastEndTime = op.endTime;
    } else {
        // 离散处理机不使用批次号
        drawOperationRectangle(plot, op, machineIdx, 0);
    }
}
```

### 关键改进点

1. **排序增强**
   ```java
   machineOperations.sort((a, b) -> {
       int cmp = Double.compare(a.startTime, b.startTime);
       if (cmp == 0) {
           return Double.compare(a.endTime, b.endTime);
       }
       return cmp;
   });
   ```
   - 首先按开始时间排序
   - 如果开始时间相同，再按结束时间排序
   - 确保同一批次的工序排在一起

2. **跟踪上一个工序的时间**
   ```java
   double lastStartTime = -1;
   double lastEndTime = -1;
   ```
   - 记录上一个工序的开始和结束时间
   - 用于与当前工序比较

3. **智能判断新批次**
   ```java
   if (lastStartTime >= 0 && 
       (Math.abs(op.startTime - lastStartTime) > 0.01 || 
        Math.abs(op.endTime - lastEndTime) > 0.01)) {
       batchCounter++; // 新批次
   }
   ```
   - 只有当时间发生变化时，才增加批次号
   - 使用0.01的容差处理浮点误差
   - `lastStartTime >= 0`确保不是第一个工序

4. **更新时间**
   ```java
   lastStartTime = op.startTime;
   lastEndTime = op.endTime;
   ```
   - 每次处理完工序后，更新时间
   - 为下一个工序的比较做准备

## 示例验证

### 示例1：打印机1有2个批次

**工序数据：**
| 工件 | 开始时间 | 结束时间 | 批次 |
|------|---------|---------|------|
| J1 | 0.0 | 100.0 | 1 |
| J2 | 0.0 | 100.0 | 1 |
| J3 | 0.0 | 100.0 | 1 |
| J4 | 100.0 | 200.0 | 2 |
| J5 | 100.0 | 200.0 | 2 |

**批次号计算过程：**
1. J1: `lastStartTime=-1` → 批次=1，更新`lastStartTime=0.0, lastEndTime=100.0`
2. J2: `0.0==0.0 && 100.0==100.0` → 批次=1（不变）
3. J3: `0.0==0.0 && 100.0==100.0` → 批次=1（不变）
4. J4: `100.0!=0.0` → 批次=2（新批次），更新`lastStartTime=100.0, lastEndTime=200.0`
5. J5: `100.0==100.0 && 200.0==200.0` → 批次=2（不变）

**显示结果：**
```
打印机1: [B1-1] [B1-1] [B1-1] [B1-2] [B1-2]
         ↑____同一批次____↑   ↑__同一批次__↑
```

| J8 | 150.0 | 250.0 | 2 |

## 浮点误差处理

### 为什么需要容差？

在计算机中，浮点数运算可能产生微小误差：
```java
double a = 100.0;
double b = 99.9999999999;
// a == b 可能返回 false，但实际上它们非常接近
```

### 容差设置

```java
Math.abs(op.startTime - lastStartTime) > 0.01
```
- 使用0.01作为容差
- 如果时间差小于0.01，认为是相同时间
- 如果时间差大于0.01，认为是不同时间

### 容差影响

| 时间差 | 是否认为相同 | 是否新批次 |
|-------|------------|-----------|
| 0.0 | 是 | 否 |
| 0.005 | 是 | 否 |
| 0.009 | 是 | 否 |
| 0.01 | 否 | 是 |
| 0.1 | 否 | 是 |
| 1.0 | 否 | 是 |

## 注意事项

1. **批次的定义**：
   - 批次是指在同一时间段内，在同一台机器上处理的一组工序
   - 开始时间和结束时间相同的工序属于同一批次

2. **容差设置**：
   - 当前容差为0.01
   - 如果调度结果的时间精度更高，可能需要调整容差
   - 建议容差设置为时间精度的10倍

3. **排序的重要性**：
   - 必须先排序，确保同一批次的工序排在一起
   - 排序先按开始时间，再按结束时间

4. **离散处理机**：
   - 离散处理机通常一次只处理一个工件
   - 因此不使用批次号，直接显示工件号

## 与打印机布局图的一致性

甘特图的批次号应该与打印机布局图的批次对应：

- 甘特图：`B1-1`表示打印机1的第1个批次
- 打印机布局图：应该有对应的第1个批次的零件布局

确保两者的批次号计数方式一致，便于追溯和分析。
