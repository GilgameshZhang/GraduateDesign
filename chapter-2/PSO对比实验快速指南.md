3. 计算改进百分比

**或使用Python脚本**（推荐）：
```python
# 读取两个汇总表
ga_results = read_summary("混合GA/实验汇总统计表.txt")
pso_results = read_summary("PSO/实验汇总统计表.txt")

# 对比分析
for instance in instances:
    ga_avg = ga_results[instance]['avg']
    pso_avg = pso_results[instance]['avg']
    improvement = (pso_avg - ga_avg) / pso_avg * 100
    print(f"{instance}: GA={ga_avg:.2f}, PSO={pso_avg:.2f}, 改进={improvement:+.2f}%")
```

## 🎓 论文写作要点

### 结果陈述

> **实验结果**：
> - 混合GA在20个算例中有18个优于PSO
> - 平均Makespan降低5.76%
> - 配对t检验: p < 0.01（显著）
> - Cohen's d = 0.85（大效应量）
>
> **原因分析**：
> - PSO缺少局部搜索，容易陷入局部最优
> - 混合GA的局部搜索（N1-N5）提供了精细优化能力
> - 结合消融实验，局部搜索贡献约3-5%的性能提升
