## 📂 代码文件

### 核心算法

**PSO.java**
```
位置: src/main/java/AlgorthmFrame/pso/PSO.java
功能: PSO核心算法（增强版，集成GA变异算子）
关键方法:
  - solve(): 主算法循环
  - updatePosition(): 粒子位置更新（4种变异）
  - mutatePrintSequence(): 变异策略1
  - mutateDiscreteSequence(): 变异策略2
  - mutatePrintMachine(): 变异策略3
  - mutateDiscreteMachine(): 变异策略4
```

### 数据结构

**Particle.java**
```
位置: src/main/java/ProblemFrame/Particle.java
功能: 粒子类，存储粒子状态和个体最优
关键属性:
  - gene_OS, gene_MS: 当前位置
  - pBest_OS, pBest_MS: 个体最优
  - fitness, pBestFitness: 适应度
```

**PSOParameters.java**
```
位置: src/main/java/ProblemFrame/PSOParameters.java
功能: PSO参数配置类
默认参数:
  - swarmSize: 100
  - w: 0.7 (惯性权重)
  - c1, c2: 1.5 (学习因子)
  - maxRunTime: 3.0 (分钟)
```

### 测试程序

**TestPSO.java**
```
位置: src/test/java/TestPSO.java
功能: PSO快速测试
用途: 单次运行，验证功能
```

**PSOExperimentRunner.java**
```
位置: src/test/java/PSOExperimentRunner.java
功能: PSO批量实验
用途: 20个算例 × 10次 = 200次实验
```

**AlgorithmComparisonRunner.java**
```
位置: src/test/java/AlgorithmComparisonRunner.java
功能: GA vs PSO对比实验
用途: 生成对比表和论文数据
```
