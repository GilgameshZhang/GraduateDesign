# PSO粒子邻域改进功能使用说明

## 概述

针对PSO算法中的gbest和pbest进行小范围邻域改进，以提高解的质量。实现了两种邻域改进策略：

1. **OS邻域改进**：对工序序列进行swap/insert操作（重点改进同机器或关键路径相关的工序）
2. **MA邻域改进**：对关键工序尝试更换机器（看是否缩短关键路径）

## 核心方法

### 1. localSearchOS - 工序序列邻域改进

```java
public boolean localSearchOS(Problem problem, 
                             CaculateFitness caculateFitness, 
                             ProgramEntity.Operation[][] operationMatrix, 
                             double improveProb, 
                             int maxAttempts)
```

**功能**：
- 对工序序列(gene_OS)进行局部搜索
- 使用swap（交换）和insert（插入）两种操作
- 优先选择关键路径上的工序进行改进

**参数说明**：
- `problem`: 问题实例
- `caculateFitness`: 适应度计算器
- `operationMatrix`: 工序矩阵
- `improveProb`: 执行改进的概率（0.0-1.0），建议0.3-0.5
- `maxAttempts`: 最大尝试次数，建议10-30

**返回值**：
- `true`: 找到更优解
- `false`: 未找到更优解

### 2. localSearchMA - 机器分配邻域改进

```java
public boolean localSearchMA(Problem problem, 
                             CaculateFitness caculateFitness,
                             ProgramEntity.Operation[][] operationMatrix,
                             double improveProb, 
                             int maxAttempts)
```

**功能**：
- 对机器分配(gene_MS)进行局部搜索
- 对关键工序尝试更换候选机器
- 目标是缩短关键路径，降低makespan

**参数说明**：
- 参数含义与localSearchOS相同
- `maxAttempts`: 建议5-15（机器变更评估成本较高）

### 3. improvePBest - 综合邻域改进pbest

```java
public boolean improvePBest(Problem problem, 
                           CaculateFitness caculateFitness,
                           ProgramEntity.Operation[][] operationMatrix,
                           double improveProb, 
                           int maxAttemptsOS, 
                           int maxAttemptsMA)
```

**功能**：
- 对粒子的个体最优解(pbest)进行邻域改进
- 依次应用OS改进和MA改进
- 如果找到更优解，自动更新pbest

**参数说明**：
- `maxAttemptsOS`: OS改进的最大尝试次数
- `maxAttemptsMA`: MA改进的最大尝试次数

## 在PSO算法中的使用

### 方式1：每次迭代后改进gbest

```java
// 在PSO主循环中
for (int iter = 0; iter < maxIterations; iter++) {
    // ... PSO更新逻辑 ...
    
    // 对全局最优进行邻域改进
    if (gBest.localSearchOS(input, caculateFitness, operationMatrix, 0.5, 20)) {
        System.out.println("gbest OS改进成功");
    }
    
    if (gBest.localSearchMA(input, caculateFitness, operationMatrix, 0.5, 10)) {
        System.out.println("gbest MA改进成功");
    }
    
    // 重新计算适应度
    evaluateParticle(gBest);
}
```

### 方式2：定期改进所有粒子的pbest

```java
// 在PSO主循环中，每隔N代改进一次
for (int iter = 0; iter < maxIterations; iter++) {
    // ... PSO更新逻辑 ...
    
    // 每10代对所有粒子的pbest进行邻域改进
    if (iter % 10 == 0) {
        for (Particle p : swarm) {
            if (p.improvePBest(input, caculateFitness, operationMatrix, 
                              0.3, 15, 8)) {
                // pbest已自动更新
                System.out.println("粒子" + Arrays.asList(swarm).indexOf(p) + "的pbest改进成功");
            }
        }
    }
}
```

### 方式3：混合策略（推荐）

```java
// 在PSO主循环中
for (int iter = 0; iter < maxIterations; iter++) {
    // ... PSO更新逻辑 ...
    
    // 1. 每次迭代改进gbest（高频率，低强度）
    gBest.localSearchOS(input, caculateFitness, operationMatrix, 0.3, 10);
    gBest.localSearchMA(input, caculateFitness, operationMatrix, 0.3, 5);
    evaluateParticle(gBest);
    
    // 2. 每5代对pbest进行强化搜索（中频率，中强度）
    if (iter % 5 == 0) {
        for (Particle p : swarm) {
            p.improvePBest(input, caculateFitness, operationMatrix, 0.5, 15, 8);
        }
    }
    
    // 3. 每20代对所有粒子进行深度搜索（低频率，高强度）
    if (iter % 20 == 0) {
        for (Particle p : swarm) {
            p.localSearchOS(input, caculateFitness, operationMatrix, 0.8, 30);
            p.localSearchMA(input, caculateFitness, operationMatrix, 0.8, 15);
            evaluateParticle(p);
        }
    }
}
```

## 参数调优建议

### improveProb（改进概率）
- **保守策略**：0.2-0.3（计算资源有限时）
- **平衡策略**：0.4-0.6（推荐）
- **激进策略**：0.7-0.9（追求最优解时）

### maxAttempts（最大尝试次数）
- **OS改进**：
  - 小规模问题（<20个工件）：10-20次
  - 中规模问题（20-50个工件）：20-40次
  - 大规模问题（>50个工件）：30-50次

- **MA改进**：
  - 通常为OS改进次数的30%-50%
  - 因为机器变更评估成本较高

### 改进频率
- **gbest改进**：每次迭代或每2-3次迭代
- **pbest改进**：每5-10次迭代
- **深度搜索**：每20-50次迭代

## 关键技术细节

### 1. 关键路径识别
- 基于Solution的endTime字段识别关键工序
- 默认阈值：makespan的95%
- 优先对关键路径上的工序进行改进

### 2. 智能位置选择
- OS改进：70%概率选择关键工序，30%随机选择
- MA改进：80%概率选择关键工序，20%随机选择（跳过打印阶段）

### 3. 操作类型
- **Swap**：交换两个位置的工序（50%概率）
- **Insert**：将一个工序插入到另一个位置（50%概率）

### 4. 适应度计算
- 使用CaculateFitness.evaluate()计算makespan
- fitness = 1.0 / makespan（makespan越小，fitness越大）

## 注意事项

1. **性能影响**：邻域改进会增加计算时间，建议根据问题规模调整参数
2. **收敛速度**：适当的邻域改进可以加快收敛，但过度改进可能导致早熟收敛
3. **多样性**：不要对所有粒子都进行高强度改进，保持种群多样性
4. **评估成本**：每次改进都需要重新计算适应度，注意控制改进频率

## 实验建议

建议进行对比实验：

1. **基准PSO**：不使用邻域改进
2. **PSO+OS**：仅使用OS邻域改进
3. **PSO+MA**：仅使用MA邻域改进
4. **PSO+OS+MA**：同时使用两种邻域改进（混合策略）

比较指标：
- 最优makespan
- 收敛速度
- 计算时间
- 解的稳定性

## 示例完整代码

```java
public class PSO {
    private Particle[] swarm;
    private Particle gBest;
    private CaculateFitness caculateFitness;
    private Problem input;
    private ProgramEntity.Operation[][] operationMatrix;
    
    public void run() {
        // 初始化...
        
        for (int iter = 0; iter < maxIterations; iter++) {
            // PSO标准更新
            for (Particle p : swarm) {
                updateVelocity(p);
                updatePosition(p);
                evaluateParticle(p);
                p.updatePBest();
            }
            
            // 更新全局最优
            Particle currentBest = findBestParticle(swarm);
            if (currentBest.fitness > gBest.fitness) {
                gBest = new Particle(currentBest);
            }
            
            // === 邻域改进策略 ===
            
            // 1. 每次迭代改进gbest
            if (gBest.localSearchOS(input, caculateFitness, operationMatrix, 0.4, 15)) {
                evaluateParticle(gBest);
            }
            if (gBest.localSearchMA(input, caculateFitness, operationMatrix, 0.4, 8)) {
                evaluateParticle(gBest);
            }
            
            // 2. 每5代改进pbest
            if (iter % 5 == 0) {
                for (int i = 0; i < swarm.length; i++) {
                    swarm[i].improvePBest(input, caculateFitness, operationMatrix, 
                                         0.5, 15, 8);
                }
            }
            
            // 3. 输出当前结果
            System.out.printf("迭代 %d: makespan = %.2f\n", 
                             iter, 1.0 / gBest.fitness);
        }
    }
}
```

- Hybrid PSO: 在PSO框架中嵌入局部搜索算子
- 关键路径方法: 重点优化影响makespan的关键工序
