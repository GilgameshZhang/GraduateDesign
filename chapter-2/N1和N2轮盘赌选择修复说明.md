# N1和N2轮盘赌选择修复说明

## 🔍 修改内容

将N1和N2局部搜索策略中的零件选择从"选择最优零件"改为"轮盘赌选择"。

## 📊 修改前后对比

### N1：基于打印时间的跨机移动

#### 修改前
```java
策略：从打印完工时间最长的机器中选择高度最高的零件

实现：
1. 找到打印完工时间最长的机器
2. 遍历该机器上的所有零件
3. 选择高度最高的零件
4. 移动到能放下该零件且打印完工时间最短的机器
```

#### 修改后
```java
策略：从打印完工时间最长的机器中轮盘赌选择零件（高度越高权重越大）

实现：
1. 找到打印完工时间最长的机器
2. 收集该机器上的所有零件及其高度
3. 轮盘赌选择（高度越高，被选中概率越高）
4. 移动到能放下该零件且打印完工时间最短的机器
```

### N2：基于面积占用率的跨机移动

#### 修改前
```java
策略：从面积占用率最高的批次选择所有零件

实现：
1. 找到面积占用率最高的批次
2. 遍历该批次中的所有零件
3. 为每个零件尝试移动到其他合适的打印机
```

#### 修改后
```java
策略：从面积占用率最高的批次轮盘赌选择零件（面积越大权重越大）

实现：
1. 找到面积占用率最高的批次
2. 收集该批次中的所有零件及其面积
3. 轮盘赌选择（面积越大，被选中概率越高）
4. 为选中的零件尝试移动到其他合适的打印机
```

### 3. 轮盘赌选择算法

#### 基于高度的轮盘赌
```java
private int selectPartByRouletteForHeight(List<Integer> candidateIndices, List<Double> heights) {
    // 1. 计算权重（直接使用高度）
    List<Double> weights = new ArrayList<>();
    double totalWeight = 0;
    
    for (double height : heights) {
        double weight = height;  // 高度越高权重越大
        weights.add(weight);
        totalWeight += weight;
    }
    
    // 2. 轮盘赌选择
    double randomValue = r.nextDouble() * totalWeight;
    double cumulativeWeight = 0;
    
    for (int i = 0; i < weights.size(); i++) {
        cumulativeWeight += weights.get(i);
        if (randomValue <= cumulativeWeight) {
            return candidateIndices.get(i);
        }
    }
    
    return candidateIndices.get(candidateIndices.size() - 1);
}
```

#### 基于面积的轮盘赌
```java
private int selectPartByRouletteForArea(List<Integer> candidateIndices, List<Double> areas) {
    // 1. 计算权重（直接使用面积）
    List<Double> weights = new ArrayList<>();
    double totalWeight = 0;
    
    for (double area : areas) {
        double weight = area;  // 面积越大权重越大
        weights.add(weight);
        totalWeight += weight;
    }
    
    // 2. 轮盘赌选择
    double randomValue = r.nextDouble() * totalWeight;
    double cumulativeWeight = 0;
    
    for (int i = 0; i < weights.size(); i++) {
        cumulativeWeight += weights.get(i);
        if (randomValue <= cumulativeWeight) {
            return candidateIndices.get(i);
        }
    }
    
    return candidateIndices.get(candidateIndices.size() - 1);
}
```

## 📈 轮盘赌概率示例

### N1示例（基于高度）

```
机器M1上有3个零件：
- 零件A：高度10mm
- 零件B：高度5mm
- 零件C：高度15mm

权重分配：
- 零件A：weight = 10
- 零件B：weight = 5
- 零件C：weight = 15
totalWeight = 30

选中概率：
- P(A) = 10/30 = 33.3%
- P(B) = 5/30 = 16.7%
- P(C) = 15/30 = 50%  ← 高度最高，概率最高

轮盘赌过程：
random = 0.6（假设）
randomValue = 0.6 × 30 = 18

累积权重：
- A: 0 + 10 = 10 < 18, 继续
- B: 10 + 5 = 15 < 18, 继续
- C: 15 + 15 = 30 ≥ 18, 选中C ✓
```

### N2示例（基于面积）

```
批次B1上有3个零件：
- 零件X：面积100mm²
- 零件Y：面积200mm²
- 零件Z：面积150mm²

权重分配：
- 零件X：weight = 100
- 零件Y：weight = 200
- 零件Z：weight = 150
totalWeight = 450

选中概率：
- P(X) = 100/450 = 22.2%
- P(Y) = 200/450 = 44.4%  ← 面积最大，概率最高
- P(Z) = 150/450 = 33.3%

轮盘赌过程：
random = 0.4（假设）
randomValue = 0.4 × 450 = 180

累积权重：
- X: 0 + 100 = 100 < 180, 继续
- Y: 100 + 200 = 300 ≥ 180, 选中Y ✓
```

## 🎲 轮盘赌 vs 最优选择

| 特性 | 最优选择 | 轮盘赌选择 |
|-----|---------|-----------|
| 确定性 | 确定的（总是选最优） | 随机的（按概率选择） |
| 多样性 | 低（总是同一个） | 高（每次可能不同） |
| 探索能力 | 弱 | 强 |
| 局部最优风险 | 高 | 低 |
| 适用场景 | 确定性优化 | 随机搜索、进化算法 |

### 为什么使用轮盘赌？

1. **增加多样性**：不总是选择最优的零件，给其他零件机会
2. **避免局部最优**：探索更多可能的移动方案
3. **概率偏向**：仍然偏向于选择更优的零件（高度高/面积大）
4. **平衡探索与利用**：
   - 高权重零件有较高概率被选中（利用）
   - 低权重零件也有机会被选中（探索）

## ⚠️ 注意事项

### 边界情况处理

1. **只有一个候选零件**：
```java
if (candidateIndices.size() == 1) {
    return candidateIndices.get(0);  // 直接返回
}
```

2. **总权重为0**（理论上不会发生）：
```java
if (totalWeight <= 0) {
    return candidateIndices.get(r.nextInt(candidateIndices.size()));  // 随机选择
}
```

3. **候选列表为空**：
```java
if (candidateIndices.isEmpty()) {
    return -1;  // 返回无效值
}
```
