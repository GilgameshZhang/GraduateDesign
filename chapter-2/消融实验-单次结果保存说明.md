## 🔍 代码实现机制

### 核心代码片段

```java
// 在 runSingleExperiment() 方法中

// 1. 创建唯一的文件夹名称（带时间戳）
String folderName = experimentName + "_run" + runNo + "_" + 
                   new SimpleDateFormat("HHmmss").format(new Date());
//     ↓
//  完整算法_run1_134520
//  ^^^^^^^^  ^^^  ^^^^^^
//  实验组名   次数  时间戳（确保唯一性）

// 2. 创建独立的输出器
ExperimentResultWriter writer = new ExperimentResultWriter(
    folderName,   // 文件夹名称
    runNo,        // 运行次数
    problem       // 问题对象（用于生成图表）
);

// 3. 写入参数信息
writer.writeExperimentInfo(experimentName, runNo, params);

// 4. 绑定到GA实例
ga.setResultWriter(writer);

// 5. 运行算法（自动写入结果）
Solution solution = ga.solve();

// 6. 关闭输出器（完成文件写入）
writer.close();
```

### 关键设计点

| 特性 | 实现方式 | 作用 |
|-----|---------|------|
| **独立性** | 每次创建新的 `ExperimentResultWriter` | 互不干扰 |
| **唯一性** | 文件夹名带时间戳 | 避免覆盖 |
| **完整性** | 自动生成所有图表和报告 | 一站式保存 |
| **可追溯性** | 记录参数配置和运行时间 | 方便后续分析 |

## 🎯 如何查看单次运行结果

### 方法1：直接查看文件夹

1. 导航到 `src/main/resources/result/消融实验/`
2. 找到目标文件夹，如 `完整算法_run1_134520/`
3. 打开 `实验报告.txt` 查看详细数据
4. 查看各个图片文件

### 方法2：使用文本编辑器搜索

```bash
# 在 result/消融实验/ 目录下搜索特定makespan
grep -r "最优Makespan" .
```

### 方法3：Python脚本批量分析

```python
import os
import re

# 遍历所有实验文件夹
for folder in os.listdir("src/main/resources/result/消融实验/"):
    if folder.startswith("完整算法_run"):
        report_path = os.path.join(folder, "实验报告.txt")
        with open(report_path, 'r', encoding='utf-8') as f:
            content = f.read()
            # 提取makespan
            makespan = re.search(r"最优Makespan: ([\d.]+)", content)
            if makespan:
                print(f"{folder}: {makespan.group(1)}")
```

## ⚠️ 注意事项

### 1. 时间戳冲突

如果两次运行在同一秒内完成，可能产生相同的时间戳。解决方案：
- ✅ 已使用 `HHmmss` 格式（精确到秒）
- ✅ 正常情况下每次运行>1秒，不会冲突
- 💡 如需更精确，可改为毫秒：`HHmmssSSS`

### 2. 文件夹命名

当前格式：`完整算法_run1_134520`
- `完整算法`: 实验组名称
- `run1`: 第1次运行
- `134520`: 时间戳（13:45:20）

### 3. 查看历史记录

所有文件夹都会保留，不会被覆盖：
```
完整算法_run1_134520/  ← 第一次实验
完整算法_run1_140330/  ← 第二次实验（不同日期/时间）
```
