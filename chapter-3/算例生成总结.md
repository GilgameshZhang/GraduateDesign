### 2. 能耗参数设计

| 参数 | 说明 | 用途 |
|------|------|------|
| **P_run** | 运行功率 (kW) | 计算加工期间能耗 |
| **P_idle** | 待机功率 (kW) | 计算空闲期间能耗 |
| **E_switch** | 开关机能耗 (kWh) | 关机策略的能耗代价 |
| **T_warmup** | 预热时间 (秒) | 影响开关机决策 |
| **allowSwitch** | 是否允许关机 | 强制控制开关机行为 |

**关键机制: 盈亏平衡时间**
```
T_breakEven = E_switch / P_idle

当空闲时间 > T_breakEven + T_warmup 时，关机比待机更节能
```

## 🌟 核心特性

### 1. 四种能耗配置模板

#### ECO (节能型)
- 低待机功率 (0.2-0.4 kW)
- 低开关机代价 (0.8-1.2 kWh)
- 鼓励关机策略
- 适用: 桌面级3D打印机

#### STANDARD (标准型) ⭐ 推荐
- 平衡的能耗参数
- 打印机允许关机，批处理机倾向待机
- 适用: 工业级3D打印机，热处理炉

#### HEAVY_DUTY (重载型)
- 高运行功率 (6-9 kW)
- 高开关机代价 (4-6 kWh)
- 不鼓励关机
- 适用: 大型工业设备

#### TEMPERATURE_SENSITIVE (温度敏感型)
- 高待机功率 (1.2-2.0 kW)
- 极高开关机代价 (8-15 kWh)
- 强制禁止关机
- 适用: 需保温的设备（如热处理炉）

## 🔬 技术亮点

### 1. 智能开关机策略

算法自动计算每个空闲间隔是否应该关机:

```
if (allowSwitch && gapDuration > T_warmup + T_breakEven):
    关机 → 能耗 = E_switch
else:
    待机 → 能耗 = P_idle × gapDuration
```

### 2. 时间单位自动转换

**问题:**
- 调度系统使用"秒"
- 能耗系统使用"小时" (因为kWh = kW × 小时)

**解决:**
EnergyCalculator自动转换:
```java
double durationHours = durationSeconds / 3600.0;
double energy = P_run * durationHours;  // kWh
```

### 3. 批处理去重

批处理机同一批次的多个工件有相同的时间段，需要去重避免重复计算能耗:

```java
private List<Operation> removeBatchDuplicates(List<Operation> operations) {
    // 检查startTime和endTime是否相同
    // 相同则认为是同一批次，只保留一个
}
```

### 4. 灵活的配置系统

**三级配置优先级:**
1. 算例文件中的能耗参数 (最高优先级)
2. 机器对象自带的PowerParameters
3. 默认参数 (根据机器类型)

## ⚠️ 注意事项

1. **时间单位:** 调度用秒，能耗用小时，EnergyCalculator会自动转换
2. **离散机:** 当前版本设为0，预留扩展
3. **批处理去重:** 同一批次的工件时间相同，能耗只计算一次
4. **allowSwitch=0:** 强制禁止关机，即使空闲很长时间
5. **向后兼容:** 第二章算例可以直接使用，会自动使用默认能耗参数
