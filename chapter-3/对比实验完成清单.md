## 特色功能

### 🚀 多线程加速

- 自动检测CPU核心数
- 并行运行多个实验
- 显著缩短实验时间

**示例**：
- 单线程：4算法×10次 = 40个任务，耗时约20分钟
- 8核并行：同时运行8个任务，耗时约5分钟
- **加速比：4倍**

### 📊 归一化HV计算

**问题**：不同算例的目标值范围差异大

**解决**：
1. 收集所有实验的目标值
2. 计算全局最小值和最大值
3. 归一化到[0, 1]区间
4. 使用统一参考点(1.1, 1.1)

**优势**：
- ✅ 不同算例之间HV可比
- ✅ 消除量纲差异
- ✅ 更准确可靠

### 🎯 近似Pareto前沿（PF*）

**定义**：所有算法所有运行的非支配解合集

**用途**：
- IGD计算的参考集
- 算法性能的上界
- 问题的近似最优解集

**计算**：
1. 收集：4算法×10次×每次若干解
2. 筛选：提取非支配解
3. 去重：去除重复的解

### 🔄 统一参数配置

**确保公平对比**：
- 相同种群大小
- 相同交叉率/变异率
- 相同运行时间
- 相同局部搜索配置
- 不同随机种子

### 📈 统计显著性检验

**自动进行Wilcoxon检验**：
- 两两对比（6对）
- p-value < 0.01：差异极显著 **
- p-value < 0.05：差异显著 *
- p-value ≥ 0.05：差异不显著

## 常见问题

### Q: 如何增加重复次数？

修改 `AlgorithmComparisonExperimentRunner.java`：
```java
private static final int REPEAT_TIMES = 30;  // 改为30
```

### Q: 如何只对比部分算法？

修改：
```java
private static final String[] ALGORITHMS = {"NSGAII", "MOEAD"};  // 只要2个
```

### Q: 如何使用不同参数？

修改各算法的运行方法，例如：
```java
private static List<MOIndividual> runNSGAII(...) {
    nsgaii.setPopulationSize(150);  // NSGA-II用150
    // ...
}
```

### Q: 实验中断了怎么办？

1. 查看已完成的算例
2. 修改代码只运行未完成的算例
3. 或重新运行所有实验

### Q: 如何合并多次实验的结果？

需要手动合并：
1. 收集所有实验的Pareto前沿
2. 提取非支配解
3. 重新计算指标
