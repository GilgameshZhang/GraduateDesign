# 指标数据文件说明

## 📋 概述

在v1.2版本中，对比实验框架新增了**指标数据文件**输出功能，专门用于生成箱线图和统计分析。

---

## 🆕 新增文件

每个算例运行后，会在输出目录下额外生成两个指标数据文件：

### 1. MetricsData.csv
**格式**：CSV（逗号分隔）  
**用途**：直接导入Python/R/Excel画箱线图  
**位置**：`output/comparison_experiment/算例名称_时间戳/MetricsData.csv`

**文件内容示例**：
```csv
Algorithm,Run,HV,IGD,RunTime
NSGAII,1,0.85623456,0.01234567,123.45
NSGAII,2,0.86213456,0.01123456,125.67
NSGAII,3,0.85112345,0.01345678,122.89
...
MOEAD,1,0.82345678,0.02345678,134.56
MOEAD,2,0.82912345,0.02234567,136.78
...
MOGWO,1,0.83456789,0.01823456,145.67
...
SPEA2,1,0.84567890,0.01567890,156.78
...
```

**字段说明**：
- `Algorithm`：算法名称（NSGAII, MOEAD, MOGWO, SPEA2）
- `Run`：运行次数（1-10）
- `HV`：该次运行的Hypervolume值
- `IGD`：该次运行的IGD值
- `RunTime`：该次运行的时间（秒）

### 2. MetricsData.txt
**格式**：TXT（易读格式）  
**用途**：人工查看和验证  
**位置**：`output/comparison_experiment/算例名称_时间戳/MetricsData.txt`

**文件内容示例**：

## 📊 使用方法

### 方法1：使用Python绘制箱线图

#### 快速使用（推荐）

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 读取CSV文件
data = pd.read_csv('output/.../MetricsData.csv')

# 绘制HV箱线图
plt.figure(figsize=(10, 6))
sns.boxplot(x='Algorithm', y='HV', data=data)
plt.title('Hypervolume Comparison')
plt.savefig('hv_boxplot.png', dpi=300)
plt.show()

# 绘制IGD箱线图
plt.figure(figsize=(10, 6))
sns.boxplot(x='Algorithm', y='IGD', data=data)
plt.title('IGD Comparison')
plt.savefig('igd_boxplot.png', dpi=300)
plt.show()
```

#### 使用自动化脚本

```bash
# 运行可视化脚本（已自动集成）
python visualize_comparison.py
```

脚本会自动：
1. 读取 `MetricsData.csv`
2. 生成HV箱线图
3. 生成IGD箱线图
4. 进行统计显著性检验

### 方法2：使用R绘制箱线图

```r
# 读取CSV文件
data <- read.csv('output/.../MetricsData.csv')

# 绘制HV箱线图
library(ggplot2)
ggplot(data, aes(x=Algorithm, y=HV, fill=Algorithm)) +
  geom_boxplot() +
  theme_minimal() +
  labs(title='Hypervolume Comparison', y='HV')
ggsave('hv_boxplot.png', width=10, height=6, dpi=300)

# 绘制IGD箱线图
ggplot(data, aes(x=Algorithm, y=IGD, fill=Algorithm)) +
  geom_boxplot() +
  theme_minimal() +
  labs(title='IGD Comparison', y='IGD')
ggsave('igd_boxplot.png', width=10, height=6, dpi=300)
```

### 方法3：使用Excel绘制箱线图

1. 双击打开 `MetricsData.csv`
2. Excel会自动识别CSV格式
3. 选择数据 → 插入 → 图表 → 箱线图
4. 设置X轴为Algorithm，Y轴为HV或IGD

## 🎨 高级用法

### 1. 分组对比

```python
import pandas as pd

data = pd.read_csv('MetricsData.csv')
```

### 4. 统计注释

```python
from scipy import stats

# 添加统计显著性标注
def add_stat_annotation(data, ax):
    algorithms = data['Algorithm'].unique()
    y_max = data['HV'].max()
    
    # NSGA-II vs MOEA/D
    stat, p = stats.mannwhitneyu(
        data[data['Algorithm']=='NSGAII']['HV'],
        data[data['Algorithm']=='MOEAD']['HV']
    )
    
    if p < 0.05:
        ax.text(0.5, y_max * 1.05, '**', ha='center', fontsize=20)
```

## 🔍 验证数据

### 检查数据完整性

```python
import pandas as pd

# 读取CSV
data = pd.read_csv('MetricsData.csv')

# 检查每个算法的运行次数
for alg in ['NSGAII', 'MOEAD', 'MOGWO', 'SPEA2']:
    count = len(data[data['Algorithm'] == alg])
    print(f"{alg}: {count} 次运行")  # 应该都是10

# 检查缺失值
print(f"缺失值数量: {data.isnull().sum().sum()}")  # 应该是0
```

### 与报告对比

```python
import pandas as pd

# 从CSV读取
data = pd.read_csv('MetricsData.csv')
csv_mean_hv = data[data['Algorithm']=='NSGAII']['HV'].mean()

# 从报告中读取（手动）
report_mean_hv = 0.856234  # 从ComparisonReport.txt复制

# 验证一致性
print(f"CSV平均HV: {csv_mean_hv:.6f}")
print(f"报告平均HV: {report_mean_hv:.6f}")
print(f"差异: {abs(csv_mean_hv - report_mean_hv):.10f}")  # 应该非常小
```

## 🎓 统计分析示例

### Wilcoxon秩和检验

```python
from scipy.stats import wilcoxon
import pandas as pd

data = pd.read_csv('MetricsData.csv')

# NSGA-II vs MOEA/D
nsgaii_hv = data[data['Algorithm']=='NSGAII']['HV']
moead_hv = data[data['Algorithm']=='MOEAD']['HV']

statistic, p_value = wilcoxon(nsgaii_hv, moead_hv)

print(f"Wilcoxon统计量: {statistic}")
print(f"p值: {p_value}")

if p_value < 0.05:
    print("结论: 差异显著 (p < 0.05)")
```

### Kruskal-Wallis检验

```python
from scipy.stats import kruskal

# 多组比较
nsgaii = data[data['Algorithm']=='NSGAII']['HV']
moead = data[data['Algorithm']=='MOEAD']['HV']
mogwo = data[data['Algorithm']=='MOGWO']['HV']
spea2 = data[data['Algorithm']=='SPEA2']['HV']

h, p = kruskal(nsgaii, moead, mogwo, spea2)

print(f"Kruskal-Wallis H统计量: {h}")
print(f"p值: {p}")
```
