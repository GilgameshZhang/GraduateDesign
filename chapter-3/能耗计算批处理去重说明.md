# 能耗计算批处理去重修复说明

## 问题描述

### 原问题
在计算能耗时，打印机和批处理机是批处理设备，一个批次可以同时处理多个零件。但在 `EnergyCalculator` 中，存在**重复计算能耗**的问题。

### 问题示例
假设一个打印批次包含 3 个零件：
- 零件 0: 打印时间 [0.0, 5.0]
- 零件 1: 打印时间 [0.0, 5.0]  （同一批次）
- 零件 2: 打印时间 [0.0, 5.0]  （同一批次）

在 `operationMatrix` 中，这 3 个零件会有 3 个 `Operation` 对象，它们的 `startTime` 和 `endTime` 都相同。

**原来的能耗计算逻辑：**
```java
// ❌ 错误：会把同一批次计算 3 次
for (Operation op : operations) {
    double duration = op.endTime - op.startTime;
    runEnergy += params.P_run * duration;  // 5.0 * 3 = 15.0 小时
}
```

**实际情况：**
- 打印机只运行了 **5.0 小时**（一个批次）
- 但能耗却按 **15.0 小时**计算（3 倍）

---

## 修复方案

### 核心思路
添加 `removeBatchDuplicates` 方法，对于同一台机器：
- 如果多个 `Operation` 的 `startTime` 和 `endTime` 都相同
- 认为它们属于**同一批次**
- 只保留**一个代表性的 Operation**，避免重复计算

### 实现代码

#### 1. 添加去重方法

```java
/**
 * 去除批处理设备的重复工序
 * 
 * 对于打印机和批处理机，同一批次的多个零件会有相同的startTime和endTime
 * 需要去重，避免重复计算能耗
 * 
 * @param operations 原始工序列表
 * @return 去重后的工序列表
 */
private List<Operation> removeBatchDuplicates(List<Operation> operations) {
    if (operations == null || operations.isEmpty()) {
        return operations;
    }
    
    List<Operation> unique = new ArrayList<>();
    
    for (Operation op : operations) {
        boolean isDuplicate = false;
        
        // 检查是否与已有的工序重复（同时间段）
        for (Operation existingOp : unique) {
            // 如果startTime和endTime都相同，认为是同一批次
            // 使用小的误差容忍度（0.001）来处理浮点数比较
            if (Math.abs(op.startTime - existingOp.startTime) < 0.001 &&
                Math.abs(op.endTime - existingOp.endTime) < 0.001) {
                isDuplicate = true;
                break;
            }
        }
        
        if (!isDuplicate) {
            unique.add(op);
        }
    }
    
    return unique;
}
```

#### 2. 在能耗计算中使用去重后的列表

```java
private double calculateMachineEnergy(int machineId, List<Operation> operations) {
    // ...
    
    // 1. 计算运行能耗（需要去重批处理工序）
    double runEnergy = 0.0;
    List<Operation> uniqueOperations = removeBatchDuplicates(operations);  // ✅ 去重
    
    for (Operation op : uniqueOperations) {
        double duration = op.endTime - op.startTime;

    }
    
    // 2. 计算空闲间隔能耗（使用去重后的工序列表）
    for (int i = 0; i < uniqueOperations.size() - 1; i++) {  // ✅ 使用去重列表
        Operation current = uniqueOperations.get(i);
        Operation next = uniqueOperations.get(i + 1);
        // ...
    }
    
    // ...
}
```

#### 3. 在统计信息中也使用去重

```java

  - 批次1: [0.0, 5.0]  ← 只保留一个代表

计算能耗：
  runEnergy = 5.0 * P_run  ✅ 正确：只计算一次
```

## 去重判定标准

### 同一批次的判定条件
两个 `Operation` 属于同一批次，当且仅当：
1. 在同一台机器上（已经按机器分组）
2. `|op1.startTime - op2.startTime| < 0.001`
3. `|op1.endTime - op2.endTime| < 0.001`

### 为什么使用 0.001 的误差容忍度？
- 浮点数比较可能有精度误差
- 0.001 对于时间单位来说足够小（相当于 0.06 秒）
- 实际批次的时间差异远大于这个值

---

## 影响范围

### 受影响的机器类型
1. **打印机** (`PrintMachine`)
   - 一个批次可以打印多个零件
   - 这些零件的打印时间完全相同
   
2. **批处理机** (`BathchMachine`)
   - 一个批次可以同时处理多个零件
   - 这些零件的批处理时间完全相同

### 不受影响的机器类型
3. **离散加工机** (其他机器)
   - 每次只加工一个零件
   - 不会有时间重复的问题
   - 去重操作不会改变结果

## 总结

### 修复内容
✅ 添加了 `removeBatchDuplicates` 方法来去除重复的批处理工序  
✅ 在 `calculateMachineEnergy` 中使用去重后的工序列表  
✅ 在 `getStatistics` 中使用去重后的工序列表  
✅ 添加了调试输出来提示去重操作  

### 修复效果
✅ 避免了批处理设备的能耗重复计算  
✅ 能耗值更加准确和真实  
✅ 不影响离散加工机的能耗计算  
✅ 保持了代码的向后兼容性  

### 注意事项
⚠️ 此修复假设同一批次的所有零件具有**完全相同**的 `startTime` 和 `endTime`  
⚠️ 如果调度算法的实现不符合这个假设，需要调整去重逻辑  
⚠️ 浮点数误差容忍度设为 0.001，如果时间精度更高，可能需要调整

## 起始空闲段处理

### 新增功能（2026-01-08）

除了工序之间的空闲间隔，现在也会处理**起始空闲段**：
- **起始空闲段**：从时间 0 到第一个工序开始的时间段
- 也纳入开关机决策
- 也计算能耗

### 示例

假设一台机器的第一个工序在时间 10.0 开始：

```
时间轴：
  0.0                    10.0         15.0
   |<----起始空闲段---->|<--工序1-->|

起始空闲段长度：10.0
```

**能耗计算：**
```java
if (enableSwitchingStrategy) {
    if (shouldShutdown(10.0)) {
        energy = E_switch;  // 关机
    } else {
        energy = P_idle * 10.0;  // 待机
    }
}
```

## 时间单位说明

### 重要：时间单位转换

在能耗计算中：
- **调度系统使用"秒"作为时间单位**：`operation.startTime`、`operation.endTime`
- **能耗计算使用"小时"作为时间单位**：`kWh = kW × 小时`
- **自动转换**：`EnergyCalculator`内部自动进行单位转换

```java
// 自动转换常量
private static final double SECONDS_TO_HOURS = 1.0 / 3600.0;

// 使用示例
double durationSeconds = op.endTime - op.startTime;  // 秒
double durationHours = durationSeconds * SECONDS_TO_HOURS;  // 小时
energy = P_run * durationHours;  // kW × 小时 = kWh
```

详细说明请参考：`时间单位转换说明.md`
