# 编译问题解决指南

## ❌ 错误：找不到符号 - String.repeat(int)

### 错误信息

```
java: 找不到符号
  符号:   方法 repeat(int)
  位置: 类 java.lang.String
```

### 原因分析

`String.repeat()` 方法是 **Java 11** 引入的新特性。如果你使用的是 **Java 8**，就会出现这个错误。

### 解决方案

#### 方案1：清理并重新编译（推荐）

```bash
# 1. 运行清理脚本
clean_and_compile.bat

# 如果还是报错，继续下一步
```

#### 方案2：检查 Java 版本

```bash
# 运行版本检查脚本
check_java_version.bat

# 查看 Java 版本是否 >= 1.8
```

#### 方案3：清理 IDE 缓存

**IDEA 用户**：
```
1. File → Invalidate Caches / Restart...
2. 选择 "Invalidate and Restart"
3. 等待 IDE 重新索引
```

**Eclipse 用户**：
```
1. Project → Clean...
2. 选择 "Clean all projects"
3. 点击 OK
```

#### 方案4：手动清理 Maven 缓存

```bash
# Windows
cd chapter-3
rmdir /s /q target
mvn clean compile

# 或使用 PowerShell
Remove-Item -Path target -Recurse -Force
mvn clean compile
```

### 第2步：确认项目配置

检查 `pom.xml`：

```xml

    <maven.compiler.source>8</maven.compiler.source>
    <maven.compiler.target>8</maven.compiler.target>
</properties>
```

✅ **已确认**：项目配置为 Java 8

### 第3步：检查代码

项目中的 `repeatString` 方法已经是 Java 8 兼容的实现：

```java
// Java 8 兼容版本（当前使用）
private static String repeatString(String str, int count) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < count; i++) {
        sb.append(str);
    }
    return sb.toString();
}

// Java 11+ 版本（不使用）
// String.repeat(count)  ← 我们没有使用这个
```

✅ **已确认**：代码兼容 Java 8

### 第4步：清理并重新编译

# 方法2：手动命令

## 🐛 常见问题

### Q1: 为什么会出现这个错误？

**A**: 可能的原因：
1. **IDE 缓存问题** - IDE 可能缓存了旧的编译信息
2. **依赖冲突** - 某个依赖库可能使用了 Java 11 特性
3. **编译器版本不匹配** - IDE 使用的 Java 版本与 Maven 不同

### Q2: 项目明明配置了 Java 8，为什么还报错？

**A**: 
- 检查 IDE 的项目 JDK 设置
- 检查 JAVA_HOME 环境变量
- 确保 IDE 和 Maven 使用同一个 JDK

**IDEA 检查方法**：
```
File → Project Structure → Project Settings → Project
查看 Project SDK 是否为 JDK 8+
```

### Q3: 我已经清理了，还是报错怎么办？

**A**: 尝试以下步骤：
```bash
# 1. 删除 target 目录
rmdir /s /q target

# 2. 删除 IDE 配置
rmdir /s /q .idea
del *.iml

# 3. 重新导入项目
# 在 IDEA 中: File → Open → 选择 pom.xml → Open as Project
```

### Q4: 能否升级到 Java 11？

**A**: 可以，但不推荐：
- 项目设计为 Java 8 兼容
- 升级可能导致其他兼容性问题
- Java 8 已足够满足需求

如果确实需要升级：
```xml
<!-- pom.xml -->
<properties>
    <maven.compiler.source>11</maven.compiler.source>
    <maven.compiler.target>11</maven.compiler.target>
</properties>
```
