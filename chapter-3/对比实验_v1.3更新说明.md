## 🎯 设计目的

### 为什么需要基准算法？

在学术论文中，为了证明改进算法的有效性，需要：

1. **消融实验**：对比有/无改进策略的效果
2. **量化贡献**：计算每个改进模块的贡献度
3. **学术规范**：符合论文审稿要求

### 对比关系

```
算法对比：
- NSGA-II          ← 改进版（启发式初始化 + 局部搜索）
- NSGA-II-Basic    ← 基准版（混合初始化 + 无局部搜索）⭐ 新增
- MOEA/D
- MOGWO
- SPEA2
```

**`runNSGAIIBasic()`**

```java
/**
 * 运行NSGA-II-Basic（基础版：随机初始化 + 无局部搜索）
 */
private static List<MOIndividual> runNSGAIIBasic(
        Problem problem,
        List<MOEvaluator.ObjectiveFunction> objectives,
        long seed) {
    
    NSGAII nsgaii = new NSGAII(problem, objectives);
    nsgaii.setPopulationSize(POPULATION_SIZE);
    nsgaii.setCrossoverRate(CROSSOVER_RATE);
    nsgaii.setMutationRate(MUTATION_RATE);
    nsgaii.setMaxGenerations(MAX_GENERATIONS);
    nsgaii.setMaxRunTimeMinutes(MAX_RUN_TIME);
    nsgaii.setSeed(seed);
    
    // 基础版：不启用局部搜索
    
    return nsgaii.solve();
}
```

### 统计检验

```python
from scipy.stats import wilcoxon

# 提取数据
nsgaii = data[data['Algorithm']=='NSGAII']['HV']
nsgaii_basic = data[data['Algorithm']=='NSGAII-Basic']['HV']

# Wilcoxon检验
stat, p = wilcoxon(nsgaii, nsgaii_basic)

# 计算改进幅度
improvement = (nsgaii.mean() - nsgaii_basic.mean()) / nsgaii_basic.mean() * 100

print(f"p-value: {p:.6f}")
print(f"HV改进幅度: {improvement:.2f}%")

if p < 0.01:
    print("✅ NSGA-II显著优于NSGA-II-Basic (p<0.01)")
```
