## 📊 核心算法

### 1. 能耗计算（含开关机策略）

```python
function calculateTotalEnergy(operationMatrix, problem):
    E_total = 0
    
    for each machine:
        # 运行能耗
        E_run = Σ(P_run × duration)
        
        # 空闲能耗
        E_idle = 0
        for each gap between operations:
            T_be = E_switch / P_idle
            
            if gap >= T_warmup + T_be and allowSwitch:
                E_idle += E_switch  # 关机
            else:
                E_idle += P_idle × gap  # 待机
        
        E_total += E_run + E_idle
    
    return E_total
```

### 2. NSGA-II环境选择（含tie-breaker）

```python
function environmentalSelection(parent, offspring, N):
    R = parent ∪ offspring
    fronts = fastNonDominatedSort(R)
    
    nextPop = []
    i = 0
    
    while |nextPop| + |fronts[i]| <= N:
        assignCrowdingDistance(fronts[i])
        nextPop += fronts[i]
        i += 1
    
    if |nextPop| < N:
        assignCrowdingDistance(fronts[i])
        fronts[i].sort(by: -crowdingDistance, -packingQ, batchCount)
        nextPop += fronts[i][0 : N - |nextPop|]
    
    return nextPop
```

本文采用的能耗模型考虑了机器的运行能耗和空闲能耗。
