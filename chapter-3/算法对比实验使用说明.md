## 实验概述

本实验框架用于对比四种多目标进化算法在3D打印调度问题上的性能：

| 算法 | 全称 | 特点 |
|------|------|------|
| **NSGA-II** | Non-dominated Sorting Genetic Algorithm II | 经典多目标遗传算法，基于非支配排序 |
| **MOEA/D** | Multi-Objective Evolutionary Algorithm based on Decomposition | 基于分解的多目标进化算法 |
| **MOGWO** | Multi-Objective Grey Wolf Optimizer | 多目标灰狼优化算法 |
| **SPEA2** | Strength Pareto Evolutionary Algorithm 2 | 改进的强度Pareto进化算法 |

**实验设计**：
- 每个算例每个算法运行 **10次**
- 统一参数配置（种群大小、交叉率、变异率等）
- 计算三大核心指标：**HV、IGD、C-metric**
- 自动生成详细的对比报告

---

## 功能特性

### ✅ 核心功能

1. **多算法对比**
   - 同时运行4种算法
   - 统一实验条件
   - 公平性能对比

2. **三大评价指标**
   - **HV (Hypervolume)**：衡量收敛性+多样性
   - **IGD (Inverted Generational Distance)**：衡量与真实前沿的距离
   - **C-metric (Coverage)**：衡量算法间的支配关系

3. **灵活的运行模式**
   - 单个算例对比
   - 批量算例对比（J20/J50/J100）
   - 全部算例对比

4. **完整的结果输出**
   - 每次运行的Pareto前沿
   - 每个算法的汇总Pareto前沿
   - 所有算法的近似Pareto前沿（PF*）
   - 详细的对比报告

5. **多线程支持**
   - 自动检测CPU核心数
   - 并行运行实验
   - 显著缩短运行时间

## 性能指标说明

### 1️⃣ Hypervolume (HV) - 主指标

**定义**：Pareto前沿与参考点围成的超体积

**特点**：
- 同时衡量收敛性和多样性
- 多目标优化领域最权威的指标
- **越大越好**

**本实验的计算方法**：
1. 将所有目标值归一化到 [0, 1] 区间
2. 使用固定参考点 (1.1, 1.1)
3. 计算2D超体积

**报告中的数据**：
- 平均HV：10次运行的平均值
- 标准差：稳定性指标
- 最大HV/最小HV：性能范围

**论文写法示例**：
> "在J20P3B2D5_01算例上，NSGA-II的平均HV为0.856±0.012，显著优于MOEA/D（0.823±0.018）。"

---

### 2️⃣ IGD (Inverted Generational Distance)

**定义**：获得的Pareto前沿与参考Pareto前沿的平均距离

**特点**：
- 衡量算法的逼近能力
- 反映解集与真实前沿的差距
- **越小越好**

**本实验的计算方法**：
1. 计算近似Pareto前沿 PF* = 所有算法所有运行的非支配解合集
2. 对于PF*中的每个点，找到算法Pareto前沿中最近的点
3. 计算平均欧氏距离

**与HV的互补关系**：
- HV看"覆盖范围"（面积）
- IGD看"逼近程度"（距离）

**论文写法示例**：
> "IGD结果显示，NSGA-II（0.0123±0.0018）在逼近PF*方面优于其他算法。"

---

### 3️⃣ C-metric (Coverage Metric)

**定义**：算法A的解集支配算法B的解集的比例

$$C(A, B) = \frac{|\{x \in B | \exists y \in A: y \prec x\}|}{|B|}$$

**特点**：
- 直观反映算法间的支配关系
- 非对称指标：C(A,B) ≠ C(B,A)
- 值域 [0, 1]

**解读**：
- C(A, B) = 0.5：A的解集支配了B的50%
- C(A, B) = 0：A完全不支配B
- C(A, B) = 1：A完全支配B

**报告中的矩阵**：
```
              NSGAII    MOEAD     MOGWO     SPEA2
NSGAII        0.0000    0.4532    0.3821    0.2945
MOEAD         0.1234    0.0000    0.2156    0.1789
MOGWO         0.2345    0.3456    0.0000    0.2567
SPEA2         0.1678    0.2789    0.1234    0.0000
```

**论文写法示例**：
> "C-metric结果表明，NSGA-II对MOEA/D的支配率为45.32%，而MOEA/D对NSGA-II的支配率仅为12.34%，说明NSGA-II在该问题上具有明显优势。"

### 步骤2：画Pareto前沿对比图

使用各算法的 `AlgorithmParetoFront.txt` 文件：

**Python示例代码**：

```python
import matplotlib.pyplot as plt
import numpy as np

# 读取Pareto前沿
def read_pareto_front(file_path):
    data = np.loadtxt(file_path, skiprows=4)
    return data[:, 0], data[:, 1]  # Cmax, Energy

# 读取所有算法
algorithms = ['NSGAII', 'MOEAD', 'MOGWO', 'SPEA2']
colors = ['red', 'blue', 'green', 'orange']
markers = ['o', 's', '^', 'D']

plt.figure(figsize=(10, 6))

for alg, color, marker in zip(algorithms, colors, markers):
    file_path = f'output/comparison_experiment/J20P3B2D5_01_xxx/{alg}/AlgorithmParetoFront.txt'
    cmax, energy = read_pareto_front(file_path)
    plt.scatter(cmax, energy, c=color, marker=marker, label=alg, s=50, alpha=0.7)

plt.xlabel('Maximum Completion Time (Cmax)', fontsize=12)
plt.ylabel('Total Energy Consumption', fontsize=12)
plt.title('Pareto Front Comparison - J20P3B2D5_01', fontsize=14)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('pareto_comparison.png', dpi=300)
plt.show()
```

## 常见问题

### Q1: 运行时间太长怎么办？

**解决方案**：
1. 启用多线程（已默认启用）
2. 减少重复次数（从10改为5）
3. 降低最大运行时间（从5分钟改为3分钟）
4. 使用更少的算例

### Q2: 内存不足怎么办？

**解决方案**：
1. 增加JVM堆内存：
   ```bash
   export MAVEN_OPTS="-Xmx8g"
   mvn test -Dtest=AlgorithmComparisonExperimentRunner
   ```
2. 减少种群大小
3. 分批运行算例

### Q3: 如何只对比部分算法？

**修改代码**：

找到这一行：
```java
private static final String[] ALGORITHMS = {"NSGAII", "MOEAD", "MOGWO", "SPEA2"};
```

改为（例如只对比NSGA-II和MOEA/D）：
```java
private static final String[] ALGORITHMS = {"NSGAII", "MOEAD"};
```

### Q4: 如何使用不同的参数配置？

**方式一：修改常量**（所有算法使用相同参数）
```java
private static final int POPULATION_SIZE = 150;  // 改为150
```

**方式二：修改算法方法**（每个算法使用不同参数）
```java
private static List<MOIndividual> runNSGAII(...) {
    NSGAII nsgaii = new NSGAII(problem, objectives);
    nsgaii.setPopulationSize(150);  // NSGA-II用150
    // ...
}

private static List<MOIndividual> runMOEAD(...) {
    MOEAD moead = new MOEAD(problem, objectives);
    moead.setPopulationSize(100);   // MOEA/D用100
    // ...
}
```

### Q5: 如何添加更多指标？

参考 `PerformanceMetrics` 类和 `calculateMetrics` 方法，添加新的指标计算即可。
