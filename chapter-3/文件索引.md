## 📋 核心概念速查

### 能耗配置类型
| 类型 | 说明 | 典型场景 |
|------|------|----------|
| **ECO** | 节能型 | 桌面级打印机 |
| **STANDARD** ⭐ | 标准型 (推荐) | 工业级打印机 |
| **HEAVY** | 重载型 | 大型工业设备 |
| **TEMP** | 温度敏感型 | 热处理炉 |

### 能耗参数
| 参数 | 单位 | 说明 |
|------|------|------|
| P_run | kW | 运行功率 |
| P_idle | kW | 待机功率 |
| E_switch | kWh | 开关机能耗 |
| T_warmup | 秒 | 预热时间 |
| allowSwitch | 0/1 | 是否允许关机 |

### 关键公式
```
盈亏平衡时间: T_breakEven = E_switch / P_idle

开关机决策: if (gapDuration > T_breakEven + T_warmup) → 关机
           else → 待机
```
