# NSGA-II 输出功能整合完成

## ✅ 已完成的工作

### 1. 创建了完整的输出工具类

#### `ParetoFrontVisualizer.java`
- **功能**: 生成Pareto前沿图
- **输出**: PNG格式图表
- **坐标轴**: 
  - 横轴: 能耗 (kWh)
  - 纵轴: Cmax (最大完工时间)
- **特点**: 
  - 支持单条和多条Pareto前沿对比
  - 自动调整样式和字体
  - 使用JFreeChart库

#### `NSGAIIResultExporter.java`
- **功能**: 导出所有NSGA-II结果
- **输出内容**:
  1. Pareto前沿图 (`pareto_front.png`)
  2. Pareto前沿解集数据 (`pareto_front_data.txt`)
  3. 最优Cmax解的甘特图 (`best_cmax_gantt.png`)
  4. 最优Cmax解的打印批次排布图 (`best_cmax_printer_layout.png`)
  5. 详细调度记录 (`best_cmax_schedule_records.txt`)

- **详细记录包括**:
  - 基本信息（Cmax、能耗、装箱质量、批次数）
  - 染色体编码（OS和MS基因）
  - 零件加工顺序记录（每个工件的所有工序）
  - 机器加工顺序记录（每台机器加工的所有工序）
  - 打印批次详细信息（每个批次的零件列表和占用率）

### 2. 更新了NSGAIIRunner主程序

- **修改**: 在`saveResults`方法中集成了`NSGAIIResultExporter`
- **输出目录结构**: `chapter-3/output/nsgaii_YYYYMMDD_HHMMSS/`
- **自动生成**: 运行NSGA-II后自动生成所有可视化图表和详细记录

### 3. 创建了测试程序

#### `QuickTestWithOutput.java`
- **功能**: 快速测试所有输出功能
- **特点**: 
  - 使用小规模参数（种群20，代数50）
  - 快速验证输出功能是否正常
  - 输出到固定目录 `chapter-3/output/quick_test/`

### 4. 创建了详细的使用文档

#### `NSGAII输出说明.md`
- **内容**:
  - 输出目录结构说明
  - 每个输出文件的详细解释
  - 示例图表和数据格式
  - 如何使用输出结果
  - 常见问题解答

## 🚀 使用方法

### 方法1: 使用NSGAIIRunner（推荐）

```java
// 运行NSGAIIRunner.java
// 会自动生成所有输出
public static void main(String[] args) {
    // ... 配置和运行NSGA-II ...
    // 输出会自动保存到 chapter-3/output/nsgaii_YYYYMMDD_HHMMSS/
}
```

### 方法2: 使用QuickTestWithOutput（快速测试）

```java
// 运行QuickTestWithOutput.java
// 使用小规模参数快速测试输出功能
public static void main(String[] args) {
    // 输出会保存到 chapter-3/output/quick_test/
}
```

### 方法3: 手动调用NSGAIIResultExporter

```java
// 在你的代码中手动调用
List<MOIndividual> paretoFront = nsgaii.run();
Operation[][] operationMatrix = createOperationMatrix(problem);
NSGAIIResultExporter exporter = new NSGAIIResultExporter(problem, operationMatrix);
exporter.exportAllResults(paretoFront, "output/my_results");
```

## 📝 注意事项

### 1. 依赖库
确保项目中包含以下依赖：
- **JFreeChart**: 用于生成图表
- **Jackson**: 用于JSON输出（如果需要）

### 2. 算例文件
- 确保算例文件路径正确
- 算例文件需要包含能耗参数（使用`EnergyAwareInput`读取）

### 3. 输出目录
- 程序会自动创建输出目录
- 确保有写入权限

### 4. 图表生成
- 图表生成需要一定时间，特别是大规模问题
- 如果图表生成失败，检查JFreeChart依赖是否正确
