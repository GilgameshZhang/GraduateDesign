# 工序机器分配修复说明

## 问题描述

在算例生成时，所有工序的候选机器都是从全部机器中随机选择，导致：
- 打印工序可能选到批处理机或离散加工机
- 批处理工序可能选到打印机或离散加工机
- 离散加工工序可能选到打印机或批处理机

这与实际生产流程不符。

## 3D打印车间调度流程

```
工件 → 打印 → 批处理 → 离散加工1 → 离散加工2 → ... → 完成
        ↓        ↓          ↓            ↓
      打印机   批处理机   离散加工机    离散加工机
```

**工序类型：**
1. **第1道工序**：打印工序 → 只能在**打印机**上加工
2. **第2道工序**：批处理工序 → 只能在**批处理机**上加工
3. **第3道及以后工序**：离散加工工序 → 只能在**离散加工机**上加工

## 解决方案

### 修改前（错误）

```java
// 为每道工序生成备选机器和加工时间
for (int opId = 0; opId < opsCount; opId++) {

        }
    }
}
```

### 修改后（正确）

```java
// 为每道工序生成备选机器和加工时间
for (int opId = 0; opId < opsCount; opId++) {
    // 根据工序类型确定可选机器范围 ✅
    int machineStart, machineEnd, machineTypeCount;
    
    if (opId == 0) {
        // 第1道工序：打印工序，只能选择打印机
        machineStart = 0;
        machineEnd = printCount;
        machineTypeCount = printCount;
    } else if (opId == 1) {
        // 第2道工序：批处理工序，只能选择批处理机
        machineStart = printCount;
        machineEnd = printCount + batchCount;
        machineTypeCount = batchCount;
    } else {
        // 第3道及以后工序：离散加工工序，只能选择离散加工机
        machineStart = printCount + batchCount;
        machineEnd = totalMachines;
        machineTypeCount = discreteCount;
    }
    
    // 备选机器数 (1到该类型机器总数，最多3台)
    int maxCandidates = Math.min(3, machineTypeCount);
    int candidateCount = 1 + random.nextInt(maxCandidates);
    writer.write(" " + candidateCount);
    
    // 从该类型机器中随机选择 ✅
    boolean[] selected = new boolean[machineTypeCount];
    int selectedCount = 0;
    
    while (selectedCount < candidateCount) {
        int relativeId = random.nextInt(machineTypeCount);
        if (!selected[relativeId]) {
            selected[relativeId] = true;
            selectedCount++;
            
            int actualMachineId = machineStart + relativeId;
            
            // 根据工序类型生成不同的加工时间 ✅
            int processingTime;
            if (opId == 0) {
                // 打印工序：时间较长 (1200-3600秒, 20-60分钟)
                processingTime = 1200 + random.nextInt(2401);
            } else if (opId == 1) {
                // 批处理工序：时间中等 (900-1800秒, 15-30分钟)
                processingTime = 900 + random.nextInt(901);
            } else {
                // 离散加工工序：时间较短 (300-900秒, 5-15分钟)
                processingTime = 300 + random.nextInt(601);
            }
            
            writer.write(String.format(" %d %d", actualMachineId + 1, processingTime));
        }
    }
}
```

## 关键改进

### 1. 机器范围划分

```
机器ID分布（1-based）:
┌─────────────┬──────────────┬─────────────────┐
│   打印机    │  批处理机    │  离散加工机     │
├─────────────┼──────────────┼─────────────────┤
│  1 ~ P      │ P+1 ~ P+B    │ P+B+1 ~ P+B+D   │
└─────────────┴──────────────┴─────────────────┘

示例（P=2, B=1, D=2）:
  M1, M2     │     M3       │    M4, M5
```

### 2. 工序类型识别

```java
if (opId == 0)      → 打印工序   → 选择打印机   [1, P]
else if (opId == 1) → 批处理工序 → 选择批处理机 [P+1, P+B]
else                → 离散加工   → 选择离散机   [P+B+1, P+B+D]
```

### 3. 加工时间差异化

不同类型工序有不同的时间特征：

| 工序类型 | 时间范围 | 说明 |
|---------|---------|------|
| 打印 | 1200-3600秒 (20-60分钟) | 时间最长，是瓶颈工序 |
| 批处理 | 900-1800秒 (15-30分钟) | 时间中等 |
| 离散加工 | 300-900秒 (5-15分钟) | 时间较短 |

这更符合实际生产情况。

## 相关问题

### Q1: 为什么不在第2道工序之后随机选择机器类型？

**A:** 3D打印车间的工艺流程是固定的：
- 所有工件都需要**先打印**（第1道）
- 然后**批处理去除支撑**（第2道）
- 最后进行**离散加工**（第3+道）

这是工艺约束，不能改变。

### Q2: 工件可以有不同的工序数吗？

**A:** 可以。工序数在2-10之间随机：
- 至少2道（打印+批处理）
- 最多10道（打印+批处理+8道离散加工）

### Q3: 可以跳过批处理工序吗？

**A:** 当前实现中，所有工件都至少有2道工序（打印+批处理）。如果需要某些工件跳过批处理，需要修改生成逻辑。
