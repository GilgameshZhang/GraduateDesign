# 对比实验快速指南

## 🚀 快速开始（3步完成）

### 步骤1：运行对比实验

**Windows用户**：
```bash
双击运行: run_comparison.bat
```

**Mac/Linux用户**：
```bash
cd chapter-3
mvn clean compile test -Dtest=AlgorithmComparisonExperimentRunner
```

### 步骤2：选择运行模式

根据提示选择：
```
1. 单个算例对比     ← 推荐：首次运行（约15-30分钟）
2. J20批量对比      ← 小规模批量（约1-2小时）
3. J50批量对比      ← 中规模批量（约2-4小时）
4. J100批量对比     ← 大规模批量（约4-8小时）
5. 全部算例对比     ← 完整实验（约8-15小时）
```

### 步骤3：查看结果

结果保存在：
```
chapter-3/output/comparison_experiment/算例名称_时间戳/
```

关键文件：
- `ComparisonReport.txt` - 📊 详细对比报告（论文数据来源）
- `NSGAII/AlgorithmParetoFront.txt` - 🎨 NSGA-II的汇总Pareto前沿（画图用）
- `MOEAD/AlgorithmParetoFront.txt` - 🎨 MOEA/D的汇总Pareto前沿（画图用）
- `MOGWO/AlgorithmParetoFront.txt` - 🎨 MOGWO的汇总Pareto前沿（画图用）
- `SPEA2/AlgorithmParetoFront.txt` - 🎨 SPEA2的汇总Pareto前沿（画图用）

## 📖 论文写作模板

### 实验设置

> 本文采用四种经典多目标进化算法进行对比：NSGA-II、MOEA/D、MOGWO和SPEA2。所有算法采用相同的参数配置：种群大小为100，交叉率为0.9，变异率为0.1，最大运行时间为5分钟。为保证结果的可靠性，每个算例每个算法独立运行10次。采用三个经典性能指标进行评价：Hypervolume（HV）、Inverted Generational Distance（IGD）和C-metric。

### 结果描述

> 表X展示了四种算法在J20系列算例上的性能对比。从HV指标来看，本文提出的NSGA-II算法平均HV为0.856±0.012，显著优于MOEA/D（0.823±0.018）、MOGWO（0.835±0.016）和SPEA2（0.846±0.013）。Wilcoxon秩和检验表明，NSGA-II与其他算法的性能差异在统计上显著（p < 0.01）。IGD结果进一步验证了NSGA-II的优越性，其平均IGD为0.0123±0.0018，在所有算法中最小，表明NSGA-II获得的Pareto前沿最接近真实前沿。

> C-metric结果揭示了算法间的支配关系。NSGA-II对MOEA/D的支配率为45.32%，而反向支配率仅为12.34%，充分说明了NSGA-II的优势。图X展示了各算法在目标空间的分布，可以观察到NSGA-II的Pareto前沿具有更好的收敛性和多样性。

## 🎯 性能指标快速解读

### HV (Hypervolume)
- **含义**：Pareto前沿覆盖的超体积
- **越大越好**
- **主指标**：收敛性+多样性

**示例**：
```
NSGAII: 0.856 ± 0.012  ✅ 最好
SPEA2:  0.846 ± 0.013
MOGWO:  0.835 ± 0.016
MOEAD:  0.823 ± 0.018  ❌ 最差
```

### IGD (Inverted Generational Distance)
- **含义**：与参考前沿的平均距离
- **越小越好**
- **互补指标**：逼近程度

**示例**：
```
NSGAII: 0.0123 ± 0.0018  ✅ 最好（最接近PF*）
SPEA2:  0.0157 ± 0.0015
MOGWO:  0.0182 ± 0.0018
MOEAD:  0.0235 ± 0.0023  ❌ 最差
```

### C-metric (Coverage)
- **含义**：A支配B的比例
- **非对称**：C(A,B) ≠ C(B,A)
- **直观指标**：支配关系

**示例**：
```
C(NSGAII, MOEAD) = 0.4532  → NSGA-II支配MOEA/D的45.32%
C(MOEAD, NSGAII) = 0.1234  → MOEA/D只支配NSGA-II的12.34%
结论：NSGA-II显著优于MOEA/D
```

## 🔧 故障排除

### 问题1：编译失败

**原因**：缺少依赖或代码错误

**解决**：
```bash
mvn clean install
```

### 问题2：内存不足

**原因**：大规模算例+多线程

**解决**：
```bash
export MAVEN_OPTS="-Xmx8g"
mvn test -Dtest=AlgorithmComparisonExperimentRunner
```

### 问题3：运行时间过长

**解决方案**：
1. 减少重复次数：`REPEAT_TIMES = 5`
2. 降低运行时间：`MAX_RUN_TIME = 3.0`
3. 减小种群：`POPULATION_SIZE = 50`
4. 分批运行算例

### 问题4：Python画图失败

**原因**：缺少依赖

**解决**：
```bash
pip install numpy matplotlib seaborn scipy pandas
```

如果是中文显示问题：
```bash
# Windows: 确保安装了SimHei字体
# Mac: 使用 STHeiti 或 PingFang
# Linux: 安装 wqy-zenhei
```
