## ⚙️ 算法参数配置

如果要修改算法参数，编辑 `MainEntry.java` 中的常量：

```java
// 算法参数（在MainEntry.java顶部）
private static final int POPULATION_SIZE = 100;      // 种群规模
private static final int MAX_GENERATION = 200;       // 最大代数
private static final double CROSSOVER_RATE = 0.9;    // 交叉率
private static final double MUTATION_RATE = 0.1;     // 变异率
```

**推荐参数**：

| 算例规模 | 种群规模 | 最大代数 | 说明 |
|---------|---------|---------|------|
| 小规模 (J10) | 50-100 | 100-200 | 快速收敛 |
| 中等规模 (J20) | 100-150 | 200-300 | 平衡效率和质量 |
| 大规模 (J30+) | 150-200 | 300-500 | 需要更多代数 |

## 🔍 常见问题

### Q1: 算例文件不存在怎么办？

**A**: 先运行 `GenerateTestInstances.java` 生成算例。

### Q2: 如何使用自己的算例？

**A**: 修改 `MainEntry.java` 中的 `selectInstance()` 方法：

```java
private static String selectInstance() {
    return "你的算例路径.txt";
}
```

### Q3: 优化结果不理想怎么办？

**A**: 尝试：
1. 增加种群规模 (`POPULATION_SIZE`)
2. 增加最大代数 (`MAX_GENERATION`)
3. 运行多次，选择最好的结果

### Q4: 如何添加更多目标？

**A**: 在 `MainEntry.java` 中添加目标函数：

```java
objectives.add(new MOEvaluator.TotalTardiness());  // 拖期
objectives.add(new MOEvaluator.TotalBatchWaitingTime());  // 等待时间
```

同时修改 `MOIndividual` 的创建：
```java
MOIndividual individual = new MOIndividual(chromosome, 3);  // 改为3个目标
```
