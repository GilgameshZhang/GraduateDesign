## 🎯 使用流程

### 方式1：快速开始（推荐新手）

```bash
1. 双击 run_taguchi_experiment.bat
2. 选择算例（建议首选1-小规模）
3. 等待完成（10-60分钟）
4. 查看结果报告
```

### 方式2：IDE运行（推荐开发者）

```bash
1. IDEA打开 NSGAIITaguchiExperimentRunner.java
2. 右键 main 方法 -> Run
3. 控制台选择算例
4. 查看结果
```

### 方式3：命令行运行

```bash
cd chapter-3
mvn clean compile
mvn test -Dtest=NSGAIITaguchiExperimentRunner
```

### L9正交表

| 实验 | popSize | crossoverRate | mutationRate | localSearchL |
|------|---------|---------------|--------------|--------------|
| 1    | 50      | 0.70         | 0.10        | 5            |
| 2    | 50      | 0.80         | 0.20        | 10           |
| 3    | 50      | 0.90         | 0.30        | 20           |
| 4    | 100     | 0.70         | 0.20        | 20           |
| 5    | 100     | 0.80         | 0.30        | 5            |
| 6    | 100     | 0.90         | 0.10        | 10           |
| 7    | 150     | 0.70         | 0.30        | 10           |
| 8    | 150     | 0.80         | 0.10        | 20           |
| 9    | 150     | 0.90         | 0.20        | 5            |

**说明**: localSearchL 表示每个精英个体的局部搜索尝试次数，局部搜索每代都执行。

### 固定参数

- **最大代数**: 500代
- **最大运行时间**: 2分钟
- **局部搜索**: 启用
- **重复次数**: 10次/组
- **评价指标**: 超体积(HV)

## 🔧 自定义配置

### 修改参数范围

```java
int[][] l9OrthogonalArray = {
    // A     B    C    D
    {  50,  70,  10,  5},  // 实验1: 修改这里
    {  50,  80,  20, 10},  // 实验2: 修改这里
    // ...
};
```

### 修改重复次数

第32行：
```java
private static final int REPEAT_TIMES = 10;  // 改为5或20
```

### 修改运行时间

第35行：
```java
private static final double MAX_RUN_TIME = 2.0;  // 单位：分钟
```

第38行：
```java
private static final int MAX_GENERATIONS = 500;
```
