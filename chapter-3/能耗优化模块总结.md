## 📊 核心算法逻辑

### 能耗计算（开关机策略）

```
对每台机器:
    E_run = Σ(P_run × 工序时长)
    
    对每个空闲间隔:
        T_be = E_switch / P_idle
        
        if gap >= T_warmup + T_be and allowSwitch:
            E_gap = E_switch  (关机)
        else:
            E_gap = P_idle × gap  (待机)
    
    E_machine = E_run + Σ(E_gap)

E_total = Σ(E_machine)
```

### NSGA-II环境选择（含tie-breaker）

```
1. 合并种群: R = P ∪ Q
2. 非支配排序: fronts = fastNonDominatedSort(R)
3. 依次添加前沿到nextPop，直到超过N
4. 对最后一个前沿:
   a) 计算拥挤距离
   b) 排序: crowdingDistance ↓ → packingQ ↓ → batchCount ↑
   c) 选择前 (N - |nextPop|) 个个体
5. 返回 nextPop
```

## 🔧 可配置参数

### 1. 机器能耗参数（可自定义）

```java
PowerParameters params = new PowerParameters(
    5.0,    // P_run (kW) - 运行功率
    0.5,    // P_idle (kW) - 待机功率
    2.0,    // E_switch (kWh) - 开关机能耗
    5.0,    // T_warmup - 预热时间
    true    // allowSwitch - 允许关机
);
```

**推荐值**：
- 打印机（FDM）：`(5.0, 0.5, 2.0, 5.0, true)`
- 批处理机（热处理）：`(3.0, 0.8, 5.0, 20.0, false)` ← 不允许关机
- 离散加工机（CNC）：`(2.0, 0.3, 1.0, 3.0, true)`

## 🎓 理论基础

### 能耗模型

**参考文献**：
- Che, A., et al. (2022). "Energy-efficient bi-objective single-machine scheduling with power-down mechanism." *Computers & Operations Research*.

**盈亏平衡时间**：
```
T_breakEven = E_switch / P_idle
```

**关机条件**：
```
gap >= T_warmup + T_breakEven
```

### NSGA-II算法

**参考文献**：
- Deb, K., et al. (2002). "A fast and elitist multiobjective genetic algorithm: NSGA-II." *IEEE Transactions on Evolutionary Computation*.

**时间复杂度**：
- 非支配排序：O(MN²)
- 拥挤距离：O(MN log N)
