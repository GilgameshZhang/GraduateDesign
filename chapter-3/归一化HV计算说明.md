# 归一化HV计算 - 最终方案

## 🎯 最终方案：归一化 + 固定参考点(1.1, 1.1)

### 核心思想

1. **归一化**：将所有目标值归一化到 [0, 1] 区间
2. **固定参考点**：使用统一的参考点 (1.1, 1.1)
3. **可比性**：不同算例之间HV值也可以比较

---

## 📊 完整流程

### 三阶段法

```
阶段1: 运行所有实验 (90次)
       ↓
       记录所有Pareto前沿
       
阶段2: 归一化处理
       ↓
       找出全局最小值和最大值
       min = [minCmax, minEnergy]
       max = [maxCmax, maxEnergy]
       
阶段3: 计算HV
       ↓
       对每个Pareto前沿:
         1. 归一化: (value - min) / (max - min)
         2. 计算HV: 使用参考点(1.1, 1.1)
```

---

## 💻 实现细节

### 归一化公式

```
归一化值 = (原始值 - 最小值) / (最大值 - 最小值)

示例:
  原始Cmax范围: [100, 200]
  归一化后: [0, 1]
  
  原始值=150 → 归一化值 = (150-100)/(200-100) = 0.5
  原始值=100 → 归一化值 = (100-100)/(200-100) = 0.0
  原始值=200 → 归一化值 = (200-100)/(200-100) = 1.0
```

### 代码实现

```java
/**
 * 计算归一化范围
 */
private static NormalizationInfo calculateNormalizationRange(
        List<List<List<MOIndividual>>> allParetoFronts) {
    
    double[] minValues = new double[2];
    double[] maxValues = new double[2];
    Arrays.fill(minValues, Double.POSITIVE_INFINITY);
    Arrays.fill(maxValues, Double.NEGATIVE_INFINITY);
    
    // 遍历所有实验
    for (List<List<MOIndividual>> groupFronts : allParetoFronts) {
        for (List<MOIndividual> paretoFront : groupFronts) {
            for (MOIndividual ind : paretoFront) {
                // 更新最小值和最大值
                minValues[0] = Math.min(minValues[0], ind.objectives[0]);
                minValues[1] = Math.min(minValues[1], ind.objectives[1]);
                maxValues[0] = Math.max(maxValues[0], ind.objectives[0]);
                maxValues[1] = Math.max(maxValues[1], ind.objectives[1]);
            }
        }
    }
    
    return new NormalizationInfo(minValues, maxValues);
}

/**
 * 归一化Pareto前沿
 */
private static List<MOIndividual> normalizeParetoFront(
        List<MOIndividual> front,
        double[] minValues,
        double[] maxValues) {
    
    List<MOIndividual> normalizedFront = new ArrayList<>();
    
    for (MOIndividual ind : front) {
        MOIndividual normalized = new MOIndividual(ind);
        
        // 归一化各目标值到[0,1]
        for (int i = 0; i < ind.objectives.length; i++) {
            double range = maxValues[i] - minValues[i];
            if (range > 0) {
                normalized.objectives[i] = 
                    (ind.objectives[i] - minValues[i]) / range;
            } else {
                normalized.objectives[i] = 0.0;
            }
        }
        
        normalizedFront.add(normalized);
    }
    
    return normalizedFront;
}

/**
 * 计算HV（使用归一化数据和固定参考点）
 */
double[] referencePoint = {1.1, 1.1};  // 固定参考点
List<MOIndividual> normalizedFront = normalizeParetoFront(front, min, max);
double hv = NSGAIIOperations.calculateHypervolume2D(normalizedFront, referencePoint);
```

## 🎯 归一化的优势

### 1. 消除量纲差异

**问题**：Cmax和Energy的量纲不同

```
原始值：
  Cmax: 100-200 (范围=100)
  Energy: 400-600 (范围=200)
  
Energy的变化比Cmax大一倍，HV计算时Energy影响更大 ❌
```

**解决**：归一化后量纲统一

```
归一化后：
  Cmax: 0.0-1.0 (范围=1.0)
  Energy: 0.0-1.0 (范围=1.0)
  
两个目标平等，HV计算公平 ✅
```

### 2. 固定参考点

**原来**：每个算例参考点不同

```
算例J20: 参考点 = [180, 550]  → HV值
算例J50: 参考点 = [450, 1200] → HV值
无法直接比较！❌
```

**现在**：所有算例使用相同参考点

```
算例J20: 归一化后参考点 = [1.1, 1.1] → HV值
算例J50: 归一化后参考点 = [1.1, 1.1] → HV值
可以直接比较！✅
```

### 3. HV值有界

**归一化后HV值范围**：

```
理论最小值: 0.0 (空前沿)
理论最大值: 1.21 (1.1 × 1.1)
实际范围: 通常在 [0.5, 1.0] 之间
```

**便于解读**：
- HV = 0.8：表示覆盖了80%的理论最大超体积
- HV = 0.9：表示覆盖了90%的理论最大超体积

## 🔬 理论分析

### 为什么参考点是(1.1, 1.1)？

**归一化后的目标空间**：

```
归一化Energy
↑
1.1├────────────────R (参考点 1.1, 1.1)
   │   ╱──╲         │
1.0├──╱────╲────────┤  ← 最差解（归一化=1.0）
   │ ●──●───●──●    │  ← Pareto前沿（归一化≈0.0-0.8）
0.5│                 │
   │                 │
0.0├─────────────────┼──→ 归一化Cmax
   0.0             1.0 1.1

说明:
- 归一化后，最好的解接近(0, 0)
- 最差的解接近(1, 1)
- 参考点(1.1, 1.1)确保覆盖所有解（10%边界）
- HV衡量从(1.1, 1.1)到Pareto前沿的空间
```

### HV理论最大值

```
如果Pareto前沿是单个点(0, 0)：
HV_max = (1.1 - 0) × (1.1 - 0) = 1.21

实际中Pareto前沿是曲线：
HV_实际 < 1.21

典型值：
  优秀算法: HV > 0.85
  一般算法: HV ≈ 0.70
  较差算法: HV < 0.60
```

## 🔍 注意事项

### 1. 归一化范围的确定

**关键**：必须基于所有实验的数据

```
✅ 正确：
  - 运行所有90次实验
  - 找出全局最小值和最大值
  - 所有实验使用相同的归一化范围

❌ 错误：
  - 每个实验独立归一化
  - 会导致HV值不可比
```

### 2. 参考点的选择

**为什么是(1.1, 1.1)？**

```
归一化后：
  最优解接近: (0, 0)
  最差解接近: (1, 1)
  
参考点(1.1, 1.1):
  - 比最差解大10%
  - 确保覆盖所有解
  - 标准做法
```

**可以改为(1.2, 1.2)吗？**

可以，但不推荐：
- 增加安全边界会降低HV敏感度
- (1.1, 1.1)是多目标优化的标准选择

### 3. 极端情况处理

**范围为0的情况**：

```java
if (range > 0) {
    normalized = (value - min) / range;
} else {
    normalized = 0.0;  // 所有解相同时
}
```
