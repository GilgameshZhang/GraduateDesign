## ⚡ 开关机策略说明

### 什么是智能开关机策略？

当机器空闲时间足够长时，将机器关机以节省能耗。

#### 判定条件

```
空闲时间 >= T_warmup + T_breakEven

其中：
- T_warmup: 开机预热时间
- T_breakEven: 盈亏平衡时间 = E_switch / P_idle
- E_switch: 开关机能耗
- P_idle: 待机功率
```

#### 能耗对比

| 策略 | 空闲能耗计算 | 适用场景 |
|------|------------|---------|
| **智能开关机** | min(待机能耗, 开关机能耗) | NSGA-II |
| **纯待机** | 待机能耗 | 其他算法 |

**节能效果**：通常可节省10-30%的空闲能耗

## 🔧 代码实现

### 修改位置

**文件**：`AlgorithmComparisonExperimentRunner.java`

**修改1**：目标函数配置方法

```java
/**
 * 配置目标函数
 * 
 * @param problem 问题实例
 * @param enableSwitchingStrategy 是否启用智能开关机策略
 */
private static List<MOEvaluator.ObjectiveFunction> configureObjectives(
        Problem problem, boolean enableSwitchingStrategy) {
    List<MOEvaluator.ObjectiveFunction> objectives = new ArrayList<>();
    
    // 目标1: 最大完工时间
    objectives.add(new MOEvaluator.MaximumCompletionTime());
    
    // 目标2: 总能耗（可配置开关机策略）
    objectives.add(new MOEvaluator.TotalEnergyConsumption(
        problem, enableSwitchingStrategy, false));
    
    return objectives;
}
```

**修改2**：为每个算法配置不同的策略

```java
// 为每个算法配置目标函数
// NSGA-II启用开关机策略，其他算法关闭开关机策略
boolean enableSwitchingStrategy = algorithm.equals("NSGAII");
List<MOEvaluator.ObjectiveFunction> objectives = configureObjectives(
    problem, enableSwitchingStrategy);

if (enableSwitchingStrategy) {
    System.out.println("  ⚡ 能耗策略: 智能开关机策略（已启用）");
} else {
    System.out.println("  ⚡ 能耗策略: 纯待机策略（开关机已关闭）");
}
```

## 📈 实验分析要点

### 1. 能耗降低幅度

```
节能率 = (Energy_待机 - Energy_开关机) / Energy_待机 × 100%

预期：10-30%
```

### 2. 开关机触发频率

```
触发率 = 开关机次数 / 总空闲次数 × 100%

典型：20-40%（取决于调度方案）
```

### 3. 对Cmax的影响

```
Cmax影响 = (Cmax_开关机 - Cmax_待机) / Cmax_待机 × 100%

预期：< 1%（开关机主要影响能耗，对Cmax影响很小）
```

## 🔧 问题排查

### Q1: 如何确认开关机策略是否生效？

**方法1**：查看控制台输出
```
运行算法: NSGAII
⚡ 能耗策略: 智能开关机策略（已启用）
```

**方法2**：对比能耗值
- NSGA-II的能耗应明显低于其他算法
- 如果差距很小（<5%），可能策略未生效

**方法3**：查看代码调用
```java
// 应该看到这样的配置
```
