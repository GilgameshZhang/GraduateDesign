## 📊 实现方式

### 之前的状况

```java
public class Machine {
    public String name;
    public Double eneragyCost;  // 只有一个简单的Double字段
}
```

**问题**：
- ❌ 只能存储单一能耗值
- ❌ 无法表达完整的能耗模型（运行功率、待机功率、开关机等）

### 现在的实现 ✅

```java
public class Machine {
    public String name;
    public Double eneragyCost;          // 保留向后兼容
    public PowerParameters powerParams;  // ✅ 新增：完整的能耗参数
    
    // ✅ 提供便捷方法
    public void setPowerParameters(PowerParameters params);
    public PowerParameters getPowerParameters();
    public boolean hasPowerParameters();
}
```

**优势**：
- ✅ 完整的能耗模型（P_run, P_idle, E_switch, T_warmup, allowSwitch）
- ✅ 向后兼容（保留原有 eneragyCost 字段）
- ✅ 面向对象设计（能耗参数直接存储在机器对象中）
- ✅ EnergyCalculator 可以直接从机器读取参数

### 示例1：从算例文件读取（推荐）⭐

```java

// 2. 查看机器是否已携带能耗参数

    if (machines[i].hasPowerParameters()) {
        System.out.println("机器 " + (i+1) + " 已配置能耗参数:");
        System.out.println("  " + machines[i].getPowerParameters());
    }
}

// 3. 创建能耗计算器（自动从机器读取参数）

// 4. 计算能耗（使用机器自带的参数）
double energy = calculator.calculateTotalEnergy(operationMatrix, problem);
```

## 🔧 EnergyCalculator 的读取逻辑

### 优先级

```java
private void initializeDefaultParameters(Problem problem) {
    Machine[] machines = problem.getMachines();
    
    for (int i = 0; i < machines.length; i++) {
        PowerParameters params = null;
        
        // 【优先级1】从机器对象读取
        if (machines[i].hasPowerParameters()) {
            params = machines[i].getPowerParameters();
            // ✅ 使用机器自带参数
        } else {
            // 【优先级2】使用类型默认值
            if (machines[i] instanceof PrintMachine) {
                params = PowerParameters.createPrintMachineDefault();
            } else if (machines[i] instanceof BathchMachine) {
                params = PowerParameters.createBatchMachineDefault();
            } else {
                params = PowerParameters.createDiscreteMachineDefault();
            }
            // ⚠️ 使用默认参数
        }
        
        machineParams.put(i, params);
    }
}
```

## 📝 完整工作流程示例

```java
public class CompleteEnergyWorkflow {
    public static void main(String[] args) throws Exception {
        // ========== 步骤1：生成算例 ==========
        System.out.println("【步骤1】生成含能耗参数的算例");
        
        EnergyAwareInstanceGenerator generator = 
            new EnergyAwareInstanceGenerator(42, true);
        
        generator.generateInstance(20, 3, 2, 5, "instance_with_energy.txt");
        System.out.println("  ✓ 算例生成完成\n");
        
        // ========== 步骤2：读取算例 ==========
        System.out.println("【步骤2】读取算例");
        
        EnergyAwareInput input = new EnergyAwareInput(
            new File("instance_with_energy.txt"));
        Problem problem = input.getProblemDesFromFile();
        
        System.out.println("  ✓ 算例读取完成");
        System.out.println("  ✓ 工件数: " + problem.getJobCount());
        System.out.println("  ✓ 机器数: " + problem.getMachineCount() + "\n");
        
        // ========== 步骤3：验证能耗参数 ==========
        System.out.println("【步骤3】验证机器能耗参数");
        
        Machine[] machines = problem.getMachines();
        for (int i = 0; i < machines.length; i++) {
            if (machines[i].hasPowerParameters()) {
                PowerParameters p = machines[i].getPowerParameters();
                System.out.println(String.format(
                    "  ✓ 机器%d: P_run=%.2f, P_idle=%.2f, T_be=%.2f",
                    i+1, p.P_run, p.P_idle, p.getBreakEvenTime()));
            }
        }
        System.out.println();
        
        // ========== 步骤4：定义多目标 ==========
        System.out.println("【步骤4】定义多目标函数");
        
        List<MOEvaluator.ObjectiveFunction> objectives = new ArrayList<>();
        objectives.add(new MOEvaluator.MaximumCompletionTime());
        objectives.add(new MOEvaluator.TotalEnergyConsumption(problem, true, false));
        
        System.out.println("  ✓ 目标1: Cmax");
        System.out.println("  ✓ 目标2: Energy (含开关机策略)\n");
        
        // ========== 步骤5：初始化种群 ==========
        System.out.println("【步骤5】初始化种群");
        
        List<MOIndividual> population = initializePopulation(problem, 50);
        System.out.println("  ✓ 种群规模: 50\n");
        
        // ========== 步骤6：评价种群 ==========
        System.out.println("【步骤6】评价种群（使用机器能耗参数）");
        
        MOEvaluator evaluator = new MOEvaluator();
        for (MOIndividual ind : population) {
            Operation[][] operationMatrix = createOperationMatrix(problem);
            evaluator.evaluate(ind, problem, operationMatrix, objectives);
        }
        
        System.out.println("  ✓ 评价完成");
        System.out.println("  ✓ 每个个体包含2个目标值: [Cmax, Energy]\n");
        
        // ========== 步骤7：输出结果 ==========
        System.out.println("【步骤7】输出前5个个体的目标值");
        
        for (int i = 0; i < Math.min(5, population.size()); i++) {
            MOIndividual ind = population.get(i);
            System.out.println(String.format(
                "  个体%d: Cmax=%.2f, Energy=%.2f kWh",
                i+1, ind.objectives[0], ind.objectives[1]));
        }
        
        System.out.println("\n✅ 完整工作流程演示完成！");
        System.out.println("✅ 机器能耗参数已成功传递并使用！");
    }
    
    // ... 辅助方法 ...
}
```
