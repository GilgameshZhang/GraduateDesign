## 🎯 核心功能总览

### 支持的算法（5种）

| 算法 | 配置 | 用途 |
|------|------|------|
| **NSGA-II** | 启发式初始化 + 局部搜索 | 改进算法 ⭐ |
| **NSGA-II-Basic** | 混合初始化 + 无局部搜索 | 基准算法（消融实验）|
| **MOEA/D** | 标准初始化 + 无局部搜索 | 对比算法 |
| **MOGWO** | 标准初始化 + 无局部搜索 | 对比算法 |
| **SPEA2** | 标准初始化 + 无局部搜索 | 对比算法 |

### 评价指标（3种）

1. **HV (Hypervolume)**
   - 衡量收敛性+多样性
   - 归一化计算，参考点(1.1, 1.1)
   - 越大越好

2. **IGD (Inverted Generational Distance)**
   - 衡量与真实前沿的距离
   - 基于近似PF*计算
   - 越小越好

3. **C-metric (Coverage Metric)**
   - 衡量算法间的支配关系
   - 两两对比，5×5矩阵
   - 直观的支配率

## 🚀 快速开始

### 第1步：运行实验

```bash
# Windows
run_comparison.bat

# 其他系统
cd chapter-3
mvn test -Dtest=AlgorithmComparisonExperimentRunner
```

### 第2步：选择模式

```
1. 单个算例对比     (推荐：首次运行，30-45分钟)
2. J20批量对比      (2-3小时)
3. J50批量对比      (4-6小时)
4. J100批量对比     (8-12小时)
5. 全部算例对比     (15-20小时)
```

### 第3步：查看结果

```bash
# 进入输出目录
cd output/comparison_experiment/算例名称_时间戳/

# 查看对比报告
cat ComparisonReport.txt

# 查看某个算法某次运行
cd NSGAII/run_1/
ls -lh  # 查看所有输出文件
```

### 第4步：生成额外图表

```bash
# 运行可视化脚本
python visualize_comparison.py
```
