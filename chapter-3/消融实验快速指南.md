# 消融实验快速指南

## 🎯 什么是消融实验？

**消融实验（Ablation Study）**：系统地移除算法的某些组件，以验证每个组件的贡献。

在本项目中：
- **完整算法**：NSGA-II（启发式初始化 + 局部搜索）
- **消融版本**：NSGA-II-Basic（混合初始化 + **无局部搜索**）

**目的**：证明局部搜索对算法性能的贡献

## 📊 专门的消融对比图

### Python代码：只对比改进版和基础版

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy.stats import wilcoxon

# 读取数据
data = pd.read_csv('MetricsData.csv')

# 只提取NSGA-II和NSGA-II-Basic
ablation_data = data[data['Algorithm'].isin(['NSGAII', 'NSGAII-Basic'])]

# 1. HV对比箱线图
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# HV
sns.boxplot(x='Algorithm', y='HV', data=ablation_data, ax=axes[0],
            palette=['#FF6B6B', '#FFA07A'])
axes[0].set_title('Hypervolume Comparison', fontsize=14, fontweight='bold')
axes[0].set_xlabel('Algorithm', fontsize=12)
axes[0].set_ylabel('Hypervolume', fontsize=12)

# IGD
sns.boxplot(x='Algorithm', y='IGD', data=ablation_data, ax=axes[1],
            palette=['#FF6B6B', '#FFA07A'])
axes[1].set_title('IGD Comparison', fontsize=14, fontweight='bold')
axes[1].set_xlabel('Algorithm', fontsize=12)
axes[1].set_ylabel('IGD', fontsize=12)

plt.tight_layout()
plt.savefig('ablation_study.png', dpi=300, bbox_inches='tight')
print("✅ 消融实验对比图已保存: ablation_study.png")

# 2. 统计检验
nsgaii_hv = data[data['Algorithm']=='NSGAII']['HV']
basic_hv = data[data['Algorithm']=='NSGAII-Basic']['HV']

stat, p = wilcoxon(nsgaii_hv, basic_hv)
improvement = (nsgaii_hv.mean() - basic_hv.mean()) / basic_hv.mean() * 100

print(f"\n=== 消融实验统计结果 ===")
print(f"NSGA-II平均HV:       {nsgaii_hv.mean():.6f}")
print(f"NSGA-II-Basic平均HV: {basic_hv.mean():.6f}")
print(f"改进幅度:            {improvement:.2f}%")
print(f"p-value:            {p:.6f}")
if p < 0.01:
    print("结论: NSGA-II极显著优于NSGA-II-Basic (p<0.01) **")
elif p < 0.05:
    print("结论: NSGA-II显著优于NSGA-II-Basic (p<0.05) *")
```

## 💡 数据分析要点

### 1. 改进幅度计算

```python
import pandas as pd

data = pd.read_csv('MetricsData.csv')

# HV改进幅度
hv_improved = data[data['Algorithm']=='NSGAII']['HV'].mean()
hv_basic = data[data['Algorithm']=='NSGAII-Basic']['HV'].mean()
hv_improvement = (hv_improved - hv_basic) / hv_basic * 100

print(f"HV改进幅度: {hv_improvement:.2f}%")

# IGD改进幅度（注意：IGD越小越好）
igd_improved = data[data['Algorithm']=='NSGAII']['IGD'].mean()
igd_basic = data[data['Algorithm']=='NSGAII-Basic']['IGD'].mean()
igd_improvement = (igd_basic - igd_improved) / igd_basic * 100

print(f"IGD改进幅度: {igd_improvement:.2f}%")
```

### 2. 统计显著性

```python
from scipy.stats import wilcoxon

nsgaii_hv = data[data['Algorithm']=='NSGAII']['HV']
basic_hv = data[data['Algorithm']=='NSGAII-Basic']['HV']

stat, p = wilcoxon(nsgaii_hv, basic_hv)

# 论文写法
if p < 0.01:
    print("差异极显著 (p<0.01) **")
elif p < 0.05:
    print("差异显著 (p<0.05) *")
else:
    print("差异不显著 (p≥0.05)")
```

### 3. 效应量（Effect Size）

```python
# Cohen's d
mean_diff = nsgaii_hv.mean() - basic_hv.mean()
pooled_std = np.sqrt((nsgaii_hv.std()**2 + basic_hv.std()**2) / 2)
cohens_d = mean_diff / pooled_std

print(f"Cohen's d: {cohens_d:.4f}")

# 解释
if abs(cohens_d) < 0.2:
    print("效应量: 小")
elif abs(cohens_d) < 0.5:
    print("效应量: 中")
elif abs(cohens_d) < 0.8:
    print("效应量: 大")
else:
    print("效应量: 非常大")
```
