```

# Format: Cmax Energy

245.500000	1250.000000
248.300000	1245.000000
250.000000	1240.000000
...
```

### 2. pareto_front.png ⭐
**格式**：PNG图片（1200x800）
**内容**：Pareto前沿散点图

![Pareto前沿图示例](示例：Cmax-Energy散点图)

**特点**：
- 横轴：Cmax（最大完工时间）
- 纵轴：Energy（总能耗）
- 每个点代表一个非支配解
- 自动标注轴标签和标题

## 💡 常见问题

### Q1: 图片生成失败怎么办？

**可能原因**：
1. 缺少可视化依赖
2. 内存不足
3. 权限问题

**解决方案**：
- 检查控制台的错误信息
- 图片生成失败不影响其他输出
- 可以单独运行可视化工具补充生成

### Q2: 为什么有些文件生成失败？

程序采用**容错设计**：
- 如果某个图表生成失败，会显示警告
- 继续生成其他文件
- 确保至少有基本的数据输出

### Q3: 如何只生成部分输出？

修改 `saveAlgorithmResults()` 方法，注释掉不需要的部分：

```java
// 如果不需要甘特图，注释掉这部分
// try {
//     String ganttFile = runDir + "best_cmax_gantt.png";
//     exportGanttChart(...);
// } catch (Exception e) { ... }
```

### Q4: 输出太多，磁盘空间不够？

**方案1**：只保留关键文件
```java
// 只生成ParetoFront.txt和Statistics.txt
// 注释掉图片生成代码
```

**方案2**：减少运行次数
```java
private static final int REPEAT_TIMES = 5;  // 从10改为5
```

**方案3**：分批实验
- 先运行J20算例
- 清理后运行J50算例
- 最后运行J100算例
