## 🚀 主程序1: NSGAIIRunner（推荐）

### 特点
✅ **功能最完整** - 包含所有功能模块  
✅ **高度可配置** - 所有参数可在顶部修改  
✅ **输出详细** - 控制台显示 + 文件保存  
✅ **交互友好** - 支持交互式选择算例  
✅ **能耗分析** - 自动对比能耗策略效果  

### 适用场景
- ✅ 正式的实验运行
- ✅ 需要保存详细结果
- ✅ 需要对比能耗策略
- ✅ 批量运行多个算例

### 使用方法

#### 方法1: 直接运行（交互式）
```java
右键 NSGAIIRunner.java -> Run 'NSGAIIRunner.main()'
```

程序会提示选择算例：
```
请选择算例文件:
1. 使用默认算例 (chapter-2 J20P3B2D5_01.txt)
2. 输入自定义路径

请选择 (1/2): 
```

#### 方法2: 命令行参数
```bash
java AlgorithmFrame.nsgaii.NSGAIIRunner "path/to/instance.txt"
```

### 配置参数

在文件顶部修改：
```java
// 算法参数
private static final int POPULATION_SIZE = 100;        // 种群规模
private static final int MAX_GENERATIONS = 200;        // 最大代数
private static final double CROSSOVER_RATE = 0.9;      // 交叉率
private static final double MUTATION_RATE = 0.1;       // 变异率
private static final double MAX_RUN_TIME = 10.0;       // 最大运行时间（分钟）

// 输出配置
private static final boolean SAVE_RESULTS = true;      // 是否保存结果
private static final int DISPLAY_TOP_N = 20;           // 显示前N个解

// 随机种子
private static final long RANDOM_SEED = 0;             // 0=随机
```

- ✅ 能耗策略对比

**文件输出：**
```

```

包含：
- 算例信息
- 算法参数
- 完整Pareto前沿

## ❓ 常见问题

### Q: 三个程序有什么本质区别吗？
A: 核心算法完全相同，区别在于：
- **NSGAIIRunner**: 功能最全、输出最详细
- **QuickStart**: 代码最简、上手最快
- **MainEntry**: 原有版本

### Q: 我应该修改哪些参数？
A: 主要修改：
1. **算例路径** - 必须修改
2. **种群规模和代数** - 根据算例规模调整
3. **随机种子** - 需要可重复实验时设置

### Q: 如何知道参数设置是否合理？
A: 观察：
- Pareto前沿规模应在 20-50 个解
- 如果只有几个解，增加种群或代数
- 如果运行时间过长，减小参数

### Q: 结果不满意怎么办？
A: 尝试：
1. 增加种群规模（提高多样性）
2. 增加进化代数（更充分的搜索）
3. 调整变异率（0.1-0.2）
4. 多次运行取最好结果
