## 🎯 核心功能

### 1. 支持的算法（5种）

| 算法 | 配置 | 用途 |
|------|------|------|
| **NSGA-II** | 启发式初始化 + 局部搜索 | **改进算法** ⭐ |
| NSGA-II-Basic | 标准初始化 + 无局部搜索 | 基准算法（消融） |
| MOEA/D | 标准初始化 + 无局部搜索 | 对比算法 |
| MOGWO | 标准初始化 + 无局部搜索 | 对比算法 |
| SPEA2 | 标准初始化 + 无局部搜索 | 对比算法 |

**关键点**：
- NSGA-II是**唯一启用局部搜索**的算法
- 其他算法都是基准版本（无局部搜索）
- 用于证明NSGA-II改进策略的有效性

### 2. 评价指标（3种）

#### HV (Hypervolume)
- ✅ 归一化到[0,1]区间
- ✅ 固定参考点(1.1, 1.1)
- ✅ 主指标，越大越好

#### IGD (Inverted Generational Distance)
- ✅ 基于近似PF*
- ✅ 欧氏距离计算
- ✅ 互补指标，越小越好

#### C-metric (Coverage)
- ✅ 两两支配关系
- ✅ 5×5矩阵
- ✅ 直观支配率

```python
import pandas as pd
import seaborn as sns

# 读取数据
data = pd.read_csv('MetricsData.csv')

# 只对比NSGA-II和NSGA-II-Basic
ablation = data[data['Algorithm'].isin(['NSGAII', 'NSGAII-Basic'])]

# 画对比图
sns.boxplot(x='Algorithm', y='HV', data=ablation)
plt.title('Ablation Study: HV Comparison')
plt.savefig('ablation_hv.png', dpi=300)

# 统计检验
from scipy.stats import wilcoxon
nsgaii = data[data['Algorithm']=='NSGAII']['HV']
basic = data[data['Algorithm']=='NSGAII-Basic']['HV']
_, p = wilcoxon(nsgaii, basic)
print(f"p-value: {p:.6f}")
print(f"改进幅度: {(nsgaii.mean()-basic.mean())/basic.mean()*100:.2f}%")
```

### 批量处理多个算例

```python
import glob
import pandas as pd

# 读取所有算例的MetricsData.csv
all_files = glob.glob('output/**/MetricsData.csv', recursive=True)

# 合并数据
all_data = []
for file in all_files:
    instance = file.split('/')[2].split('_')[0]  # 提取算例名
    data = pd.read_csv(file)
    data['Instance'] = instance
    all_data.append(data)

combined = pd.concat(all_data)

# 按算例分组分析
summary = combined.groupby(['Instance', 'Algorithm'])['HV'].mean()
print(summary)
```
