## 🔍 常见问题

### Q1: 为什么只有NSGA-II使用开关机策略？

**答**：为了公平地验证NSGA-II的改进效果。

- NSGA-II作为改进算法，使用所有改进策略（局部搜索+开关机）
- 其他算法作为基准，使用基础配置
- 这样可以清晰地展示NSGA-II改进的效果

### Q2: 如何单独验证开关机策略的效果？

**答**：可以进行额外的消融实验：

1. **NSGA-II（开关机）** vs **NSGA-II（纯待机）**
2. 两者都使用局部搜索
3. 只改变开关机策略

这样可以量化开关机策略的贡献。

### Q3: 能耗差距多少算正常？

**答**：根据调度方案的不同，预期差距为：

- **理想情况**：20-30%（机器空闲时间长）
- **典型情况**：10-20%（正常空闲时间）
- **最差情况**：5-10%（机器几乎满负荷）

如果差距<5%，可能需要检查：
- 算例是否空闲时间过短
- 开关机策略是否正确配置

### Q4: 如何修改配置？

**答**：修改`AlgorithmComparisonExperimentRunner.java`：

```java
// 当前配置：只有NSGA-II使用开关机
boolean enableSwitchingStrategy = algorithm.equals("NSGAII");

// 所有算法都使用开关机
boolean enableSwitchingStrategy = true;

// 所有算法都不使用开关机
boolean enableSwitchingStrategy = false;
```
