# NSGA-II 输出说明

## 概述

NSGA-II算法运行完成后，会自动生成完整的结果输出，包括：
1. **Pareto前沿图**（能耗 vs Cmax）
2. **Pareto前沿解集数据**（所有非支配解）
3. **最优Cmax解的甘特图**
4. **最优Cmax解的打印批次排布图**
5. **详细调度记录**（零件加工顺序、机器加工顺序）

---

## 输出目录结构

```
chapter-3/output/nsgaii_YYYYMMDD_HHMMSS/
├── NSGAII_result.txt                    # 算法运行摘要
├── pareto_front.png                     # Pareto前沿图
├── pareto_front_data.txt                # Pareto前沿解集详细数据
├── best_cmax_gantt.png                  # 最优Cmax解的甘特图
├── best_cmax_printer_layout.png         # 最优Cmax解的打印批次排布图
└── best_cmax_schedule_records.txt       # 最优Cmax解的详细调度记录
```

### 2. `pareto_front.png` - Pareto前沿图

**图表说明**：
- **横轴**：能耗 (kWh)
- **纵轴**：Cmax (最大完工时间)
- **数据点**：每个点代表一个Pareto最优解
- **连线**：展示Pareto前沿的形状

**解读**：
- 左上角的点：能耗低，但Cmax高（节能但慢）
- 右下角的点：能耗高，但Cmax低（快速但耗能）
- 中间的点：能耗和Cmax的折中方案

**示例图**：
```
Cmax ↑
     |
 50  |    ●
     |      ●
 45  |        ●
     |          ●
 40  |            ●
     |              ●
 35  |________________●__→ 能耗 (kWh)
     100  110  120  130  140
```

### 4. `best_cmax_gantt.png` - 最优Cmax解的甘特图

**图表说明**：
- **横轴**：时间
- **纵轴**：机器编号
- **矩形块**：每个矩形代表一个工序
  - **颜色**：不同颜色代表不同工件
  - **标签**：
    - 打印机/批处理机：`B机器号-批次号`（如 `B1-1` 表示1号打印机的第1批）
    - 离散机：`J工件号`（如 `J0` 表示工件0）

**示例图**：
```
机器 ↑
     |
打印机1 |  [B1-1]    [B1-2]
     |
批处理机1|    [B1-1]      [B1-2]
     |
离散机1 |[J0][J1]  [J2]    [J3]
     |
离散机2 |  [J0][J2]  [J1]    [J3]
     |_________________________________→ 时间
     0    10   20   30   40   50
```

**解读**：
- 可以看出每台机器的工作时间线
- 可以识别关键路径（决定Cmax的路径）
- 可以发现机器空闲时间

## 如何使用输出结果

### 1. 选择合适的解

从Pareto前沿中选择最适合实际需求的解：
- **追求速度**：选择Cmax最小的解（`pareto_front_data.txt`中的第1个解）
- **追求节能**：选择能耗最小的解（`pareto_front_data.txt`中的最后一个解）
- **平衡方案**：选择中间的解

### 2. 分析调度方案

通过甘特图和详细记录分析：
- **关键路径**：找出决定Cmax的关键工序序列
- **瓶颈机器**：识别利用率最高的机器
- **优化空间**：发现机器空闲时间，考虑进一步优化

### 3. 验证装箱方案

通过打印批次排布图验证：
- **占用率**：检查是否充分利用打印平台
- **批次数**：评估是否需要调整批次划分
- **零件排布**：确认零件是否能实际放置

### 4. 对比不同算例

运行多个算例后，可以对比：
- Pareto前沿的形状和范围
- 不同算例的优化空间
- 算法参数对结果的影响

## 常见问题

### Q1: 为什么Pareto前沿只有少数几个解？
A: 这是正常的。Pareto前沿的解数量取决于：
- 问题的复杂度
- 目标之间的冲突程度
- 算法的收敛情况

如果解太少，可以尝试：
- 增加种群规模
- 增加迭代代数
- 调整交叉率和变异率

### Q2: 如何判断算法是否收敛？
A: 观察以下指标：
- Pareto前沿是否平滑连续
- 多次运行结果是否稳定
- Cmax和能耗的范围是否合理

### Q3: 甘特图中的空白时间是什么？
A: 空白时间表示机器空闲或等待前序工序完成。这是正常的，因为：
- 工序之间有依赖关系
- 机器可能需要等待工件到达
- 批处理需要等待足够的工件

### Q4: 如何提高装箱占用率？
A: 装箱占用率由算法自动优化，但可以通过以下方式间接影响：
- 调整打印机数量和尺寸
- 调整工件尺寸分布
- 修改装箱算法参数（在`CaculateFitness`中）
