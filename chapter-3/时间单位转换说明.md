# 时间单位转换说明

## 问题描述

### 单位不一致问题

在能耗计算中存在一个**严重的单位问题**：

1. **调度系统**：使用**秒（s）**作为时间单位
   - `operation.startTime` 单位：秒
   - `operation.endTime` 单位：秒
   - `makespan` 单位：秒

2. **能耗计算**：使用**小时（h）**作为时间单位
   - 功率单位：`kW`（千瓦）
   - 能耗单位：`kWh`（千瓦时）= `kW × 小时`

**如果不转换单位，会导致能耗计算错误**：
```
错误计算：E = P_run × duration_秒
结果单位：kW·s（不是kWh！）
实际错误：能耗被高估了 3600 倍！
```

---

## 修复方案

### 核心思路

添加时间单位转换常量，在所有能耗计算中自动将**秒转换为小时**：

```java
/** 时间单位转换：秒 -> 小时 */
private static final double SECONDS_TO_HOURS = 1.0 / 3600.0;
```

### 转换公式

```
小时 = 秒 × (1 / 3600)
     = 秒 / 3600
```

例如：
- 3600 秒 = 1 小时
- 7200 秒 = 2 小时
- 1800 秒 = 0.5 小时

---

## 修复位置

### 1. 运行能耗计算

**修复前（错误）：**
```java
for (Operation op : uniqueOperations) {
    double duration = op.endTime - op.startTime;  // 秒
    runEnergy += params.P_run * duration;  // kW × 秒 = kW·s ❌ 单位错误！
}
```

**修复后（正确）：**
```java
for (Operation op : uniqueOperations) {
    double durationSeconds = op.endTime - op.startTime;  // 秒
    double durationHours = durationSeconds * SECONDS_TO_HOURS;  // 转换为小时
    runEnergy += params.P_run * durationHours;  // kW × 小时 = kWh ✅ 正确
}
```

---

### 2. 起始空闲能耗计算

**修复前（错误）：**
```java
Operation firstOp = uniqueOperations.get(0);
double initialGap = firstOp.startTime - 0.0;  // 秒

if (params.shouldShutdown(initialGap)) {  // ❌ 传入秒，但参数应该是小时
    gapEnergy = params.E_switch;
} else {
    gapEnergy = params.P_idle * initialGap;  // kW × 秒 ❌ 单位错误
}
```

**修复后（正确）：**
```java
Operation firstOp = uniqueOperations.get(0);
double initialGapSeconds = firstOp.startTime - 0.0;  // 秒
double initialGapHours = initialGapSeconds * SECONDS_TO_HOURS;  // 转换为小时

if (params.shouldShutdown(initialGapHours)) {  // ✅ 传入小时
    gapEnergy = params.E_switch;
} else {
    gapEnergy = params.P_idle * initialGapHours;  // kW × 小时 = kWh ✅
}
```

---

**修复前（错误）：**

**修复后（正确）：**

```java
if (params.shouldShutdown(gapHours)) {  // ✅ 小时

    gapEnergy = params.P_idle * gapHours;  // kW × 小时 = kWh ✅

```

### 4. 统计信息计算

**修复前（错误）：**

## 影响对比

### 示例：一个简单的调度方案

**场景**：
- 一台机器运行一个工序
- 工序时间：[0, 3600]（秒）
- 功率：P_run = 5.0 kW

**修复前（错误）：**
```
duration = 3600 秒
energy = 5.0 kW × 3600 秒 = 18000 kW·s
     = 18000 kW·s × (1小时/3600秒) 
     = 5.0 kWh × 3600  ❌
     = 18000 kWh  ❌ 错误！高估了3600倍
```

**修复后（正确）：**
```
durationSeconds = 3600 秒
durationHours = 3600 / 3600 = 1.0 小时
energy = 5.0 kW × 1.0 小时 = 5.0 kWh  ✅ 正确
```

**差异**：18000 kWh vs 5.0 kWh（差了3600倍！）

## 开关机决策的影响

### 盈亏平衡时间计算

**公式**：
```
T_breakEven = E_switch / P_idle
```

如果 `E_switch = 2.0 kWh`，`P_idle = 0.5 kW`：
```
T_breakEven = 2.0 / 0.5 = 4.0 小时
```

### 决策条件

**修复前（错误）：**
```java
double gapSeconds = 7200.0;  // 2小时 = 7200秒
if (params.shouldShutdown(gapSeconds)) {  // ❌ 传入7200
    // T_warmup + T_breakEven = 1.0 + 4.0 = 5.0小时
    // 7200 > 5.0 → 关机 ❌ 错误判断（把秒当成小时）
}
```

**修复后（正确）：**
```java
double gapSeconds = 7200.0;  // 2小时
double gapHours = 7200.0 / 3600.0 = 2.0;  // 转换为小时
if (params.shouldShutdown(gapHours)) {  // ✅ 传入2.0
    // T_warmup + T_breakEven = 1.0 + 4.0 = 5.0小时
    // 2.0 < 5.0 → 待机 ✅ 正确判断
}
```

## 相关参数单位总结

| 参数 | 单位 | 说明 |
|------|------|------|
| `operation.startTime` | 秒(s) | 工序开始时间 |
| `operation.endTime` | 秒(s) | 工序结束时间 |
| `makespan` | 秒(s) | 最大完工时间 |
| `P_run` | 千瓦(kW) | 运行功率 |
| `P_idle` | 千瓦(kW) | 待机功率 |
| `E_switch` | 千瓦时(kWh) | 开关机能耗 |
| `T_warmup` | 小时(h) | 预热时间 |
| `T_breakEven` | 小时(h) | 盈亏平衡时间 |
| `能耗计算结果` | 千瓦时(kWh) | 总能耗 |

### 转换关系

```
1 kWh = 1 kW × 1 小时
      = 1000 W × 3600 秒
      = 3,600,000 W·s (焦耳)
```

## 注意事项

### ⚠️ 重要提醒

1. **所有时间相关的计算都需要单位转换**
   - 运行时间
   - 空闲时间
   - 决策阈值

2. **不要混用单位**
   - 能耗计算统一用"小时"
   - 调度计算统一用"秒"
   - 在接口处进行转换

3. **调试输出要明确单位**
   - 显示"秒"和"小时"
   - 显示"kWh"
   - 避免混淆

4. **文档要说明单位**
   - API文档标注单位
   - 变量命名体现单位（如`durationSeconds`、`durationHours`）
