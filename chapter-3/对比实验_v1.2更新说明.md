### 1. MetricsData.csv


**字段说明**：
- `Algorithm`：算法名称
- `Run`：运行次数（1-10）
- `HV`：Hypervolume值
- `IGD`：IGD值
- `RunTime`：运行时间（秒）

### 2. MetricsData.txt

**格式**：TXT（易读格式）  
**位置**：`output/comparison_experiment/算例名称_时间戳/MetricsData.txt`

**内容**：
- 算例信息
- 各算法详细数据表格
- 统计信息（均值、标准差）

## 🎓 实际案例

### 完整的分析流程

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats

# 1. 读取数据
data = pd.read_csv('MetricsData.csv')

# 2. 基本统计
print("=== 基本统计 ===")
print(data.groupby('Algorithm')['HV'].describe())

# 3. 绘制箱线图
fig, axes = plt.subplots(1, 2, figsize=(15, 6))

sns.boxplot(x='Algorithm', y='HV', data=data, ax=axes[0])
axes[0].set_title('Hypervolume Comparison')

sns.boxplot(x='Algorithm', y='IGD', data=data, ax=axes[1])
axes[1].set_title('IGD Comparison')

plt.tight_layout()
plt.savefig('comparison_boxplot.png', dpi=300)

# 4. 统计检验
print("\n=== Wilcoxon检验 ===")
algorithms = ['NSGAII', 'MOEAD', 'MOGWO', 'SPEA2']
for i, alg1 in enumerate(algorithms):
    for alg2 in algorithms[i+1:]:
        data1 = data[data['Algorithm']==alg1]['HV']
        data2 = data[data['Algorithm']==alg2]['HV']
        _, p = stats.wilcoxon(data1, data2)
        print(f"{alg1} vs {alg2}: p = {p:.6f}")

# 5. 生成报告
with open('analysis_report.txt', 'w') as f:
    f.write("算法性能分析报告\n")
    f.write("="*50 + "\n\n")
    f.write(data.groupby('Algorithm')['HV'].describe().to_string())
```
