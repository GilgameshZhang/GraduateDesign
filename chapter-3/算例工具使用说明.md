## 🚀 快速开始

### 方法1: 使用Java生成器（推荐）

**生成标准测试集:**

```bash
cd chapter-3
javac -d bin -sourcepath src/main/java src/main/java/util/java/EnergyAwareInstanceGenerator.java
java -cp bin util.java.EnergyAwareInstanceGenerator
```

这将在 `chapter-3/src/main/resources/instance/` 目录下生成:
- J10 系列: 3个小规模算例
- J20 系列: 5个中规模算例
- J50 系列: 5个大规模算例
- J100 系列: 3个超大规模算例

**生成单个自定义算例:**

修改 `EnergyAwareInstanceGenerator.java` 的main方法:

```java
EnergyAwareInstanceGenerator gen = new EnergyAwareInstanceGenerator(12345);
gen.generateInstance(
    30,                          // 30个工件
    3,                           // 3台打印机
    2,                           // 2台批处理机
    0,                           // 0台离散机
    "instance/custom_J30P3B2D0_01.txt",
    EnergyProfile.ECO,           // 打印机使用节能配置
    EnergyProfile.TEMPERATURE_SENSITIVE  // 批处理机使用温度敏感配置
);
```

### 方法2: 为第二章算例添加能耗参数

**单文件处理:**

```bash
python add_energy_params.py \
    chapter-2/src/main/resources/instance/J20/J20P3B2D5_01.txt \
    chapter-3/src/main/resources/instance/J20/J20P3B2D5_01.txt
```

**批量处理目录:**

```bash
# 处理整个J20目录
python add_energy_params.py --batch chapter-2/src/main/resources/instance/J20/

# 指定输出目录
python add_energy_params.py \
    --batch chapter-2/src/main/resources/instance/J20/ \
    --output-dir chapter-3/src/main/resources/instance/J20/
```

**使用不同能耗配置:**

```bash
# 使用节能配置
python add_energy_params.py input.txt output.txt \
    --printer-profile ECO \
    --batch-profile ECO

# 使用温度敏感配置
python add_energy_params.py input.txt output.txt \
    --printer-profile TEMP \
    --batch-profile TEMP
```

## 📊 能耗配置类型

### ECO (节能型)
- **适用场景:** 频繁开关机不影响设备寿命
- **特点:** 低待机功率，鼓励关机策略
- **典型设备:** 桌面级3D打印机，小型喷砂机

### STANDARD (标准型) ⭐ 推荐
- **适用场景:** 平衡性能和能耗
- **特点:** 打印机允许关机，批处理机倾向待机
- **典型设备:** 工业级3D打印机，热处理炉

### HEAVY (重载型)
- **适用场景:** 高功率设备，频繁开关机代价高
- **特点:** 高运行功率，不鼓励关机
- **典型设备:** 大型3D打印机，工业炉

### TEMP (温度敏感型)
- **适用场景:** 需要保持温度的设备
- **特点:** 禁止关机，高待机功率
- **典型设备:** 高温热处理炉，恒温设备

## 📖 算例格式概览

### 第三章格式 (v2.0)

```
第1行: machineCount jobCount
第2行: printMachineCount [id L W H printSpeed recordTime prepareTime] ...
第3行: batchMachineCount [id capacity] ...
第4行: printMachineCount [id P_run P_idle E_switch T_warmup allowSwitch] ... ← 新增
第5行: batchMachineCount [id P_run P_idle E_switch T_warmup allowSwitch] ... ← 新增
第6行: discreteMachineCount                                                  ← 新增
第7行+: 工件信息 (与第二章相同)
```

### 能耗参数说明

| 参数 | 单位 | 说明 |
|------|------|------|
| P_run | kW | 运行功率（加工时） |
| P_idle | kW | 待机功率（空闲时） |
| E_switch | kWh | 开关机能耗代价 |
| T_warmup | 秒 | 预热时间 |
| allowSwitch | 0/1 | 是否允许关机（1=允许，0=不允许） |

### 盈亏平衡时间

关键公式: **T_breakEven = E_switch / P_idle**

当空闲时间 > T_breakEven + T_warmup 时，关机比待机更节能。

示例:
- 打印机: P_idle=0.5kW, E_switch=2.0kWh → T_be=4小时
- 批处理机: P_idle=0.8kW, E_switch=5.0kWh → T_be=6.25小时

## 📝 命名规范

算例文件命名格式: **JxxPyyBzzDww_nn.txt**

- **Jxx**: 工件数 (Job count)
- **Pyy**: 打印机数 (Printer count)
- **Bzz**: 批处理机数 (Batch machine count)
- **Dww**: 离散加工机数 (Discrete machine count, 可选)
- **nn**: 实例编号 (01, 02, ...)

示例:
- `J10P2B1D0_01.txt` - 10工件，2打印机，1批处理机
- `J20P3B2D0_05.txt` - 20工件，3打印机，2批处理机，第5个实例
- `J50P4B3D0_10.txt` - 50工件，4打印机，3批处理机，第10个实例

## ⚠️ 注意事项

### 时间单位
- **调度系统**: 使用秒（seconds）
- **能耗系统**: 使用小时（hours）
- EnergyCalculator自动转换: 秒 ÷ 3600 = 小时

### 离散加工机
- 当前版本预留扩展，实际使用中设为0

## 🐛 常见问题

**Q: 如何验证能耗参数是否生效?**

A: 三种方法:
1. 查看EnergyAwareInput的输出日志
2. 使用EnergyCalculator.getStatistics()查看开关机次数
3. 对比有无能耗参数的总能耗差异

**Q: T_warmup会影响makespan吗?**

A: 当前版本中，T_warmup仅用于能耗计算的盈亏平衡判断，不影响调度时间轴。

**Q: allowSwitch=0时还会关机吗?**

A: 不会。allowSwitch=0强制设备始终待机，即使空闲时间很长。

**Q: 如何为整个第二章算例库添加能耗参数?**

A: 使用批量处理:
```bash
python add_energy_params.py \
    --batch chapter-2/src/main/resources/instance/ \
    --output-dir chapter-3/src/main/resources/instance/
```
