## 📝 代码说明

我们的代码**已经是 Java 8 兼容**的！

```java
// ✅ 我们使用的是这个（Java 8 兼容）
private static String repeatString(String str, int count) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < count; i++) {
        sb.append(str);
    }
    return sb.toString();
}

// ❌ 我们没有使用这个（需要 Java 11）
// String.repeat(count)
```
