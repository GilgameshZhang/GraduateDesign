## 📋 三步开始实验

### 第1步：验证环境

```bash
cd chapter-1
mvn clean compile test-compile -DskipTests
```

看到 `BUILD SUCCESS` 说明环境正常！

### 第2步：选择实验类型

您有两种实验可以运行：

#### 选项A：多算法对比实验（20个算例）
- 对比 GA-TS、GA-GA、GA-ACO、ALNS 四种算法
- 5个规模梯队 × 4个案例 = 20个算例
- 预计时间：多线程约5小时

#### 选项B：消融实验（5个算例）
- 测试不同参数对 GA-TS 算法的影响
- 5个规模梯队 × 1个案例 = 5个算例  
- 预计时间：多线程约1.5小时

### 第3步：运行实验

#### 方式1：使用批处理脚本（最简单）

```bash
# Windows系统直接双击：
run_comparison_experiments.bat   # 对比实验
run_ablation_experiments.bat     # 消融实验
```

**注意**：使用脚本前需要先修改对应的Java文件配置（见下方）

#### 方式2：使用Maven命令

```bash
# 对比实验
mvn exec:java -Dexec.mainClass="MultiAlgorithmComparison" -Dexec.classpathScope=test

# 消融实验  
mvn exec:java -Dexec.mainClass="AblationExperimentRunner" -Dexec.classpathScope=test
```

## 🎯 最小验证实验（5分钟）

想快速验证一切正常？运行这个最小配置：

编辑 `MultiAlgorithmComparison.java`：

```java
public static void main(String[] args) {
    // 只运行1个小规模算例，每个算法只运行1次
    runMultiAlgorithmComparison(
        "chapter-1/src/main/resources/Machine/machine_2",
        "chapter-1/src/main/resources/PrintItem/printItem_10/printItem_10_01",
        "QuickTest",
        1,     // 只运行1次（不是3次）
        false  // 关闭可视化（更快）
    );
}
```

然后运行：
```bash
mvn exec:java -Dexec.mainClass="MultiAlgorithmComparison" -Dexec.classpathScope=test
```

**预计时间**：4个算法 × 5分钟 = 20分钟（多线程可能更快）

## ❓ 常见问题

### Q1: 编译失败怎么办？

确认Java版本是8：
```bash
java -version  # 应该显示 1.8.x
```

清理后重新编译：
```bash
mvn clean compile test-compile -DskipTests
```

### Q2: 找不到算例文件？

检查路径是否存在：
```bash
ls src/main/resources/Machine/
ls src/main/resources/PrintItem/
```

### Q3: 实验运行时间太长？

- 减少重复次数（3改为1）
- 减少算例数量（先运行几个）
- 确保启用了多线程

### Q4: 结果保存在哪里？

- 对比实验：`multi_algorithm_comparison_results/`
- 消融实验：`ablation_results/`
- 可视化图表：在各自的子目录中
