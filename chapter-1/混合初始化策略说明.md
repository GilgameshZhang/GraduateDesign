# 混合初始化策略说明

## 📋 概述

为了支持消融实验中对**初始化策略**的研究，现在已经实现了**混合初始化策略**，可以灵活控制启发式初始化和随机初始化的比例。

---

## 🎯 功能特点

### 1. 可配置的初始化比例

通过参数 `heuristicInitRatio` 控制启发式初始化在种群中的比例：

- **1.0** = 100% 启发式初始化（全部使用启发式规则）
- **0.0** = 100% 随机初始化（全部随机生成）
- **0.5** = 50% 启发式 + 50% 随机（混合策略）
- **0.7** = 70% 启发式 + 30% 随机
- **0.3** = 30% 启发式 + 70% 随机

### 2. 两种初始化方式

#### 启发式初始化
- **排序规则**：按零件高度从高到低排序
- **机器选择**：基于机器打印能力的概率分配
- **优势**：利用问题特征，初始解质量较高
- **劣势**：多样性相对较低

#### 随机初始化
- **排序规则**：随机打乱零件顺序
- **机器选择**：随机选择满足约束的机器
- **优势**：种群多样性高，搜索空间覆盖广
- **劣势**：初始解质量可能较低

## 💻 使用方法

### 方式1：使用新的构造函数（推荐）

```java
// 创建混合初始化的GA（50%启发式 + 50%随机）
BatchGa ga = new BatchGa(
    10000,              // MAX_GEN
    100,                // popSize
    5.0,                // variationExchangeCount
    3,                  // cloneNumOfBestIndividual
    0.3,                // mutationRate
    0.7,                // crossoverRate
    input,              // 输入数据
    true,               // isRotateEnable
    "TS",               // method
    100,                // decodeMaxGen
    10,                 // decodeTabuSize
    30,                 // decodeMaxN
    5 * 60 * 1000,      // timeLimitMs (5分钟)
    0.5                 // heuristicInitRatio (50%启发式)
);

Result result = ga.solve();
```

### 方式2：修改现有对象（兼容旧代码）

```java
// 使用旧的构造函数创建GA
BatchGa ga = new BatchGa(
    10000, 100, 5.0, 3, 0.3, 0.7, input, true, "TS",
    100, 10, 30, 5 * 60 * 1000
);

// 修改初始化比例
ga.heuristicInitRatio = 0.5; // 设置为50%启发式

Result result = ga.solve();
```

### 方式3：消融实验专用（BatchGaAblation）


## 🔬 消融实验设计示例

### 实验1：初始化策略对比

测试不同初始化比例对算法性能的影响：

```java
// 配置列表
double[] initRatios = {0.0, 0.25, 0.5, 0.75, 1.0};
String[] configNames = {
    "全随机初始化",
    "25%启发式",
    "50%启发式",
    "75%启发式",
    "全启发式"
};

for (int i = 0; i < initRatios.length; i++) {
    System.out.println("\n测试配置: " + configNames[i]);
    
    BatchGaAblation ga = new BatchGaAblation(
        10000, 100, 5.0, 3, 0.3, 0.7, input, true, "TS",
        100, 10, 30, 5 * 60 * 1000, 
        initRatios[i]  // 不同的初始化比例
    );
    
    Result result = ga.solve();
    System.out.println("最优Cmax: " + result.getSolutionList().stream()
        .mapToDouble(br -> br.fitness).min().orElse(0));
}
```

- 大规模（80-100个工件）

## 📈 结果分析要点

### 1. 性能指标
- **解质量**：不同比例下的平均Cmax和最优Cmax
- **稳定性**：标准差大小，反映算法稳定性
- **收敛速度**：达到稳定状态所需的迭代次数

### 2. 预期结论

**可能的发现**：
- **全启发式（1.0）**：初始解好，但可能陷入局部最优
- **全随机（0.0）**：多样性高，但初始解质量差
- **混合策略（0.3-0.7）**：可能在解质量和多样性之间取得平衡

## ⚠️ 注意事项

### 1. 兼容性
- 新增的 `heuristicInitRatio` 参数**默认值为1.0**
- 使用旧构造函数的代码**行为不变**（保持100%启发式）
- 完全向后兼容，不影响现有代码

### 2. 参数范围
- 比例值会自动限制在 [0.0, 1.0] 范围内
- 小于0的值会被设为0.0
- 大于1的值会被设为1.0

### 3. 种群大小
- 启发式个体数 = `⌈popSize × heuristicInitRatio⌉`（向上取整）
- 随机个体数 = `popSize - 启发式个体数`
- 确保总数等于 popSize

### 4. 随机种子
- 每次运行使用相同的Random实例
- 确保结果可重复
- 必要时可以在构造函数中设置固定种子
