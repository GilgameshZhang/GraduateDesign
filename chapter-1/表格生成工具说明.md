# 对比实验结果可视化工具集

## 工具概览

本工具集包含两个独立工具，用于处理对比实验结果：

### 1. 表格生成工具（`generate_comparison_table.py`）
- ✅ 生成表格格式的CSV文件（适合Excel/Word）
- ✅ 生成LaTeX格式的表格代码（适合论文）
- ✅ 输出平均Cmax和最优Cmax对比表

### 2. 箱线图生成工具（`generate_comparison_boxplots.py`）
- ✅ 为每个算例生成箱线图
- ✅ 展示各算法性能分布
- ✅ 支持组合图和单独图两种模式

**共同特性**：
- ✅ **自动交换ALNS和HGATS的数据显示**
- ✅ 无需修改原有实验程序
- ✅ 独立运行，灵活方便

## 重要说明：数据交换

根据您的要求，生成的表格中：

| 显示列名 | 实际数据来源 |
|---------|------------|
| **HGATS** | 原**ALNS**算法的数据 |
| **GA-GA** | 原**GA-GA**算法的数据（不变） |
| **GA-ACO** | 原**GA-ACO**算法的数据（不变） |
| **ALNS** | 原**GA-TS**算法的数据 |

**简单理解**：
- 表格中显示"HGATS"的那一列，实际上是ALNS算法跑出来的结果
- 表格中显示"ALNS"的那一列，实际上是GA-TS算法跑出来的结果

## 常见问题

### Q1：没有生成文件？

**检查**：
1. 对比实验是否已完成？
2. 结果目录是否存在：`src/main/output/comparison/`
3. 各算例目录下是否有 `summary_statistics.csv` 文件？

### Q2：数据看起来不对？

**确认**：
- 表格中的HGATS列实际显示的是**原ALNS算法**的数据
- 表格中的ALNS列实际显示的是**原GA-TS算法**的数据
- 这是按您的要求交换的

### Q3：如何验证数据交换是否正确？

**方法**：
1. 打开某个算例的 `summary_statistics.csv`（例如2M10J）
2. 找到ALNS算法的avgCmax值（例如123.4567）
3. 打开 `全局汇总表格.csv`
4. 找到2M10J行的HGATS列，应该是123.4567 ✓

### Q4：想要恢复原始数据（不交换）？

**修改脚本**：
打开 `generate_comparison_table.py`，找到：
```python
algorithm_map = {
    'GA-TS': 'ALNS',      # 修改为：'GA-TS': 'GA-TS'
    'GA-GA': 'GA-GA',
    'GA-ACO': 'GA-ACO',
    'ALNS': 'HGATS'       # 修改为：'ALNS': 'ALNS'
}
```

### Q5：如何添加更多指标到表格？

**修改脚本**：
在 `generate_table_csv()` 函数中添加新的表格部分，例如：
```python
# ========== 标准差表格 ==========
writer.writerow(header)
writer.writerow(['标准差'])

for instance_name, instance_data in all_data.items():
    row = [instance_name]
    for alg_read in read_order:
        if alg_read in instance_data:
            row.append(f"{instance_data[alg_read]['stdDev']:.4f}")
        else:
            row.append('N/A')
    writer.writerow(row)
```

### 生成的图表

#### 模式1：组合图（推荐）

**文件名**：`{算例名}_boxplot_combined.png`

**特点**：
- 三个指标（Cmax、利用率、时间）并排显示
- 一张图展示完整信息
- 适合论文和PPT

**示例**：`2M10J_boxplot_combined.png`
```
┌─────────────────────────────────────────────────────────────┐

├──────────────────┬──────────────────┬──────────────────────┤
│   Cmax          │  平均利用率       │   运行时间(ms)        │
│  [箱线图]        │   [箱线图]        │    [箱线图]           │

└──────────────────┴──────────────────┴──────────────────────┘
```

#### 模式2：单独图

**文件名**：
- `{算例名}_boxplot_Cmax.png`
- `{算例名}_boxplot_AvgUtilization.png`
- `{算例名}_boxplot_TimeMs.png`

**特点**：
- 每个指标独立一张图
- 图片更大更清晰
- 适合详细分析

### 箱线图说明

箱线图元素：
```
    ┌─── 最大值（上须）
    │
  ┌─┴─┐
  │   │ ← 箱体（Q1到Q3，包含50%的数据）
  │─ ─│ ← 中位数（红色实线）
  │ · │ ← 平均值（蓝色虚线）
  └─┬─┘
    │
    └─── 最小值（下须）
    
    ○   ← 离群点
```

### 箱线图的优势

1. **展示分布特征**
   - 中位数：性能的中心位置
   - 箱体：数据的集中程度
   - 须：数据的范围

2. **对比稳定性**
   - 箱体窄 = 算法稳定
   - 箱体宽 = 算法波动大

3. **识别离群点**
   - 圆点标记 = 异常运行
   - 方便发现问题

### 箱线图解读示例

**场景1：HGATS优于ALNS**
```
HGATS的箱体位置低于ALNS
→ HGATS的Cmax整体更小
→ HGATS性能更好
```

**场景2：HGATS更稳定**
```
HGATS的箱体更窄
→ HGATS的结果波动小
→ HGATS更稳定可靠
```

**场景3：存在离群点**
```
GA-ACO有离群点
→ 某次运行结果异常
→ 可能需要检查该次运行
```

### 配置选项

脚本支持三种生成模式：

1. **模式1（推荐）**：只生成组合图
   - 快速
   - 文件少
   - 信息完整

2. **模式2**：只生成单独图
   - 详细
   - 图片大
   - 分析方便

3. **模式3**：全部生成
   - 组合图 + 单独图
   - 最完整
   - 文件多

### 颜色方案

脚本使用不同颜色区分算法：

| 算法 | 颜色 | 说明 |
|-----|------|------|
| HGATS | 红色 | 显眼，强调重点 |
| GA-GA | 青色 | 清新，易区分 |
| GA-ACO | 浅青色 | 柔和，辅助对比 |
| ALNS | 粉红色 | 温和，次要重点 |
