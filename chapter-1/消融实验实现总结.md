## 评分策略实现细节

### 复杂评分策略（原始）

```
遍历所有未放置的工件
  ↓
对每个工件计算12级评分
  ↓
选择评分最高的工件
  ↓
放置该工件
  ↓
继续下一个天际线
```

**特点**：
- 遍历所有工件
- 智能选择最优
- 批次利用率高

### 按顺序策略（消融）

```
尝试当前工件（counter）
  ↓
能放置？
├─ 是 → 放置，counter++
└─ 否 → 结束批次，开始新批次
```

**特点**：
- 不遍历所有工件
- 严格按顺序
- 放不下就结束批次
- 批次数增加

### 性能影响

**为什么按顺序策略性能下降5-10%？**

1. **批次数增加**：无法跳过暂时放不下的工件
2. **空间浪费**：无法智能填补空隙
3. **顺序依赖**：性能严重依赖输入顺序

**示例对比**：
```
工件序列：[A(大), B(小), C(中), D(小)]
当前天际线空间：中等

复杂评分：
  - 遍历 [A,B,C,D]
  - C 和 D 都能放，C 评分更高
  - 放置 C
  - 批次1：[C, D, B]，批次2：[A]
  - 总批次数：2

按顺序：
  - 尝试 A（太大，放不下）
  - 结束批次
  - 批次1：[]，批次2：[A]，批次3：[B, C, D]
  - 总批次数：3（实际上批次1为空，2个有效批次）
```
