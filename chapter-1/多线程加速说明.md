## 多线程实现

### 核心技术

使用 Java 的 `ExecutorService` 和 `Callable` 实现任务并行：

```java
// 创建线程池（最多8个线程）
int numThreads = Math.min(Runtime.getRuntime().availableProcessors(), 8);
ExecutorService executor = Executors.newFixedThreadPool(numThreads);

// 为每个配置×运行次数创建独立任务
List<Callable<ExperimentResult>> tasks = new ArrayList<>();
for (int run = 1; run <= numRuns; run++) {
    for (AblationConfig config : configs) {
        tasks.add(() -> runSingleExperiment(...));
    }
}

// 并行执行所有任务
List<Future<ExperimentResult>> futures = executor.invokeAll(tasks);
```

### 线程安全措施

1. **同步集合**：使用 `Collections.synchronizedList()` 保护结果列表
   ```java
   instanceResults.put(config.configId, 
       Collections.synchronizedList(new ArrayList<ExperimentResult>()));
   ```

2. **原子计数器**：使用 `AtomicInteger` 追踪进度
   ```java
   AtomicInteger completedTasks = new AtomicInteger(0);
   int completed = completedTasks.incrementAndGet();
   ```

3. **同步输出**：使用 `synchronized (System.out)` 保护控制台输出
   ```java
   synchronized (System.out) {
       System.out.println("进度信息...");
   }
   ```

## 线程数选择

### 自动检测

代码会自动检测可用CPU核心数：
```java

```

### 推荐配置

| CPU核心数 | 建议线程数 | 预计耗时 |
|-----------|------------|----------|
| 4核 | 4 | ~6-7小时 |
| 6核 | 6 | ~4-5小时 |
| 8核+ | 8 | ~3-4小时 |

**为什么限制最多8个线程？**
- 避免过多线程导致上下文切换开销
- 每个任务需要5分钟，不需要太多并发
- 8个线程已经能充分利用大多数CPU

## 注意事项

### 1. 线程安全

所有共享数据结构都已做好线程安全处理：
- ✅ 结果列表使用 `synchronizedList`
- ✅ 进度计数使用 `AtomicInteger`
- ✅ 控制台输出使用 `synchronized`

### 2. 异常处理

完善的异常处理机制：
- 单个任务失败不影响其他任务
- 捕获并记录所有异常
- 优雅关闭线程池

### 3. 内存占用

多线程会增加内存占用：
- 8个线程同时运行8个GA实例
- 建议至少8GB可用内存
- 大规模算例可能需要更多内存

### 4. 结果一致性

**多线程不影响结果正确性**：
- 每个任务完全独立
- 随机种子由系统时间自动生成
- 结果统计完全准确
