## 🎯 核心改进

### 新增参数：`heuristicInitRatio`

这个参数控制种群初始化时使用启发式规则的比例：

| 参数值 | 启发式个体 | 随机个体 | 说明 |
|-------|-----------|---------|------|
| 0.0 | 0% | 100% | 全部随机初始化 |
| 0.25 | 25% | 75% | 25%启发式 + 75%随机 |
| 0.5 | 50% | 50% | 一半启发式，一半随机 |
| 0.75 | 75% | 25% | 75%启发式 + 25%随机 |
| 1.0 | 100% | 0% | 全部启发式（默认值） |

### 初始化策略说明

#### 🔹 启发式初始化（Heuristic）
- **零件排序**：按高度从高到低排序
- **机器分配**：基于机器打印能力的概率分配
- **特点**：利用问题领域知识，初始解质量高，但多样性相对较低

#### 🔹 随机初始化（Random）
- **零件排序**：完全随机打乱
- **机器分配**：随机选择满足约束的机器
- **特点**：种群多样性高，覆盖更广的搜索空间，但初始解质量可能较低

## 💻 使用方法

### 方法1：创建消融实验对象

```java
import AlgorithmFrame.machineChoice.ga.BatchGaAblation;
import ProblemFrame.Input;
import ProblemFrame.Result;
import util.ReadDataUtil;

// 读取算例
Input input = ReadDataUtil.readData(
    "chapter-1/src/main/resources/Machine/machine_2",
    "chapter-1/src/main/resources/PrintItem/printItem_10/printItem_10_01",
    true
);

// 创建50%启发式 + 50%随机的混合初始化策略
BatchGaAblation ga = new BatchGaAblation(
    10000,              // MAX_GEN
    100,                // popSize（种群大小100）
    5.0,                // variationExchangeCount
    3,                  // cloneNumOfBestIndividual
    0.3,                // mutationRate
    0.7,                // crossoverRate
    input,              // 输入数据
    true,               // isRotateEnable
    "TS",               // method（使用禁忌搜索）
    100,                // decodeMaxGen
    10,                 // decodeTabuSize
    30,                 // decodeMaxN
    5 * 60 * 1000,      // timeLimitMs（5分钟）
    0.5                 // heuristicInitRatio（50%启发式）
);

Result result = ga.solve();

// 提取结果
double cmax = result.getSolutionList().stream()
    .mapToDouble(br -> br.fitness)
    .min()
    .orElse(Double.MAX_VALUE);
    
System.out.println("最优Cmax: " + cmax);
```

## 🔍 深入分析

### 预期结果分析

1. **全随机（0.0）**：
   - 优点：种群多样性最大，覆盖搜索空间广
   - 缺点：初始解质量差，需要更多代数才能收敛
   - 适用场景：问题结构不明确，或需要避免早熟收敛

2. **全启发式（1.0）**：
   - 优点：初始解质量高，收敛快
   - 缺点：种群多样性低，容易陷入局部最优
   - 适用场景：问题结构清晰，启发式规则有效

3. **混合策略（0.3-0.7）**：
   - 优点：平衡解质量和多样性
   - 缺点：需要调整找到最优比例
   - 适用场景：一般推荐，适合大多数情况

### 影响因素

初始化策略的效果可能受以下因素影响：

1. **问题规模**：
   - 小规模：启发式效果可能更明显
   - 大规模：多样性可能更重要

2. **启发式规则质量**：
   - 规则好：高比例启发式更有效
   - 规则一般：低比例可能更好

3. **其他参数**：
   - 高变异率：可以弥补启发式初始化的多样性不足
   - 大种群：对初始化策略的依赖可能降低

## ⚠️ 注意事项

### 1. 向后兼容性
- ✅ 旧代码完全不受影响
- ✅ 不传入 `heuristicInitRatio` 参数时，默认使用1.0（全启发式）
- ✅ 保持原有行为不变

### 2. 参数验证
- 自动将比例限制在 [0.0, 1.0] 范围内
- 小于0会自动设为0
- 大于1会自动设为1

### 3. 种群大小计算
- 启发式个体数 = ⌈popSize × heuristicInitRatio⌉（向上取整）
- 随机个体数 = popSize - 启发式个体数
- 确保两者之和等于popSize

### 4. 输出信息
- 运行时会自动输出初始化策略信息
- 便于记录和验证实验配置
- 包含在控制台日志中
