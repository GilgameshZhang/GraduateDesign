### 方案概述

**对比实验**：5个规模梯队 × 4个案例 = 20个算例
**消融实验**：5个规模梯队 × 1个案例 = 5个算例

### 实验规模梯队

| 级别 | 机器 | 工件 | 描述 | 算例编号（对比实验） | 算例编号（消融实验） |
|-----|-----|-----|-----|------------------|----------------|
| 1. 小规模 | 2 | 10 | 验证基本功能 | 1-4 | 1 |
| 2. 中小规模 | 3 | 20 | 初步性能差异 | 5-8 | 5 |
| 3. 中等规模 | 3 | 40 | 性能开始分化 | 9-12 | 9 |
| 4. 中大规模 | 4 | 60 | 测试可扩展性 | 13-16 | 13 |
| 5. 大规模 | 5 | 80 | 极限性能测试 | 17-20 | 17 |

## 📋 实际操作步骤

### 第一步：准备实验环境

1. 确保所有代码已编译成功
2. 检查算例文件是否齐全
3. 确认有足够的磁盘空间（至少1GB）

```bash
cd chapter-1
mvn clean compile test-compile -DskipTests
```

### 第二步：修改实验配置

#### 对于对比实验

编辑 `MultiAlgorithmComparison.java` 的 `main` 方法，参考 `实验运行指南.md` 中的完整配置代码，添加所有20个算例的调用。

**简化示例**（每个规模复制4次，修改案例编号）：

```java
public static void main(String[] args) {
    // 小规模 - 4个案例
    for (int i = 1; i <= 4; i++) {
        runMultiAlgorithmComparison(
            "chapter-1/src/main/resources/Machine/machine_2",
            String.format("chapter-1/src/main/resources/PrintItem/printItem_10/printItem_10_%02d", i),
            String.format("Small-2M10J-%02d", i),
            3, true
        );
    }
    
    // 中小规模 - 4个案例
    for (int i = 1; i <= 4; i++) {
        runMultiAlgorithmComparison(
            "chapter-1/src/main/resources/Machine/machine_3",
            String.format("chapter-1/src/main/resources/PrintItem/printItem_20/printItem_20_%02d", i),
            String.format("MediumSmall-3M20J-%02d", i),
            3, true
        );
    }
    
    // 以此类推...（参考完整版）
}
```

#### 对于消融实验

编辑 `AblationExperimentRunner.java`，在`main`方法中配置5个算例（每个规模的案例01）。

### 第三步：执行实验

```bash
# 对比实验（预计5-7小时，多线程）
mvn exec:java -Dexec.mainClass="MultiAlgorithmComparison" -Dexec.classpathScope=test

# 消融实验（预计1.5-2小时，多线程）
mvn exec:java -Dexec.mainClass="AblationExperimentRunner" -Dexec.classpathScope=test
```

### 第四步：收集结果

实验完成后，结果保存在：
- `multi_algorithm_comparison_results/` 
- `ablation_results/`

## 💡 实用建议

### 1. 分阶段执行

不要一次运行全部20个算例，建议分阶段：

**第1天**：小规模（1-4）+ 中小规模（5-8） ≈ 2小时
**第2天**：中等规模（9-12） ≈ 1小时
**第3天**：中大规模（13-16） ≈ 1.5小时
**第4天**：大规模（17-20） ≈ 2小时
**第5天**：消融实验（5个） ≈ 1.5小时

### 2. 快速验证

先运行1个小规模算例，确保一切正常：

```java
public static void main(String[] args) {
    runMultiAlgorithmComparison(
        "chapter-1/src/main/resources/Machine/machine_2",
        "chapter-1/src/main/resources/PrintItem/printItem_10/printItem_10_01",
        "Test-Small",
        1,    // 只运行1次（而非3次）
        true
    );
}
```

### 3. 备份结果

每完成一个阶段，立即备份结果目录。

### 4. 结果验证

检查：
- CSV文件是否生成
- 数据是否完整（没有NaN或异常值）
- 可视化图表是否正确
