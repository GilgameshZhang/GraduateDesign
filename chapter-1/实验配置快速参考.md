## ⚙️ 五、自定义配置

### 修改时间限制

在对应的Java文件中修改：
```java
private static final long TIME_LIMIT_MS = 5 * 60 * 1000;  // 改为其他值（毫秒）
```

### 修改重复次数

```java
private static final int NUM_RUNS = 3;  // 改为其他值
```

### 修改线程数

```java
private static final int THREAD_POOL_SIZE = 4;  // 改为CPU核心数
```

### 禁用多线程

```java
private static final boolean ENABLE_MULTI_THREADING = false;  // 改为false
```

### 选择不同案例

在`generateInstanceConfigs()`方法中修改案例编号：
```java
// 从案例01改为案例02
configs.add(new InstanceConfig("Small-2M10J-02", 2, 10, "小规模", 2));
```

## 💡 七、注意事项

1. **确保算例文件存在**: 检查`src/main/resources/`目录下的Machine和PrintItem文件夹
2. **留足磁盘空间**: 预留至少1GB空间存储结果
3. **保持系统稳定**: 实验期间避免运行其他高负载程序
4. **及时备份结果**: 实验完成后立即备份结果目录
5. **记录实验环境**: 记录CPU型号、内存大小、操作系统等信息用于论文
