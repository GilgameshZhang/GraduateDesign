# 第一章可视化功能 - 快速开始指南

## 🎯 功能概述

现在第一章的所有算法（GA-TS、GA-GA、GA-ACO、ALNS）都支持自动生成可视化图表！

### ⏱️ 重要更新：时间限制终止条件

**所有算法现在使用5分钟时间限制作为终止条件！**
- 不再使用固定迭代次数
- 更公平的算法对比
- 更符合实际应用场景

### 生成的图表类型

1. **迭代曲线图** - 查看算法收敛过程
2. **批次分布图** - 查看各机器的负载情况
3. **甘特图** - 查看作业调度时间线
4. **批次布局图** - 查看每个批次中零件的布局

## 🚀 快速开始

### 方法1：多算法对比（推荐）

**最完整的对比实验！包含GA-TS、GA-GA、GA-ACO、ALNS**

```java
// 运行: MultiAlgorithmComparison.java
public static void main(String[] args) {
    runMultiAlgorithmComparison(
        machinePath,
        itemPath,
        "Small-2M10J",
        3,      // 每个算法运行3次（每次5分钟）
        true    // ✅ 开启可视化
    );
}
// 预计耗时：4算法 × 3次 × 5分钟 / 8核 ≈ 7.5分钟
```

### 方法2：单算法对比

运行 `ComparisonExperiment.java`（只测试GA-TS）：

```java
public static void main(String[] args) {
    runComparison(
        machinePath,
        itemPath,
        3,      // 运行3次（每次5分钟）
        true    // ✅ 开启可视化
    );
}
// 预计耗时：3次 × 5分钟 = 15分钟
```

### 方法3：消融实验

运行 `AblationExperimentRunner.java`：

```java
public static void main(String[] args) {
    runAblationExperimentParallel(true);  // ✅ 多线程 + 可视化
}
// 预计耗时：5配置 × 3算例 × 10次 × 5分钟 / 8核 ≈ 47分钟
```

### 方法4：快速测试

运行 `VisualizationTest.java`：

```java
public static void main(String[] args) {
    quickTest();  // 快速测试（30秒）
    // 或
    fullTest();   // 完整测试（使用时间限制）
}
```

## 🎨 生成的图表示例

### 1. 迭代曲线图
- 显示每一代的最优Cmax
- 观察算法收敛速度

### 2. 批次分布图
- 蓝色柱：各机器的批次数量
- 橙色线：各机器的利用率

### 3. 甘特图
- 横轴：时间
- 纵轴：机器编号
- 矩形：批次（标注 B机器号-批次号）

### 4. 批次布局图
- 显示每个批次中零件的具体位置
- 红色↻标记：零件被旋转

## ⚙️ 配置选项

### 开启/关闭可视化

```java
// 开启可视化（会增加运行时间和存储空间）
runComparison(path1, path2, runs, true);

// 关闭可视化（只保存数值结果）
runComparison(path1, path2, runs, false);
```

### 调整算法参数

```java
ALNSParameters params = new ALNSParameters();
params.maxIterations = 1000;      // 迭代次数
params.timeLimitMs = 60000;       // 时间限制（毫秒）
```

## ⚡ 性能提示

1. **首次测试**：建议先运行 `quickTest()` 验证功能（30秒）
2. **完整测试**：`fullTest()` 需要5-10分钟
3. **大规模实验**：建议关闭可视化或只为最优运行生成图表

## 🔧 故障排除

### 问题：中文显示为方块
**解决**：系统缺少微软雅黑字体，可修改代码使用其他字体

### 问题：图表生成失败
**检查**：
1. JFreeChart依赖是否存在（pom.xml）
2. 输出目录权限是否足够

### 问题：图表为空
**检查**：算法是否正常运行并返回结果
