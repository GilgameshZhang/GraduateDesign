## 🎯 如何查看结果

### 1. 查看单次运行的详细结果

```bash
cd chapter-1/src/main/output/ablation/
cd V0-Full_Small-2M10J_run1_*/
cat 实验报告.txt
# 查看收敛曲线图.png
```

### 2. 查看汇总结果

```bash
cd chapter-1/src/main/output/ablation/
cat ablation_summary.csv
cat ablation_report.txt
```

### 3. 使用Excel分析

打开 `ablation_detailed_results.csv` 或 `ablation_summary.csv`，可以：
- 生成图表
- 进行统计分析
- 对比不同配置

## 💡 使用建议

### 1. 论文撰写

- 使用 `收敛曲线图.png` 展示算法性能
- 使用 `ablation_summary.csv` 制作对比表格
- 引用 `实验报告.txt` 中的详细数据

### 2. 结果分析

- 对比不同配置的RPD值
- 分析标准差判断算法稳定性
- 观察收敛曲线判断收敛速度

### 3. 问题排查

- 查看 `实验报告.txt` 了解算法运行细节
- 检查批次分配是否合理
- 查看机器负载是否均衡

## 🚀 运行实验

```bash
cd chapter-1
run_ablation_experiment.bat
# 选择 [2] 完整实验
```

实验完成后，会自动生成所有文件和图表。

## 📝 注意事项

1. **磁盘空间**：每次运行约占用1-2MB，完整实验（5配置×3算例×10次）约150MB
2. **运行时间**：每次运行5分钟，完整实验约2-5小时
3. **文件命名**：包含时间戳，不会覆盖之前的结果
4. **图片格式**：PNG格式，可直接插入论文
