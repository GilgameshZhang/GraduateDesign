# BL算法平面排布图使用说明

## 🎨 功能概述

BL算法现在支持生成**精美的平面排布图**，可视化展示每个托盘上的物品摆放情况。

## 📊 生成的可视化内容

### 1. 平面排布图
每个托盘会生成一个单独的PNG图片，包含：
- ✅ 容器边界（黑色粗边框）
- ✅ 每个物品的矩形表示（不同颜色区分）
- ✅ 物品名称标签
- ✅ 物品尺寸标注
- ✅ 旋转标记（如果物品被旋转则显示↻）
- ✅ 统计信息（物品数量、利用率、使用面积、最大高度）

### 2. 文本数据
还会生成包含详细坐标信息的文本文件。

## 🚀 快速开始

### 运行测试
直接运行 `Run.java` 即可：

```bash
# 方式1：在IDE中运行
右键点击 Run.java → Run 'Run.main()'

# 方式2：命令行运行（在chapter-1目录下）
mvn compile
mvn exec:java -Dexec.mainClass="AlgorithmFrame.bachSelect.bottomLeft.Run"
```

### 输出位置
所有可视化结果保存在：
```
visualization_results/
├── BL_原始顺序_托盘1.png

├── BL_面积降序.txt

├── ...
```

## 🎯 自定义配置

### 修改数据路径
在 `Run.java` 中修改第14-15行：

```java
String itemPath = "你的物品数据路径";
String machinePath = "你的机器数据路径";
```

### 调整图片大小
在 `BLLayoutVisualizer.java` 的第 `generateSingleLayout` 方法中：

```java
ChartUtils.saveChartAsPNG(outputFile, chart, 1200, 1000); // 宽度, 高度
```

### 修改颜色方案
在 `BLLayoutVisualizer.java` 的 `getColorForItem` 方法中自定义颜色：

```java
Color[] colors = {
    new Color(255, 200, 200), // RGB格式
    new Color(200, 255, 200),
    // 添加更多颜色...
};
```

### 颜色说明
- 🟥 浅红、🟩 浅绿、🟦 浅蓝、🟨 浅黄、🟪 浅粉、🟦 浅青...
- 每个物品使用不同颜色，便于区分
- 边框使用深色，填充使用浅色

### 标记说明
- **↻** - 表示该物品被旋转了90度
- **黑色粗边框** - 容器边界
- **物品名称** - 居中显示在矩形内
- **尺寸标注** - 显示在矩形下方（长×宽）

## 🔧 技术细节

### 依赖库
- **JFreeChart 1.5.3** - 用于图表生成
- 已添加到 `pom.xml` 中，Maven会自动下载

### 核心类
1. **BLLayoutVisualizer.java** - 可视化生成器
2. **Run.java** - 主程序，包含可视化调用
3. **BottomLeftPacking.java** - BL算法核心

### 生成流程
```
Run.java
  └─> testStrategy()
       ├─> BottomLeftPacking.packings()  → 生成装箱方案
       ├─> saveVisualizationData()       → 保存文本数据
       └─> BLLayoutVisualizer.generateAllLayouts()  → 生成PNG图片
```

## 📝 注意事项

1. **文件夹创建** - 程序会自动创建 `visualization_results/` 文件夹
2. **中文支持** - 使用微软雅黑字体，支持中文显示
3. **坐标系统** - 左下角为原点(0,0)，与数学坐标系一致
4. **尺寸单位** - 所有尺寸单位为毫米(mm)

## 🐛 常见问题

**Q: 图片没有生成？**  
A: 检查控制台是否有错误信息，确保 `visualization_results/` 文件夹有写入权限。

**Q: 中文显示乱码？**  
A: 确保系统安装了微软雅黑字体，或在代码中修改为其他字体。

**Q: 图片太小看不清？**  
A: 修改 `ChartUtils.saveChartAsPNG()` 的宽高参数。

**Q: 颜色不够用？**  
A: 在 `getColorForItem()` 方法中添加更多颜色。
