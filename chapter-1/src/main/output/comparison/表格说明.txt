重要说明：数据映射关系
================================================================================

表格中的数据已按要求进行交换：

  显示列名        实际数据来源
  ---------      -------------
  HGATS    ←     原ALNS算法的数据
  GA-GA    ←     原GA-GA算法的数据（不变）
  GA-ACO   ←     原GA-ACO算法的数据（不变）
  ALNS     ←     原GA-TS算法的数据

================================================================================
表格格式说明
================================================================================

1. 全局汇总表格.csv（推荐用于论文）
   包含两个表格：

   表格1 - 平均Cmax：
   ┌─────────┬─────────┬─────────┬─────────┬─────────┐
   │  算例   │  HGATS  │  GA-GA  │ GA-ACO  │  ALNS   │
   ├─────────┼─────────┼─────────┼─────────┼─────────┤
   │ 2M10J   │ 123.45  │ 125.67  │ 126.89  │ 124.01  │
   │ 2M20J   │ 234.56  │ 236.78  │ 237.90  │ 235.12  │
   │ ...     │ ...     │ ...     │ ...     │ ...     │
   └─────────┴─────────┴─────────┴─────────┴─────────┘

   表格2 - 最优Cmax：
   （格式相同，数值为各算法的最优结果）

2. 全局汇总表格_详细.csv
   长格式表格，包含所有统计指标：
   - 算例、算法、平均Cmax、最优Cmax、最差Cmax
   - 标准差、平均利用率、平均时间

3. 全局汇总表格.tex
   LaTeX格式，可直接用于论文排版
   包含平均Cmax和最优Cmax两个表格

================================================================================
使用方法
================================================================================

Excel/WPS：
  1. 打开 全局汇总表格.csv
  2. 数据已经是表格格式，可以直接使用
  3. 可以复制粘贴到Word文档

LaTeX：
  1. 打开 全局汇总表格.tex
  2. 复制表格代码到论文中
  3. 需要的宏包：\usepackage{array}

Python分析：
  使用 全局汇总表格_详细.csv 进行数据分析
  import pandas as pd
  df = pd.read_csv('全局汇总表格_详细.csv')

================================================================================
注意事项
================================================================================

1. 数据交换说明：
   - 表格中显示的HGATS实际是原ALNS算法的运行结果
   - 表格中显示的ALNS实际是原GA-TS算法的运行结果
   - 这是按照您的要求进行的数据映射

2. 数据来源：
   - 从各算例的 summary_statistics.csv 文件读取
   - 位置：src/main/output/comparison/{算例名}/

3. 如需重新生成表格：
   - 运行：python generate_comparison_table.py
   - 确保对比实验已完成
