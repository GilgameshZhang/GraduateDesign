# 第一章GA-TS算法消融实验 - 使用指南

## 📋 实验概述

本消融实验用于验证第一章GA-TS算法中三个关键组件的贡献：

| 组件 | 说明 |
|-----|------|
| **初始化策略** | 启发式初始化（按高度降序+能力概率分配） vs 随机初始化 |
| **禁忌搜索** | 完整TabuSearch（3种邻域+动态禁忌表） vs 不用搜索 |
| **Skyline启发式规则** | 12级复杂评分规则 vs 简化规则（能放=1分） |

## 🔍 关键指标说明

### RPD（相对性能损失）

```
RPD = (当前配置平均Cmax - V0-Full平均Cmax) / V0-Full平均Cmax × 100%
```

- **RPD > 0**: 性能下降（Cmax增大）
- **RPD越大**: 该组件贡献越大
- **RPD = 0**: 与基线相同（V0-Full）

### 其他指标

- **Cmax**: 最大完工时间，越小越好
- **标准差**: 解的稳定性，越小越稳定
- **材料利用率**: 材料使用效率，越大越好

## 🎯 结果解读示例

假设实验结果：

| 配置 | 平均Cmax | RPD |
|-----|---------|-----|
| V0-Full | 1000.0 | 0.00% |
| V1-NoHeuristic | 1050.0 | +5.00% |
| V2-NoTabu | 1120.0 | +12.00% |
| V3-SimpleHeuristic | 1080.0 | +8.00% |
| V4-Minimal | 1200.0 | +20.00% |

**解读**：
1. **禁忌搜索贡献最大**（RPD=12%），移除后性能下降最多
2. **Skyline启发式规则次之**（RPD=8%）
3. **初始化策略最小**（RPD=5%），但仍有一定作用
4. **三个组件协同作用明显**，全部移除后性能下降20%

## ❓ 常见问题

### Q1: 编译错误
**A**: 检查classpath，确保所有依赖类可访问。使用IDE的话，将chapter-1设为源根目录。

### Q2: 内存不足
**A**: 增加JVM堆内存：
```bash
java -Xmx4g -cp ... AblationExperimentRunner
```

### Q3: 实验中断了怎么办
**A**: 可以修改代码，在外层循环添加条件跳过已完成的算例和配置。

### Q4: 结果不稳定
**A**: 增加运行次数（修改`numRuns`变量），或者固定随机种子。

### Q5: 可视化脚本报错
**A**: 
```bash
# 安装依赖
pip install pandas matplotlib seaborn numpy

# 如果中文显示乱码，安装中文字体
pip install matplotlib --upgrade
```
