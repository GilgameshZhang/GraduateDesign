## 💡 实用技巧

### 1. 批量运行脚本

创建一个简单的批处理脚本来运行所有算例：

```bash
# run_all_experiments.sh (Linux/Mac)
#!/bin/bash

echo "开始运行所有实验..."
cd chapter-1

# 编译一次
mvn clean compile test-compile

# 运行对比实验
echo "运行对比实验..."
mvn exec:java -Dexec.mainClass="MultiAlgorithmComparison" -Dexec.classpathScope=test

# 运行消融实验
echo "运行消融实验..."
mvn exec:java -Dexec.mainClass="AblationExperimentRunner" -Dexec.classpathScope=test

echo "所有实验完成！"
```

### 2. 结果汇总

所有结果会保存在：
- `multi_algorithm_comparison_results/` - 对比实验结果
- `ablation_results/` - 消融实验结果

### 3. 中断恢复

如果实验中断，可以：
1. 查看已生成的CSV文件，确定哪些算例已完成
2. 注释掉`main`方法中已完成的算例
3. 重新运行程序继续未完成的算例
