## 🔧 技术实现

### 使用的技术栈

1. **JFreeChart 1.5.3**
   - 专业图表库
   - 支持自定义绘制
   - 中文字体支持

2. **Java AWT**
   - 自定义图形绘制
   - 矩形、文本标注
   - 颜色和字体管理

### 核心类

```
util/
├── ChartGenerator.java         # 迭代曲线图生成
├── BatchVisualization.java     # 甘特图和批次布局图生成
└── ExperimentResultWriter.java # 实验报告和图表管理
```

## 🎓 论文使用建议

### 1. 图表质量

所有图表均为：
- **PNG格式**：无损压缩
- **高分辨率**：可直接插入论文
- **专业配色**：符合学术规范
- **中文标注**：便于阅读

### 2. 图表选择

**消融实验章节**：
- 使用收敛曲线图展示不同配置的收敛性能
- 使用甘特图展示负载均衡情况
- 选择代表性批次布局图展示装箱效果

**建议组合**：
- 主图：多配置收敛曲线对比图
- 辅图1：最优配置的甘特图
- 辅图2：典型批次的布局图

### 3. 图表说明

推荐的图注格式：

```
图X.X 不同配置的算法收敛曲线对比
说明：横轴为迭代次数，纵轴为最优Cmax值。可以看出完整算法（蓝色）
收敛速度最快，最终结果最优。
```

```
图X.X 最优解的批次调度甘特图
说明：横轴为时间，纵轴为机器编号。不同颜色的矩形代表不同机器上
的批次，标签表示批次编号。可以看出各机器负载较为均衡。
```

```
图X.X 机器1批次1的零件布局图
说明：展示了Skyline装箱算法的零件排列方案。不同颜色的矩形代表
不同零件，利用率达到85.3%。
```
