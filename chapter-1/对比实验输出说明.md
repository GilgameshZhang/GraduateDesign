## 📊 对比实验类型

### 1. 单算法对比 (ComparisonExperiment)

**测试算法**：GA-TS（外层GA + 内层禁忌搜索）

**运行次数**：通常3-10次

**输出**：
- 每次运行独立的实验报告和图表文件夹
- 一个汇总CSV文件

**示例命令**：
```bash
cd chapter-1/src/test/java
javac ComparisonExperiment.java
java ComparisonExperiment
```

### 2. 多算法对比 (MultiAlgorithmComparison)

**测试算法**：
- GA-TS：外层GA + 内层禁忌搜索
- GA-GA：外层GA + 内层遗传算法
- GA-ACO：外层GA + 内层蚁群算法
- ALNS：自适应大邻域搜索

**运行次数**：每个算法3-10次

**特点**：
- 多线程并行运行
- 自动对比统计
- 生成综合对比报告

**输出**：
- 每个算法每次运行的完整报告和图表
- 算法之间的对比汇总文件

## 🚀 如何运行

### 方法1：单算法对比

```java
// 在 ComparisonExperiment.java 的 main 方法中
public static void main(String[] args) {
    // 小规模算例（每次5分钟，带可视化）
    runComparison(
        "chapter-1/src/main/resources/Machine/machine_2",
        "chapter-1/src/main/resources/PrintItem/printItem_10/printItem_10_01",
        3,      // 运行3次
        true    // 开启可视化（每次都生成完整图表）
    );
}
```

**预计耗时**：3次 × 5分钟 = 15分钟

### 方法2：多算法对比

```java
// 在 MultiAlgorithmComparison.java 的 main 方法中
public static void main(String[] args) {
    runMultiAlgorithmComparison(
        "chapter-1/src/main/resources/Machine/machine_2",
        "chapter-1/src/main/resources/PrintItem/printItem_10/printItem_10_01",
        "Small-2M10J",
        3,      // 每个算法运行3次
        true    // 开启可视化（每次都生成完整图表）
    );
}
```

**预计耗时**：4个算法 × 3次 × 5分钟 = 60分钟（多线程并行会快一些）

## 💡 使用建议

### 1. 论文撰写

**算法对比章节**：
- 使用汇总CSV制作对比表格
- 选择代表性运行的收敛曲线进行对比
- 使用最优运行的甘特图展示调度效果

**推荐图表组合**：
- 表格：从 `statistics.csv` 制作算法对比表
- 图1：多算法收敛曲线对比图
- 图2：最优算法的甘特图
- 图3：典型批次的布局图

### 2. 结果分析

**性能对比**：
- 对比平均Cmax值
- 分析标准差（稳定性）
- 比较运行时间

**可视化对比**：
- 对比收敛速度（收敛曲线图）
- 对比负载均衡（甘特图）
- 对比装箱质量（批次布局图）

### 3. 实验设计

**推荐配置**：
- 小规模算例：每算法3-5次
- 中规模算例：每算法5-10次
- 大规模算例：每算法10次以上

**时间规划**：
- 每次运行5分钟
- 小实验：约1小时
- 中实验：约3小时
- 大实验：约6-12小时
