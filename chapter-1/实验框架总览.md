# 第一章实验框架总览

## 🎯 核心特性

### ✅ 支持的算法

1. **GA-TS**：外层GA + 内层禁忌搜索（您的算法）
2. **GA-GA**：外层GA + 内层遗传算法
3. **GA-ACO**：外层GA + 内层蚁群算法
4. **ALNS**：自适应大邻域搜索

### ✅ 支持的实验类型

1. **多算法对比实验** - 4个算法同时对比
2. **单算法对比实验** - 单独测试某个算法
3. **消融实验** - 测试算法各组件的贡献

### ✅ 关键功能

- ⏱️ **5分钟时间限制**：所有算法统一使用时间终止条件
- 🚀 **多线程并行**：充分利用多核CPU，4-8倍加速
- 📊 **完整可视化**：自动生成4类图表
- 📝 **详细报告**：CSV数据 + 统计分析 + 对比报告

## ⏱️ 时间限制详解

### 终止条件

**原来**：固定迭代次数（500代）
```java
BatchGa batchGa = new BatchGa(500, ...);  // 运行500代
```

**现在**：时间限制（5分钟）
```java
long timeLimitMs = 5 * 60 * 1000;  // 5分钟
BatchGa batchGa = new BatchGa(10000, ..., timeLimitMs);  // 运行5分钟
```

### 优势

| 特性 | 迭代次数模式 | 时间限制模式 ✅ |
|------|-------------|----------------|
| 公平性 | ❌ 不同算法不公平 | ✅ 所有算法相同时间 |
| 实用性 | 理论研究 | ✅ 实际应用导向 |
| 可控性 | 固定 | ✅ 根据需要调整 |
| 论文适用 | 一般 | ✅ 推荐 |

### 运行时输出

```
运行GA-TS算法（时间限制：5分钟）...
代数:10, Cmax:850.23, 进度:2.5% (7.5s/300.0s)
代数:20, Cmax:820.45, 进度:5.0% (15.0s/300.0s)
...
代数:680, Cmax:785.50, 进度:98.2% (294.6s/300.0s)
达到时间限制 300000ms，算法终止
总共完成 683 代，最优Cmax: 785.50
```

### 自定义时间限制

如需修改（例如改为10分钟）：

**MultiAlgorithmComparison.java**
```java
// 在 runGA() 和 runALNS() 方法中
long timeLimitMs = 10 * 60 * 1000;  // 10分钟
```

**AblationExperimentRunner.java**
```java
// 在 runSingleExperiment() 方法中
long timeLimitMs = 10 * 60 * 1000;  // 10分钟
```

## 🚄 多线程加速

### 加速效果

| CPU核心数 | 理论加速比 | 实际加速比 |
|-----------|-----------|-----------|

## 🔧 参数配置速查

### 时间限制

```java
long timeLimitMs = 5 * 60 * 1000;  // 5分钟（默认）

// 根据算例规模调整：
// 小算例（10作业）：1-3分钟
// 中等算例（20-30作业）：5-10分钟
// 大算例（50+作业）：10-30分钟
```

### GA参数

```java
BatchGa batchGa = new BatchGa(
    10000,  // MAX_GEN（很大，由时间控制）
    100,    // popSize（种群规模）
    5,      // variationExchangeCount
    2,      // cloneNumOfBestIndividual
    0.2,    // mutationRate（变异率）
    0.8,    // crossoverRate（交叉率）
    input,
    true,   // isRotateEnable
    "TabuSearch",  // 内层优化方法
    100,    // decodeMaxGen（内层迭代）
    10,     // decodeTabuSize（禁忌表大小）
    30,     // decodeMaxN（邻域大小）
    timeLimitMs
);
```

### ALNS参数

```java
ALNSParameters params = new ALNSParameters();
params.maxIterations = 10000;  // 很大，由时间控制
params.timeLimitMs = 5 * 60 * 1000;  // 5分钟
params.T0 = 100.0;              // 初始温度
params.beta = 0.995;            // 降温系数
params.theta = 0.3;             // 移除比例
```

## 🔍 常见问题

### Q: 为什么要用时间限制而不是迭代次数？

A: 
1. 公平性：不同算法单次迭代耗时不同
2. 实用性：实际应用通常有时间限制
3. 可比性：论文中更有说服力

### Q: 5分钟够吗？

A: 
- 小算例（10作业）：够，通常能跑600-700代
- 中等算例（20-30作业）：够，能跑400-500代
- 大算例（50+作业）：建议延长到10分钟

### Q: 多线程会影响结果吗？

A: 
- 不会：每个线程独立运行
- 使用不同随机种子保证可重现性
- 只影响运行速度，不影响结果

### Q: 可视化占用多少空间？

A: 
- 每次运行：5-15MB
- 多算法对比（4×3次）：约100-200MB
- 消融实验（5×3×10次）：约1-2GB

### Q: 如何加快实验速度？

A: 
1. 减少运行次数（例如从10次改为3次）
2. 关闭可视化（`enableVisualization = false`）
3. 缩短时间限制（例如改为2分钟）
4. 减少算例数量
